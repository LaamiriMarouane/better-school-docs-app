title: Settings

**Settings** is where a school's configuration lives. The admin sidebar splits settings into
separate pages; each page has its own tabs. Subscription and support tools sit next to Settings
in the same sidebar group.

## Settings pages

| Page | Tabs | Documented in |
| --- | --- | --- |
| **Academic** | Academic Year, Term structure, School schedule | [Create an academic year](../getting-started/build-the-academic-foundation/create-an-academic-year), [Academic year setup](../getting-started/build-the-academic-foundation/academic-year-setup), [School schedule](./school-schedule) |
| **School** | School Info, School Documents, Regional, Custom Fields, Transport Map Appearance | [Set up the school profile](../getting-started/first-time-school-setup/set-up-the-school-profile), [Custom fields](./custom-fields), [Transport map appearance](./transport-map) |
| **Finance** | Fiscal Year, Billing | [Fiscal years](./fiscal-year), [Billing configuration](./billing-configuration) |
| **Modules** | Optional feature toggles | [Configure school modules](../getting-started/first-time-school-setup/configure-school-modules) |
