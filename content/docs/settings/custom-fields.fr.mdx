---
title: Champs personnalisés
description: Ajoutez vos propres champs aux fiches des élèves, enseignants, membres du personnel et tuteurs.
---

Les **champs personnalisés** permettent à votre école de collecter des informations
que la plateforme ne demande pas par défaut. Un champ personnalisé que vous définissez
apparaît sur le formulaire de la fiche — pour les élèves, les enseignants, le personnel ou
les tuteurs — afin que chacun saisisse les mêmes détails supplémentaires.

<Callout title="Pour qui">
Les administrateurs qui adaptent les informations que l'école enregistre sur les
personnes.
</Callout>

## Ajouter un champ personnalisé

<Steps>

<Step>
### Ouvrir les paramètres Champs personnalisés

Allez dans **Paramètres → Établissement** et ouvrez l'onglet **Champs personnalisés**. Choisissez
le profil concerné — **Élèves**, **Enseignants**, **Personnel** ou **Tuteurs** — puis cliquez sur
**Ajouter un champ**.

<Screenshot
  label="Boîte de dialogue d'un champ personnalisé"
  caption="Définissez le profil, le type, le libellé et les options du champ."
/>
</Step>

<Step>
### Définir le champ

Complétez les options ci-dessous. Un **Aperçu en direct** montre le champ tel qu'il apparaîtra
sur le formulaire.

| Option | Remarques |
| --- | --- |
| **Type de champ** | **Texte**, **Paragraphe**, **Nombre**, **Date**, **Liste déroulante**, **Oui / Non**, **Email**, **Téléphone**, **URL**, **Bouton radio** ou **Case à cocher**. |
| **Libellé du champ** | Le nom du champ, affiché sur le formulaire. |
| **Texte d'aide** | Texte indicatif facultatif affiché dans le champ. |
| **Options** | Pour les champs **Liste déroulante**, **Bouton radio** et **Case à cocher** : les choix, séparés par des virgules. |
| **Requis** | Si activé, le champ doit être renseigné avant de pouvoir soumettre le formulaire. |
| **Actif** | Si désactivé, le champ est conservé mais n'apparaît plus sur les formulaires. |
| **Visible par** | Activez ou désactivez **Enseignant**, **Tuteur** et **Étudiant** pour choisir qui d'autre peut voir le champ. |
</Step>

<Step>
### Enregistrer

Cliquez sur **Créer**.
</Step>

</Steps>

<Callout title="Où apparaissent les champs personnalisés">
Un champ défini pour les *élèves* apparaît dans le formulaire élève ; un champ pour le
*personnel* apparaît dans le formulaire du personnel, et ainsi de suite. Les fiches existantes
reçoivent simplement le nouveau champ. Les modifications d'un champ s'appliquent à chaque
formulaire où il apparaît.
</Callout>
