---
title: Champs personnalisés
description: Ajoutez vos propres champs aux fiches des élèves, enseignants et tuteurs.
---

Les **champs personnalisés** permettent à votre école de collecter des informations
que la plateforme ne demande pas par défaut. Un champ personnalisé que vous définissez
apparaît sur le formulaire de la fiche — pour les élèves, les enseignants ou les
tuteurs — afin que chacun saisisse les mêmes détails supplémentaires.

<Callout title="Pour qui">
Les administrateurs qui adaptent les informations que l'école enregistre sur les
personnes.
</Callout>

## Ajouter un champ personnalisé

<Steps>

<Step>
### Ouvrir les paramètres Champs personnalisés

Allez dans **Paramètres → Établissement** et ouvrez l'onglet **Champs personnalisés**, puis choisissez **Ajouter un champ
personnalisé**.

<Screenshot
  label="Boîte de dialogue d'un champ personnalisé"
  caption="Définissez le profil, le type, le libellé et les options du champ."
/>
</Step>

<Step>
### Définir le champ

Complétez les options ci-dessous, puis enregistrez.

| Option | Remarques |
| --- | --- |
| **Profil** | La fiche sur laquelle le champ apparaît — élève, enseignant ou tuteur. |
| **Type de champ** | Le type de saisie — texte, zone de texte, nombre, date, e-mail, téléphone, URL, case à cocher, interrupteur, bouton radio ou liste. |
| **Libellé** | Le nom du champ, affiché sur le formulaire. |
| **Texte d'aide** | Texte indicatif facultatif affiché dans le champ. |
| **Options** | Pour les champs radio et liste, l'ensemble des choix proposés. |
| **Obligatoire** | Si activé, le champ doit être rempli avant d'enregistrer la fiche. |
| **Actif** | Si désactivé, le champ est conservé mais n'apparaît plus sur les formulaires. |
</Step>

</Steps>

<Callout title="Où apparaissent les champs personnalisés">
Un champ défini pour les *élèves* apparaît dans le formulaire élève ; un champ pour les
*enseignants* apparaît dans le formulaire enseignant, et ainsi de suite. Les fiches
existantes reçoivent simplement le nouveau champ.
</Callout>
