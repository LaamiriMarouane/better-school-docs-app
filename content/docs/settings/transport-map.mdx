The **Transport map appearance** settings control how the map looks everywhere transport routes
are shown — the style of the **stop markers**, the **school marker**, and the **route lines** that
join the stops. These are presentation choices; they don't change the routes themselves.

<Callout title="Who this is for">
Administrators who want the transport map to match how their school reads it best.
</Callout>

## Open the settings

Go to **Settings → School** and open the **Transport Map Appearance** tab. A live preview updates as you change each option, so
you can see the result before saving.

## Options

| Option | Choices | What it does |
| --- | --- | --- |
| **Stop marker style** | Numbered pin, Bus stop, Dot | How each route stop appears on the map. *Numbered pin* shows the stop's order. |
| **School marker style** | School building, Bus, Dot | How the school is shown on the map. |
| **Route line style** | Solid, Dashed | The style of the line that connects consecutive stops. |
| **Show route line** | On / off | Whether the connecting line between stops is drawn at all. |
| **Show stop labels** | On / off | Whether stop names are shown on the map. |

<Callout title="Where these apply">
These choices apply to **every** transport map in the app — when you build routes, view a route's
roster, or follow a trip. There's one set of map appearance settings per school.
</Callout>

## Common use cases

- **Cleaner map** — turn off stop labels and use dots for a less crowded view.
- **Sequence at a glance** — use numbered pins so the stop order is obvious.
- **Lines off** — hide the route line when you only care about stop positions.
