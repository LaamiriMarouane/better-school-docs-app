---
title: Custom fields
description: Add your own fields to student, teacher, and guardian records.
---

**Custom fields** let your school collect information the platform does not ask for by
default. A custom field you define appears on the record's form — for students,
teachers, or guardians — so everyone captures the same extra details.

<Callout title="Who this is for">
Administrators tailoring what information the school records about people.
</Callout>

## Add a custom field

<Steps>

<Step>
### Open the Custom Fields settings

Go to **Settings → Custom Fields**, then choose **Add custom field**.

<Screenshot
  label="Custom field dialog"
  caption="Define the field's profile, type, label, and options."
/>
</Step>

<Step>
### Define the field

Complete the options below, then save.

| Option | Notes |
| --- | --- |
| **Profile** | Which record the field appears on — student, teacher, or guardian. |
| **Field type** | The kind of input — text, text area, number, date, email, phone, URL, checkbox, toggle, radio, or select. |
| **Label** | The field's name, shown on the form. |
| **Placeholder** | Optional hint text shown inside the input. |
| **Options** | For radio and select fields, the list of choices to pick from. |
| **Required** | When on, the field must be filled before the record can be saved. |
| **Active** | When off, the field is kept but no longer shown on forms. |
</Step>

</Steps>

<Callout title="Where custom fields appear">
A field defined for *students* shows in the student form; one for *teachers* shows in
the teacher form, and so on. Existing records simply gain the new field.
</Callout>
