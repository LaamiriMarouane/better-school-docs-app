Votre compte est une **organisation**. Chaque établissement de l'organisation est un **campus**.
La plupart des groupes ont un seul campus ; un groupe de plusieurs établissements peut ajouter
d'autres campus et les gérer tous avec le **même abonnement**.

<Callout title="Pour qui">
Les administrateurs qui peuvent ajouter des campus. Les autres personnes ne voient pas cette page.
</Callout>

## Ouvrir Campus

Dans la barre latérale d'administration, allez dans **Paramètres → Campus**.

En haut, vous voyez combien de campus vous avez et combien votre forfait en permet (par exemple
*1 sur 3 campus*).

Le tableau liste tous les campus de votre organisation :

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Nom** | Le nom du campus. |
| **Ville** | Sa ville. |
| **Pays** | Son pays. |
| **Statut** | **Actif** indique le campus dans lequel vous travaillez en ce moment. |

## Ajouter un campus

<Steps>

<Step>
### Ouvrir le formulaire

Cliquez sur **Ajouter un campus**.
</Step>

<Step>
### Remplir les informations

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Nom du campus** | Oui | Par exemple *Campus centre-ville*. |
| **Pays** | Non | À choisir dans la liste. |
| **Ville** | Non | |
| **Fuseau horaire** | Non | À choisir dans la liste. |
</Step>

<Step>
### Le créer

Cliquez sur **Ajouter un campus**. Le nouveau campus apparaît dans le tableau. Vous êtes
administrateur du nouveau campus et pouvez donc y passer tout de suite.
</Step>

</Steps>

Un nouveau campus partage votre abonnement actuel. Il a sa propre configuration : configurez-le comme
votre premier établissement — profil de l'école, modules, année scolaire et personnes. Voir
[Première configuration de l'école](../getting-started/first-time-school-setup).

## Quand vous ne pouvez pas ajouter de campus

À la place de **Ajouter un campus**, la page affiche une carte qui explique pourquoi :

| Carte | Ce que cela signifie | Que faire |
| --- | --- | --- |
| **Les campus nécessitent un abonnement actif** | Pendant l'essai, ou sans abonnement actif, votre organisation a un seul campus. | Cliquez sur **Voir la facturation** pour vous abonner. |
| **Limite de campus atteinte** | Votre forfait ne permet pas d'autres campus. | Cliquez sur **Contacter les ventes** pour un contrat multi-campus, ou sur **Voir la facturation** pour changer de forfait. |

## Passer d'un campus à l'autre

Quand vous pouvez travailler dans plusieurs campus, un **sélecteur d'école** apparaît dans la barre
du haut (sur un ordinateur ou un grand écran). Choisissez un campus : la page se recharge dans ce
campus, et les menus, listes et paramètres sont désormais ceux de ce campus.

Choisir une année scolaire d'un autre campus dans le sélecteur d'année vous fait aussi passer à ce
campus.

<Callout title="Un seul compte pour toute l'organisation">
Chacun se connecte une seule fois pour toute l'organisation. Ce que chacun peut faire dépend des
rôles qu'il a dans chaque campus. Les rôles s'attribuent depuis la page
[Utilisateurs](./users) du campus dans lequel vous travaillez.
</Callout>
