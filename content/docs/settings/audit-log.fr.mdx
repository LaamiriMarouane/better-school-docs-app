Le **Journal d'audit** enregistre les actions effectuées dans votre établissement : qui les a
faites, quand, et sur quoi. Utilisez-le pour répondre à des questions comme *qui a modifié ce
paiement ?* ou *qui s'est connecté hier ?*

<Callout title="Pour qui">
Les administrateurs. Les autres personnes ne voient pas cette page.
</Callout>

## Ouvrir le Journal d'audit

Dans la barre latérale d'administration, allez dans **Paramètres → Journal d'audit**.

Les entrées les plus récentes sont en haut.

| Colonne | Ce qu'elle affiche |
| --- | --- |
| **Quand** | Date et heure de l'action, dans le fuseau horaire de votre école (indiqué à côté du nom de la colonne). |
| **Qui** | La personne qui l'a faite. |
| **Rôle** | Le rôle qu'elle utilisait. |
| **Action** | Ce qu'elle a fait — par exemple **Création**, **Modification**, **Suppression**, **Connexion**, **Échec de connexion**, **Réinitialisation du mot de passe**, **Approbation**, **Exporter** ou **Changement de permission**. |
| **Module** | Le domaine de la plateforme — par exemple **Finance**, **Inscriptions**, **Examens et notes**, **Présences et congés**, **Utilisateurs** ou **Paramètres**. |
| **Entité** | L'élément concerné (par exemple le nom d'un élève) et son type. |
| **Description** | Une courte phrase qui décrit ce qui s'est passé. |

## Rechercher et filtrer

- Utilisez la zone de recherche pour trouver des entrées par **e-mail, nom d'utilisateur, nom
  complet ou entité**.
- Ouvrez le filtre pour affiner la liste :
  - **Action** — un type d'action, ou **Toutes les actions**.
  - **Module** — un domaine, ou **Tous les modules**.
  - **Période** — **Choisir une période**.

  Cliquez sur **Appliquer**. Effacez les filtres pour tout revoir.

## Exporter

Cliquez sur **Exporter CSV** pour télécharger les entrées dans un fichier CSV que vous pouvez ouvrir
dans un tableur. L'export suit la recherche et les filtres appliqués : filtrez d'abord pour
n'exporter que ce dont vous avez besoin.

## Durée de conservation des entrées

Cliquez sur le bouton **Paramètres de rétention** (engrenage) à côté de **Exporter CSV**. Saisissez
la **Rétention (jours)** et cliquez sur **Enregistrer la rétention**. Les entrées plus anciennes sont
supprimées chaque nuit.
