**Feature requests** is where schools share product ideas, vote on what matters most, and follow
what is planned or released.

<Callout title="Who this is for">
Administrators suggesting improvements and tracking the roadmap.
</Callout>

<Callout title="Active subscription required">
Submitting requests, voting, and commenting need an **Active** paid subscription. Open
[Billing & Subscription](./billing-subscription) if you need to upgrade.
</Callout>

## Open Feature requests

From the admin sidebar (Settings group), go to **Requests**.

## Browse and vote

Use the tabs:

| Tab | What it shows |
| --- | --- |
| **All** | The full list — search and filter by category; sorted by votes. |
| **My votes** | Requests your school has voted for. |
| **Roadmap** | Columns for **Planned**, **In progress**, and **Released**. |

On a request, use the vote control to vote or remove your vote. Open a request to read the
description, any **Official response**, **Comments**, and **Status history**.

## Submit a request

<Steps>

<Step>
### New request

Click **New request**.
</Step>

<Step>
### Fill in the details

| Field | Required | Notes |
| --- | --- | --- |
| **Title** | Yes | Short name for the idea. |
| **Category** | Yes | e.g. Academics, Scheduling, Finance, HR, Grading, Enrollment, Mobile app, Other. |
| **Description** | Yes | What you want and why. |
</Step>

<Step>
### Submit

Click **Submit request**. It starts as **New** for the BetterSchool team to review.
</Step>

</Steps>

## Statuses

| Status | Meaning |
| --- | --- |
| **New** | Just submitted. |
| **Under review** | Being evaluated. |
| **Planned** | On the roadmap. |
| **In progress** | Being built. |
| **Released** | Available in the product. |
| **Declined** | Not going ahead. |

Schools do not change status — the BetterSchool team does. You can comment while your
subscription allows writes.
