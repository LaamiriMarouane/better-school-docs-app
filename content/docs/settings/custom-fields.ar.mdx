---
title: الحقول المخصّصة
description: أضِف حقولك الخاصة إلى سجلات الطلاب والمعلمين وأولياء الأمور.
---

**الحقول المخصّصة** تتيح لمدرستك جمع معلومات لا تطلبها المنصّة افتراضيًا. يظهر الحقل
المخصّص الذي تعرّفه في نموذج السجل — للطلاب أو المعلمين أو أولياء الأمور — بحيث يلتقط
الجميع التفاصيل الإضافية نفسها.

<Callout title="لمن هذا الدليل">
المسؤولون الذين يخصّصون المعلومات التي تسجّلها المدرسة عن الأشخاص.
</Callout>

## إضافة حقل مخصّص

<Steps>

<Step>
### افتح إعدادات الحقول المخصّصة

انتقل إلى **الإعدادات ← الحقول المخصّصة**، ثم اختر **إضافة حقل مخصّص**.

<Screenshot
  label="مربع حوار حقل مخصّص"
  caption="حدّد ملف الحقل ونوعه واسمه وخياراته."
/>
</Step>

<Step>
### عرّف الحقل

أكمل الخيارات أدناه ثم احفظ.

| الخيار | ملاحظات |
| --- | --- |
| **الملف** | السجل الذي يظهر فيه الحقل — طالب أو معلم أو وليّ أمر. |
| **نوع الحقل** | نوع الإدخال — نص، منطقة نص، رقم، تاريخ، بريد إلكتروني، هاتف، رابط، مربع اختيار، مفتاح تبديل، زر راديو، أو قائمة. |
| **الاسم** | اسم الحقل، المعروض في النموذج. |
| **نص مساعد** | نص إرشادي اختياري يظهر داخل الحقل. |
| **الخيارات** | لحقول الراديو والقائمة، مجموعة الخيارات المتاحة. |
| **إلزامي** | عند تفعيله، يجب ملء الحقل قبل حفظ السجل. |
| **نشط** | عند تعطيله، يُحتفَظ بالحقل لكنه لا يظهر في النماذج. |
</Step>

</Steps>

<Callout title="أين تظهر الحقول المخصّصة">
الحقل المعرّف لـ*الطلاب* يظهر في نموذج الطالب؛ والمعرّف لـ*المعلمين* يظهر في نموذج
المعلم، وهكذا. تكتسب السجلات الموجودة الحقل الجديد ببساطة.
</Callout>
