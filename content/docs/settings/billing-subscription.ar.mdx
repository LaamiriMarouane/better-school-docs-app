**الفواتير والاشتراك** هو المكان الذي تدير فيه **خطة SaaS** للمدرسة مع BetterSchool —
حالة التجربة، واستخدام التسجيلات، والترقية، والتخفيض، والإلغاء. هذا **ليس** نفسه فوترة رسوم
المدرسة (جداول الأقساط للعائلات).

## افتح الفواتير والاشتراك

من الشريط الجانبي للإدارة (مجموعة الإعدادات)، انتقل إلى **الفواتير والاشتراك**.

## ما تراه

### الخطة الحالية

يعرض الجانب الأيسر:

| العنصر | ملاحظات |
| --- | --- |
| **الخطة** | تجربة مجانية، أو مستوى مدفوع (Starter، Growth، Standard، Enterprise). |
| **الحالة** | تجريبي، نشط، متأخر، موقوف، أو ملغى. |
| **تنتهي التجربة** / **الفاتورة القادمة** | حسب ما إذا كنت في تجربة أو على خطة مدفوعة. |
| **دورة الفوترة** | شهري أو سنوي (عند وجود خطة مدفوعة). |
| **الاستخدام** | التسجيلات النشطة مقابل حد الخطة (غير محدود أثناء التجربة أو على الخطط غير المحدودة). |

إذا كان تغيير مجدولًا بالفعل (إلغاء أو إيقاف أو استئناف)، يظهر إشعار بالتاريخ.

### اختر خطة

على اليمين، اختر **شهري** أو **سنوي**، ثم اختر خطة:

| الإجراء | متى يظهر |
| --- | --- |
| **اشترك** / **اختر خطة** | لا توجد خطة مدفوعة بعد، أو ما زلت في التجربة. |
| **ترقية** | الانتقال إلى مستوى أعلى أثناء كون الحالة نشط أو متأخر. |
| **تخفيض** | الانتقال إلى مستوى أدنى (معطّل إذا تجاوزت تسجيلاتك حد تلك الخطة). |
| **اتصل بالمبيعات** | احتياجات Enterprise / مخصّصة. |
| **الحالي** | التسمية على الخطة التي لديك بالفعل. |

## الترقية أو التخفيض أو الاشتراك

<Steps>

<Step>
### اختر الدورة والخطة

حدّد **شهري** أو **سنوي**، ثم إجراء الخطة (**ترقية**، **تخفيض**، **اشترك**، أو **اختر خطة**).
</Step>

<Step>
### أكّد أو ادفع

- إذا كان لديك بالفعل اشتراك **نشط** أو **متأخر**، أكّد التغيير في مربع الحوار.
- وإلا تنتقل إلى **الدفع** لدفع الخطة والدورة المختارتين (Paddle). عند نجاح الدفع، تعود إلى
  التطبيق بالاشتراك المحدَّث.
</Step>

</Steps>

## إلغاء اشتراك

عندما تكون الحالة **نشط** أو **متأخر** ولا يوجد تغيير مجدول بالفعل، استخدم **إلغاء الاشتراك**
وأكّد. قد تعرض الواجهة بعد ذلك تاريخ إلغاء مجدولًا إن وُجد.
