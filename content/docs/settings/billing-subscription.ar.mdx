**الفواتير والاشتراك** هو المكان الذي تدير فيه **اشتراك** مدرستك — حالة التجربة، واستخدام
التسجيلات، والترقية، والتخفيض، والفواتير، والإلغاء. هذا **ليس** نفسه فوترة رسوم المدرسة (جداول
الأقساط للعائلات).

<Callout title="فوترتان مختلفتان">
| المكان | ما الذي يتحكّم فيه |
| --- | --- |
| الشريط الجانبي ← **الفواتير والاشتراك** | اشتراك مدرستك واستخدامه. |
| **الإعدادات ← المالية ← الفوترة** | كيفية توقيت أقساط رسوم الطلاب. انظر [إعداد الفوترة](./billing-configuration). |
</Callout>

<Callout title="لمن هذا الدليل">
المسؤولون الذين يديرون اشتراك المدرسة. ويمكن للموظفين الذين مُنحوا الصلاحية فتحه أيضًا.
</Callout>

## افتح الفواتير والاشتراك

من الشريط الجانبي للإدارة (مجموعة الإعدادات)، انتقل إلى **الفواتير والاشتراك**.

## ما تراه

### الخطة الحالية

| العنصر | ملاحظات |
| --- | --- |
| **الخطة** | **تجربة مجانية**، أو خطة مدفوعة (**الأساسي**، **النمو**، **القياسي**، **المؤسسات**). |
| **الحالة** | **تجريبي**، **نشط**، **متأخر**، **موقوف**، أو **ملغى**. |
| **تنتهي التجربة** / **الفاتورة القادمة** | حسب ما إذا كنت في تجربة أو على خطة مدفوعة. |
| **دورة الفوترة** | **شهري** أو **سنوي** (عند وجود خطة مدفوعة). |
| **التسجيلات** | التسجيلات النشطة مقابل حد الخطة (غير محدود أثناء التجربة أو على الخطط غير المحدودة). |

إذا كان تغيير مجدولًا بالفعل (إلغاء أو تخفيض)، يظهر إشعار بالتاريخ.

### اختر خطة

في قائمة الخطط، اختر **شهري** أو **سنوي**، ثم اختر خطة:

| الإجراء | متى يظهر |
| --- | --- |
| **اشترك** / **اختر خطة** | لا توجد خطة مدفوعة بعد، أو ما زلت في التجربة. |
| **ترقية** | الانتقال إلى خطة أعلى أثناء كون الحالة نشط أو متأخر. |
| **تخفيض** | الانتقال إلى خطة أدنى (غير متاح إذا تجاوزت تسجيلاتك حد تلك الخطة). |
| **اتصل بالمبيعات** | احتياجات المؤسسات أو الاحتياجات المخصّصة. |
| **الحالي** | التسمية على الخطة التي لديك بالفعل. |
| **مجدول** | التسمية على تخفيض ينتظر تاريخ الفوترة القادم. |

## الترقية أو التخفيض أو الاشتراك

<Steps>

<Step>
### اختر الدورة والخطة

حدّد **شهري** أو **سنوي**، ثم إجراء الخطة (**ترقية**، **تخفيض**، **اشترك**، أو **اختر خطة**).
</Step>

<Step>
### أكّد أو ادفع

- تسري **الترقية** فورًا. تُفوتَر الآن عمّا تبقّى من الفترة الحالية.
- يسري **التخفيض** في تاريخ الفوترة القادم. تبقى على خطتك الحالية حتى ذلك الحين.
- إذا لم تكن لديك خطة مدفوعة بعد، تنتقل إلى صفحة الدفع لدفع الخطة والدورة المختارتين عبر Paddle،
  مزوّد الدفع لدينا. عند نجاح الدفع، تعود إلى التطبيق بالاشتراك المحدَّث.
</Step>

</Steps>

## الفواتير

تعرض قائمة **الفواتير** كل فاتورة بمبلغها وحالتها. استخدم **تنزيل** للحصول على نسخة.

## تحديث طريقة الدفع

استخدم **تحديث طريقة الدفع** لتغيير البطاقة التي تدفع بها. إذا فشلت دفعة، يظهر إشعار **فشل
الدفع** مع الزر نفسه: حدّث طريقة الدفع وستُعاد محاولة الدفعة المتأخرة تلقائيًا.

## إلغاء اشتراك

عندما تكون الحالة **نشط** أو **متأخر** ولا يوجد تغيير مجدول بالفعل، استخدم **إلغاء الاشتراك**
وأكّد. تعرض الصفحة بعد ذلك تاريخ سريان الإلغاء.
