Un **trajet** est une exécution d'un itinéraire un jour donné — par exemple *Ligne Nord — Matin,
le lundi*. Les trajets sont créés **automatiquement**. Vous n'ajoutez un trajet à la main que pour
les exceptions, comme un jour de rattrapage ou un trajet supplémentaire.

<Callout title="Pour qui">
Les administrateurs et les coordinateurs de transport qui supervisent les opérations
quotidiennes du bus.
</Callout>

## Comment les trajets quotidiens apparaissent

Vous n'ajoutez pas les trajets un par un :

- Un trajet est créé pour chaque **itinéraire actif** chaque **jour d'école**. Les jours fériés et
  les fermetures de l'école sont ignorés.
- Chaque trajet démarre avec le **véhicule et l'équipage par défaut** de l'itinéraire, ses
  **arrêts** et les **élèves** qui y sont affectés. Un trajet passé garde ces informations telles
  qu'elles étaient ce jour-là, même si vous modifiez l'itinéraire ensuite.
- Il n'y a qu'**un seul trajet par itinéraire et par jour** — jamais de doublon.

<Callout title="Ce qu'il faut pour que les trajets apparaissent">
Un itinéraire n'a de trajets que s'il est **actif** et possède des **arrêts** (et généralement des
élèves). Vérifiez que l'itinéraire est configuré avant d'attendre ses trajets.
</Callout>

## Trouver un trajet

Allez dans **Opérations → Voyages**. La page comporte trois onglets :

| Onglet | Ce qu'il affiche |
| --- | --- |
| **En cours** | Les trajets qui roulent en ce moment. |
| **Planifiés** | Les trajets qui attendent de démarrer. |
| **Terminés** | Les trajets terminés. |

Filtrez par date et par itinéraire, et passez de la vue **Cartes** à la vue **Compact**.
Sélectionnez un trajet pour ouvrir ses détails à côté de la liste, ou **Ouvrir en plein écran**.

## Créer un trajet à la main

Utilisez-le pour un jour qui n'aurait normalement pas de trajet — un samedi de rattrapage, un jour
d'examen ou une sortie.

<Steps>

<Step>
### Ouvrir les voyages

Allez dans **Opérations → Voyages**, puis cliquez sur **Ajouter un trajet**.

<Screenshot
  label="Page des trajets avec le bouton Ajouter un trajet"
  caption="Les trajets sont affichés sur un calendrier et une liste. Filtrez par itinéraire, chauffeur ou statut."
/>
</Step>

<Step>
### Renseigner le trajet

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Itinéraire** | Oui | L'itinéraire à exécuter. Ses arrêts et ses élèves sont copiés sur le trajet. |
| **Date de service** | Oui | Le jour du trajet. |
| **Heure de départ prévue** | Non | L'heure de départ prévue du bus. |
| **Véhicule** | Non | Remplace le véhicule par défaut pour ce trajet uniquement. |
| **Chauffeur** | Non | Remplace le chauffeur par défaut pour ce trajet uniquement. |
| **Accompagnateur** | Non | Remplace l'accompagnateur par défaut pour ce trajet uniquement. |

Un véhicule ou un membre d'équipage déjà pris sur un autre trajet à ce moment-là est marqué
**Occupé**, pour que vous puissiez choisir quelqu'un d'autre.
</Step>

<Step>
### Créer

Cliquez sur **Créer**. Le trajet apparaît sous **Planifiés**, prêt à être démarré par l'équipage.
</Step>

</Steps>

<Callout title="Un seul trajet par itinéraire et par jour">
Vous ne pouvez pas créer un second trajet pour le même itinéraire le même jour. Si un trajet
existe déjà, ouvrez-le.
</Callout>

## Déroulement d'un trajet

En général, l'équipage gère le trajet depuis sa propre page **Trajets** (voir
[Présence aux trajets](./trip-attendance)) :

1. **Démarrer** — le chauffeur ou l'accompagnateur démarre le trajet le jour prévu. Il passe sous
   **En cours**. Un trajet doit avoir un chauffeur ou un accompagnateur pour démarrer.
2. **Marquer les élèves** — à chaque arrêt, l'équipage marque qui est monté ou a été déposé.
3. **Terminer** — le trajet se termine tout seul quand chaque élève est marqué et chaque arrêt
   validé, ou quand l'équipage appuie sur **Terminer le voyage**. Un trajet de dépose ne peut pas
   se terminer tant qu'un élève est encore à bord. Si le bus ne peut pas finir l'itinéraire,
   l'équipage peut utiliser **Terminer le voyage (urgence)**.

Si un trajet reste en cours après sa journée, il est clôturé automatiquement et tout élève encore
non marqué est enregistré comme **Absence**. Un trajet qui n'a jamais démarré reste sous
**Planifiés** jusqu'à ce qu'un administrateur l'annule.

## Gérer un trajet depuis le bureau

Ouvrez un trajet et utilisez son menu **⋯** :

| Action | Quand |
| --- | --- |
| **Démarrer le voyage** | Sur un trajet planifié, le jour prévu — par exemple si l'équipage ne peut pas le démarrer lui-même. |
| **Terminer le voyage** | Sur un trajet en cours, pour le clôturer à la main. Les élèves non marqués sont enregistrés comme **Absence**. |
| **Changer l'équipe** | Remplacer le chauffeur, l'accompagnateur ou le véhicule pour ce trajet uniquement. Les personnes ou véhicules déjà occupés sont signalés. Les valeurs par défaut de l'itinéraire ne changent pas : le trajet suivant retrouve l'équipage habituel. |
| **Annuler le voyage** | Le trajet n'aura pas lieu. Indiquez un **Motif**. Les parents sont prévenus que le bus ne circule pas aujourd'hui, et la présence déjà marquée est conservée. Un trajet annulé ne peut pas être redémarré. |

Seuls les administrateurs peuvent changer l'équipage ; les chauffeurs et les accompagnateurs ne le
peuvent pas.

## Cas d'usage courants

- **Journée normale** — rien à faire ; les trajets apparaissent automatiquement.
- **Samedi de rattrapage** — ajoutez un trajet à la main pour cette date.
- **Chauffeur malade** — utilisez **Changer l'équipe** sur les trajets concernés.
- **Jour de neige** — annulez les trajets du jour avec un motif.
