**المركبة** هي أي حافلة أو حافلة صغيرة أو سيارة تستعملها مدرستك للنقل. تسجّل كل مركبة مرة
واحدة، فتصبح متاحة للإسناد إلى المسارات والرحلات. والأسطول هو أيضًا المكان الذي تحتفظ فيه بسجلّ
تكاليف كل مركبة — الوقود والصيانة والتأمين والفحوص.

<Callout title="لمن هذا الدليل">
المسؤولون ومنسّقو النقل الذين يديرون أسطول المدرسة.
</Callout>

## قبل أن تبدأ

- يجب تفعيل وحدة **النقل**.
- جهّز بيانات كل مركبة: رقم التسجيل (اللوحة)، والعلامة التجارية والطراز، ونوع الوقود، وعدد
  المقاعد، وقراءة العدّاد.

## إضافة مركبة

<Steps>

<Step>
### افتح الأسطول

انتقل إلى **العمليات** ← **المركبات**، ثم انقر **إضافة مركبة**.

<Screenshot
  label="قائمة المركبات مع زر إضافة مركبة"
  caption="تُعرض هنا كل مركبة في أسطولك."
/>
</Step>

<Step>
### املأ بيانات المركبة

كل الحقول مطلوبة. املأها ثم انقر **إرسال**.

| الحقل | ملاحظات |
| --- | --- |
| **رقم التسجيل** | رقم اللوحة الذي يميّز المركبة. |
| **النوع** | نوع المركبة، مثل *حافلة* أو *حافلة صغيرة* أو *سيارة*. |
| **العلامة التجارية** | الشركة المصنّعة، مثل *مرسيدس* أو *تويوتا*. |
| **الطراز** | اسم الطراز. |
| **نوع الوقود** | نوع الوقود الذي تعمل به المركبة. |
| **عدد الكيلومترات الأولي** | قراءة العدّاد عند بدء تتبّع المركبة. |
| **عدد الكيلومترات الحالي** | آخر قراءة للعدّاد. |
| **المقاعد** | عدد الركاب الذين تتّسع لهم المركبة. يظهر بجانب المركبة في المسارات كمرجع للسعة. |
</Step>

<Step>
### كرّر لكل مركبة

أضف كل حافلة وسيارة في أسطولك. تصبح متاحة للاختيار عند بناء المسارات وعند تغيير طاقم رحلة.
</Step>

</Steps>

<Callout title="إضافة عدة مركبات دفعة واحدة">
انقر **استيراد** لإضافة عدة مركبات من ملف جدول بيانات بدل إدخالها واحدة تلو الأخرى.
</Callout>

## تتبّع تكاليف مركبة

افتح مركبة (**عرض التفاصيل** من قائمة صفّها) لترى تبويبات التكاليف التي يمكنك تسجيلها:

| التبويب | ما يتتبّعه |
| --- | --- |
| **الوقود** | كل تعبئة وتكلفتها. |
| **الصيانة** | سجلّات الخدمة والإصلاح. |
| **التأمين** | وثائق التأمين وتواريخ انتهائها. |
| **ملصق السيارة** | ضريبة الطريق / الملصق وتجديده. |
| **الفحص الفني** | فحوص صلاحية السير وتواريخ انتهائها. |

<Callout title="نصيحة">
تسجيل تواريخ التأمين والملصق والفحص الفني يتيح تذكير المدرسة قبل انتهاء وثائق المركبة، حتى
لا تسير أي حافلة بدون وثائق صالحة.
</Callout>

## إيقاف مركبة عن الخدمة

لإيقاف مركبة عن الخدمة، افتح قائمة صفّها واختر **إلغاء التفعيل**. تبقى المركبة في سجلّاتك وفي
الرحلات السابقة، لكنها لا تظهر عند اختيار مركبة لمسار أو رحلة. اختر **تفعيل** لإعادتها. هذا أكثر
أمانًا من الحذف الذي يمحو سجلّ تكاليفها.

## حالات استخدام شائعة

- **وصول حافلة جديدة** — أضفها إلى الأسطول لتتمكّن من إسنادها إلى مسار.
- **بيع حافلة أو تخريدها** — ألغِ تفعيلها لتحتفظ بسجلّها مع إخفائها من الإسنادات الجديدة.
- **متابعة التكاليف** — سجّل كل تعبئة وكل صيانة لتعرف تكلفة تشغيل كل مركبة.
