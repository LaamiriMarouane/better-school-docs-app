---
title: Create payment plans
description: Bundle fees into a payment plan that can be attached to a student's enrollment.
---

A **payment plan** bundles one or more **fees** for a **level**. It is the thing you
attach to an enrollment — once attached, the student's installments are generated from
the plan's fees.

<Callout title="Who this is for">
Administrators packaging fees into the plans students are billed under.
</Callout>

## Before you start

- The **fees** must already exist for the level — see [Set up fees](./set-up-fees).
- An **academic year** must be selected.

/>

## Steps

<Steps>

<Step>
### Open the Payment Plans page

Go to **Finance → Payment Plans**, then start a new plan.

<Screenshot
  label="Create payment plan form"
  caption="The plan form: name, level, type, conditions and fees."
/>
</Step>

<Step>
### Choose the level

Pick the **level** first. The list of fees you can add is filtered to that level.
</Step>

<Step>
### Fill in the plan details

Complete the fields below, then click **Create Payment Plan**.

| Field | Required | Notes |
| --- | --- | --- |
| **Name** | Yes | The display name, e.g. *Grade 1 — Full plan*. |
| **Level** | Yes | The level the plan is for. Determines which fees are available. |
| **Plan type** | Yes | The category of plan (for example academic). |
| **Conditions** | No | Optional notes or terms shown with the plan. |
| **Fees** | Yes | One or more fees to include. Select a level first to populate this list. |
</Step>

<Step>
### Save the plan

The plan is now available to attach when you create an enrollment or enroll students
in bulk.
</Step>

</Steps>

<Callout title="What comes next">
Attaching a plan to an enrollment generates the student's installments — see
[Installments and schedules](./installments-and-schedules).
</Callout>
