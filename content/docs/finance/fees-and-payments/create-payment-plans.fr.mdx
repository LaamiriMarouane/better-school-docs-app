---
title: Créer des échéanciers
description: Regroupez des frais dans un échéancier de paiement pouvant être associé à l'inscription d'un élève.
---

Un **échéancier de paiement** regroupe un ou plusieurs **frais** pour un **niveau**.
C'est ce que vous associez à une inscription — une fois associé, les échéances de
l'élève sont générées à partir des frais de l'échéancier.

<Callout title="Pour qui">
Les administrateurs qui regroupent les frais dans les échéanciers de facturation des
élèves.
</Callout>

## Avant de commencer

- Les **frais** doivent déjà exister pour le niveau — voir [Configurer les frais](./set-up-fees).
- Une **année scolaire** doit être sélectionnée.

<Screenshot
  label="Page des échéanciers avec le bouton Ajouter un échéancier"
  caption="Les échéanciers regroupent les frais d'un niveau."
/>

## Étapes

<Steps>

<Step>
### Ouvrir la page Échéanciers

Allez dans **Finance → Échéanciers**, puis démarrez un nouvel échéancier.

<Screenshot
  label="Formulaire de création d'un échéancier"
  caption="Le formulaire : nom, niveau, type, conditions et frais."
/>
</Step>

<Step>
### Choisir le niveau

Choisissez d'abord le **niveau**. La liste des frais que vous pouvez ajouter est
filtrée sur ce niveau.
</Step>

<Step>
### Renseigner les détails de l'échéancier

Complétez les champs ci-dessous, puis cliquez sur **Créer l'échéancier**.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Nom** | Oui | Le nom affiché, ex. *1re année — Échéancier complet*. |
| **Niveau** | Oui | Le niveau concerné. Détermine les frais disponibles. |
| **Type d'échéancier** | Oui | La catégorie d'échéancier (par exemple académique). |
| **Conditions** | Non | Notes ou conditions facultatives affichées avec l'échéancier. |
| **Frais** | Oui | Un ou plusieurs frais à inclure. Choisissez d'abord un niveau pour remplir cette liste. |
</Step>

<Step>
### Enregistrer l'échéancier

L'échéancier est désormais disponible pour être associé lors de la création d'une
inscription ou d'une inscription en masse.
</Step>

</Steps>

<Callout title="Et ensuite">
Associer un échéancier à une inscription génère les échéances de l'élève — voir
[Échéances et calendriers](./installments-and-schedules).
</Callout>
