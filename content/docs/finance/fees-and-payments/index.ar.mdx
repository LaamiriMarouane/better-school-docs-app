title: الرسوم والمدفوعات

تحوّل منطقة المالية ما تتقاضاه مدرستك إلى مبالغ مستحقّة على الطلاب ومدفوعات تحصّلها.
وهي مبنيّة من عدّة أجزاء يتراكب بعضها فوق بعض:

| الجزء | ما هو |
| --- | --- |
| **الخدمة** | شيء توفّره المدرسة — الدراسة، النقل، المقصف، الزي المدرسي. |
| **الرسم** | مبلغ يُفوتَر مقابل خدمة: مبلغ واحد للمستويات المختارة (**ثابت**) أو مبلغ لكل مستوى (**حسب المستوى**)، بدورية محدّدة. |
| **خطة الدفع** | حزمة من الرسوم لمستوى واحد أو أكثر. كل رسم إلزامي أو اختياري. |
| **القسط** | جزء مجدوَل ممّا يدين به الطالب، له تاريخ استحقاق. |
| **الدفعة** | مال يُحصَّل مقابل قسط واحد أو أكثر. |
| **قاعدة التخفيض** | خصم قابل لإعادة الاستخدام يُعيَّن للطلاب (نسبة أو مبلغ ثابت). |

## كيف يترابط كل ذلك

<Steps>

<Step>
### إنشاء الخدمات

حدّد ما توفّره المدرسة — راجع [إنشاء الخدمات](./create-services).
</Step>

<Step>
### إعداد الرسوم

حدّد سعر كل خدمة ووتيرة فوترتها — راجع [إعداد الرسوم](./set-up-fees).
</Step>

<Step>
### إنشاء خطط الدفع

اجمع الرسوم في خطة لمستوياتك — راجع [إنشاء خطط الدفع](./create-payment-plans).
</Step>

<Step>
### ضبط قواعد التخفيض (اختياري)

عرّف خصومات قابلة لإعادة الاستخدام وعيّنها للطلاب — راجع
[قواعد التخفيض](./reduction-rules).
</Step>

<Step>
### أرفِق خطة عند التسجيل

عند تسجيل طالب بخطة، تُنشأ **أقساطه** — راجع
[الأقساط والجداول](./installments-and-schedules).
</Step>

<Step>
### حصّل المدفوعات

سجّل المدفوعات في **مركز الدفع** (افتحه من **المالية ← المدفوعات**) — راجع
[تسجيل دفعة](./record-a-payment). اعكس واحدة بـ
[استرداد دفعة](./refund-a-payment).
</Step>

</Steps>

<Callout title="اختر السنة الصحيحة">
اختر السنة الدراسية أعلى الشاشة قبل إعداد الخدمات والرسوم والخطط.
</Callout>
