---
title: Create expense categories
description: Set up the categories that expenses are filed under, with optional parent categories.
---

An **expense category** is how spending is organised — *Utilities*, *Maintenance*,
*Supplies*, and so on. Every expense is filed under a category, so set these up first.
Categories can be **nested** under a parent for a tidy hierarchy.

<Callout title="Who this is for">
Administrators organising how the school's spending is tracked.
</Callout>

## Before you start

- Decide on a short list of categories that match how you want to read your spending
  (for example *Utilities*, *Supplies*, *Maintenance*).

<Screenshot
  label="Expense categories tab"
  caption="Categories are managed from the Categories tab of the Expenses area."
/>

## Steps

<Steps>

<Step>
### Open the Categories tab

Go to **Finance → Expenses**, open the **Categories** tab, then click **Add Category**.

<Screenshot
  label="Create expense category form"
  caption="The form: name, parent category and description."
/>
</Step>

<Step>
### Fill in the category details

Complete the fields below, then click **Submit**.

| Field | Required | Notes |
| --- | --- | --- |
| **Name** | Yes | The display name, e.g. *Utilities*. |
| **Parent Category** | No | Nest this category under another. Leave as *None* for a top-level category. |
| **Description** | No | Optional notes. |
</Step>

<Step>
### Repeat to build the hierarchy

Add top-level categories first, then nest sub-categories under them as needed.
</Step>

</Steps>

<Callout title="Tip">
A category cannot be its own parent, and deep nesting gets hard to read — one or two
levels is usually enough.
</Callout>

## Retire a category

Use **Delete** on a category you no longer need. If expenses are still filed under it, the
category is archived instead, so those expenses keep their category. Turn on **Show
archived** to see archived categories, and use **Reactivate** to bring one back.
