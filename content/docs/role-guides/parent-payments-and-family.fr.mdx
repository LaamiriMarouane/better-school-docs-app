Cette page couvre le côté familial de la vie scolaire : l'argent, les trajets de votre enfant
vers l'école et depuis l'école, et les échanges avec l'école.

## Paiements

Ouvrez **Paiements** sur le web, ou **Frais et paiements** dans l'application mobile.

<Steps>

<Step>
### Choisissez un enfant

Sur le web, utilisez les boutons d'enfant en haut de la page, ou **Tous** pour voir tous vos
enfants ensemble. Dans l'application mobile, la page affiche l'enfant sélectionné dans la barre
du haut.
</Step>

<Step>
### Lisez les totaux

Quatre tuiles résument l'année : **Total des frais**, **Payé**, **À venir** et **En retard**.
S'il reste un montant dû d'une année précédente, **Reste dû des années précédentes** apparaît
en dessous.
</Step>

<Step>
### Parcourez les échéances

Chaque échéance indique sa description, sa date, son montant, ce qui est payé et ce qui reste
(**Restant** sur le web, **Reste à payer** dans l'application mobile), avec son statut de
paiement et si elle est **En retard**, **Bientôt dû** ou **À temps**. Utilisez le filtre (web)
ou les puces (mobile) pour n'afficher, par exemple, que les échéances non payées ou en retard.
</Step>

<Step>
### Téléchargez un reçu

Quand une échéance a été payée, son numéro de reçu apparaît.

- **Web** — cliquez sur le numéro de reçu dans la colonne **Reçu** pour le télécharger.
- **Application mobile** — touchez **Reçu** sur l'échéance, puis enregistrez, envoyez ou
  imprimez-le depuis le menu de partage de votre téléphone.

</Step>

</Steps>

<Callout title="Régler l'école">
Il n'y a pas de paiement en ligne dans l'application. Réglez l'école de la manière qu'elle vous
indique ; une fois votre paiement enregistré par l'école, il apparaît ici comme payé, avec son
reçu.
</Callout>

## Bus scolaire

Si votre école propose un service de bus, ouvrez **Le bus de mon enfant** sur le web ou **Bus
scolaire** dans l'application mobile. Pendant un trajet, chaque enfant dans le bus a une carte
avec un plan (l'école, votre arrêt et le bus) et l'état de l'enfant, par exemple **En attente
du bus** ou **Déposé**. Vous recevez aussi une notification quand votre enfant monte, est déposé
ou n'est pas monté. Voir [Suivi en direct](../transport/live-tracking).

## Récupérer votre enfant

Si votre école utilise la récupération à la porte, ouvrez **Récupération** sur le web ou
**Sortie** dans l'application mobile.

<Steps>

<Step>
### Prévenez l'école que vous êtes là

À votre arrivée, choisissez les enfants que vous récupérez (**Qui venez-vous chercher ?** sur le
web, **Qui est récupéré ?** dans l'application mobile). Si l'école a plusieurs portes,
choisissez-en une (**Choisir une porte**). Touchez ensuite **Je suis là**.
</Step>

<Step>
### Suivez votre enfant

Chaque arrivée indique votre numéro dans la file et son état : **En attente de libération**,
puis **En route**, puis **Remis**.
</Step>

<Step>
### Annulez si besoin

Tant que l'état est **En attente de libération**, vous pouvez annuler l'arrivée (**Annuler
l'arrivée**).
</Step>

</Steps>

Pour un enfant qui prend le bus ce jour-là, vous ne pouvez pas signaler votre arrivée de cette
façon — l'écran vous invite à contacter l'école pour le récupérer à la porte. Voir [Récupérer votre enfant](../dismissal/parent-pickup).

## Confirmer la réinscription

Avant une nouvelle année scolaire, l'école peut vous demander si votre enfant revient. Une carte
apparaît en haut de votre **Tableau de bord** (web) ou de l'**Accueil** (application mobile) :
**Réinscription de** votre enfant **pour** l'année suivante, parfois avec le niveau visé.

<Steps>

<Step>
### Choisissez Confirmer ou Refuser

Touchez **Confirmer** si votre enfant revient, ou **Refuser** sinon.
</Step>

<Step>
### Validez votre réponse

Un message rappelle ce que vous indiquez à l'école. Validez pour l'envoyer. **Cette réponse est
définitive** — pour la changer ensuite, contactez l'école.
</Step>

</Steps>

La carte disparaît une fois que vous avez répondu.

## Remplir des formulaires (web)

Quand l'école partage un formulaire avec vous — un sondage, une autorisation, un formulaire
d'inscription —, il apparaît sous **Communication** → **Formulaires** sur le web (**Mes
formulaires**). Chaque formulaire indique sa date de clôture (**Clôture le**). Choisissez
**Ouvrir**, remplissez-le et envoyez-le ; un message **Merci !** le confirme. Un formulaire
auquel vous avez déjà répondu est marqué **Répondu**.

Les formulaires se remplissent sur le web ; l'application mobile ne les affiche pas.

## Rester en contact avec l'école

| Quoi | Où | Ce que vous pouvez faire |
| --- | --- | --- |
| **Annonces** | Web : **Communication** → **Annonces**. Mobile : **Annonces**. | Lire les nouvelles de l'école et ouvrir leurs pièces jointes. Voir [Annonces](../communication/announcements). |
| **Événements** | Web : **Communication** → **Événements**. Mobile : **Événements**. | Voir les événements de l'école sur un calendrier. Voir [Événements](../communication/events). |
| **Messages** | Web : **Communication** → **Messages**. Mobile : **Messages**. | Écrire aux enseignants de votre enfant. Lancez une conversation avec **Nouveau message** (web) ou le bouton **+** (application mobile), puis recherchez un enseignant. Voir [Messages](../communication/messaging). |
| **Notifications** | Web : la cloche et **Communication** → **Notifications**. Mobile : **Notifications**, plus les notifications push sur votre téléphone. | Voir les nouveautés — devoirs, notes, paiements, bus, récupération, événements — et les marquer comme lues. Voir [Notifications](../communication/notifications). |
| **Réclamations** | Web : **Communication** → **Réclamations**. Mobile : **Réclamations**. | Envoyer une réclamation à l'école au sujet de l'enfant sélectionné. |

### Envoyer une réclamation

<Steps>

<Step>
### Créez-en une

Choisissez **Nouvelle réclamation** (dans l'application mobile, le bouton **+**).
</Step>

<Step>
### Décrivez le problème

Choisissez le **Type** (**Problème de note**, **Problème de frais** ou **Général**), puis
rédigez un **Titre** et une **Description**. Choisissez **Envoyer**.
</Step>

<Step>
### Suivez-la

Votre réclamation passe par **En attente**, puis **En cours**, et enfin **Résolue** ou
**Rejetée**. Ouvrez-la pour lire la **Note de résolution** de l'école.
</Step>

</Steps>

Voir [Réclamations](../communication/reclamations).
