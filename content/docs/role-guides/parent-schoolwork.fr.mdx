Tout ce qui figure sur cette page concerne l'enfant sélectionné. Pour consulter un autre enfant,
changez d'abord d'enfant — voir [Choisir l'enfant que vous consultez](./parent-guide#choisir-lenfant-que-vous-consultez).
Vous pouvez tout consulter, mais seul votre enfant peut rendre un travail ou passer un quiz.

## Emploi du temps

Ouvrez **Emploi du temps** (web : **Académique** → **Emploi du temps** ; mobile : menu →
**Emploi du temps**).

- **Web** — une vue semaine sur un grand écran, une vue jour sur un petit. Chaque cours indique
  la matière, l'enseignant et la salle.
- **Application mobile** — un jour à la fois. Utilisez les flèches pour changer de jour, ou
  touchez la date pour en choisir une. Un badge signale les cours **En cours**, **Terminée** ou
  **Annulée**.

Les cours du jour apparaissent aussi sur votre tableau de bord.

## Présence

| Où | Comment l'ouvrir | Ce que vous voyez |
| --- | --- | --- |
| **Web** | Sur le **Tableau de bord**, carte **Présence** → **Voir tout**. | La liste des présences de votre enfant avec leur statut. Utilisez le filtre pour affiner par date ou par statut. |
| **Application mobile** | Menu → **Présence**. | Les totaux du mois (**Présents**, **Absents**, **En retard**, **Demi-journée**, **Congé** et le **Taux global**) au-dessus d'un calendrier. Touchez un jour pour ouvrir son **Détail du jour**. |

La présence est en lecture seule. Si un relevé vous semble faux, contactez l'école, par exemple
via les [Messages](../communication/messaging).

## Cours et leçons

Ouvrez **Cours** (web : **Académique** → **Cours** ; mobile : menu → **Cours**).

<Steps>

<Step>
### Choisissez une matière

Vous voyez les matières de votre enfant pour l'année, chacune avec son nombre de leçons.
Recherchez par nom, ou choisissez un trimestre (ou **Tous les trimestres**).
</Step>

<Step>
### Ouvrez une leçon

Ouvrez une matière pour voir ses leçons, puis choisissez une leçon pour lire le contenu partagé
par l'enseignant. Dans l'application mobile, les leçons sont regroupées par chapitre.
</Step>

<Step>
### Ouvrez les pièces jointes et les tableaux (web)

Sur le web, une leçon peut aussi avoir des **Pièces jointes** à ouvrir et des **Tableaux** — des
tableaux blancs liés à la leçon par l'enseignant. En tant que parent, vous ouvrez un tableau en
**Lecture seule** ; choisissez **Retour à la leçon** pour revenir.
</Step>

</Steps>

Vous ne voyez que les leçons que l'enseignant a rendues visibles pour la classe de votre enfant.

## Devoirs

Ouvrez **Devoirs**. Chaque carte indique le type (fichier ou quiz), la date limite et l'état :
**À venir**, **Ouvert**, **En retard** ou **Soumis** (**Rendu** dans l'application mobile).
Filtrez par type avec les puces en haut.

Ouvrez un devoir pour voir les consignes, les pièces jointes de l'enseignant, la date limite et
le rendu de votre enfant :

- **Les fichiers rendus par votre enfant**, et leur date.
- **La note et le retour de l'enseignant** une fois corrigé — sous **Votre note** et
  **Commentaires** sur le web, **Votre résultat** et **Retour du professeur** dans
  l'application mobile.
- **Noté — en attente de publication** signifie que l'enseignant a corrigé le travail mais n'a
  pas encore publié la note.

Vous ne pouvez pas rendre un travail à la place de votre enfant — le rendu se fait depuis le
compte de l'élève.

### Quiz

Un devoir de type quiz indique les questions, les points, la limite de temps et les tentatives.
Seul votre enfant peut le passer — la page indique **Seul l'élève peut commencer ce quiz.** (web)
ou **Seul votre enfant peut passer ce quiz.** (mobile). Sous **Tentatives de votre enfant**
(web), vous pouvez ouvrir chaque tentative terminée avec **Réviser** pour voir les réponses de
votre enfant et leur correction. Dans l'application mobile, touchez une tentative terminée pour
ouvrir sa révision. La possibilité de revoir les réponses dépend du réglage du quiz par
l'enseignant.

## Examens

- **Application mobile** — menu → **Examens**. L'onglet **À venir** liste les examens prévus
  avec la date et la durée. L'onglet **Passés** montre les résultats ; utilisez le filtre pour
  choisir un trimestre ou une matière. **Note en attente** signifie que la note n'est pas encore
  publiée ; **Ne compte pas** marque un examen exclu de la moyenne.
- **Web** — les examens à venir apparaissent sur le **Tableau de bord** (**Examens à venir**).
  Les résultats d'examens se trouvent dans **Notes**.

## Notes et bulletins

Ouvrez **Notes**.

| | Web | Application mobile |
| --- | --- | --- |
| **Vue d'ensemble** | Une liste de **Matières**, chacune avec sa **Moyenne**. | La **Moyenne générale**, puis une carte par matière. Choisissez un trimestre, ou **Tous les trimestres**. |
| **Une matière** | Sélectionnez une matière pour voir sa **Moyenne par matière**, son **Rang par matière**, son **Coefficient**, et pour chaque trimestre les examens, les **Devoirs** et les **Évaluations**. | Touchez une matière pour voir pour chaque trimestre la moyenne, les examens, les **Devoirs** et les **Autres évaluations**. |
| **Bulletins** | Sous **Bulletins**, choisissez **Télécharger PDF** à côté d'un bulletin. | Sous **Bulletins**, touchez un bulletin pour le télécharger puis le partager ou l'enregistrer. |

Vous ne voyez que les notes publiées par l'école. Un bulletin apparaît une fois publié par
l'école — voir [Bulletins](../teaching/report-cards).

## Comportement et classement de classe

Ces écrans apparaissent si votre école utilise le suivi du comportement.

- **Comportement** — les incidents enregistrés pour votre enfant, positifs ou négatifs, avec les
  points, la date et la description. En lecture seule.
- **Classement de classe** — choisissez **Semaine** ou **Mois**.
  - **Web** : **Réussites sur le podium** (les semaines ou mois passés où votre enfant a fini
    1er, 2e ou 3e de la classe) et **Vos points dans le temps**. Le top 3 de la semaine apparaît
    aussi sur le **Tableau de bord**.
  - **Application mobile** : le podium de la classe pour la période, **Réussites sur le
    podium** et **Points dans le temps**.
