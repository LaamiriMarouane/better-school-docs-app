Cette page suit votre travail scolaire de la leçon jusqu'au bulletin. Pour la connexion et
l'orientation dans l'application, voir le [Guide élève](./student-guide).

## Cours et leçons

Ouvrez **Cours** (web : **Académique** → **Cours** ; mobile : menu → **Cours**).

<Steps>

<Step>
### Choisissez une matière

Vous voyez vos matières de l'année, chacune avec son nombre de leçons. Recherchez par nom, ou
choisissez un trimestre (ou **Tous les trimestres**).
</Step>

<Step>
### Ouvrez une leçon

Ouvrez une matière pour voir ses leçons, puis choisissez-en une pour la lire. Dans
l'application mobile, les leçons sont regroupées par chapitre. Vous ne voyez que les leçons que
votre enseignant a rendues visibles pour votre classe.
</Step>

<Step>
### Ouvrez les pièces jointes et les tableaux (web)

Sur le web, une leçon peut aussi avoir des **Pièces jointes** et des **Tableaux** — des tableaux
blancs liés à la leçon par votre enseignant. Ouvrez un tableau depuis la leçon ; choisissez
**Retour à la leçon** pour revenir.
</Step>

</Steps>

### Travailler sur un tableau (web)

Un tableau s'ouvre tel que votre enseignant l'a préparé. Pour y travailler vous-même, choisissez
**Activer la modification** : vous travaillez alors sur votre propre copie, et vos modifications
sont enregistrées au fur et à mesure. **Réinitialiser au tableau du professeur** rétablit la
version de votre enseignant.

## Devoirs de fichiers

Ouvrez **Devoirs**. Chaque carte indique le type (fichier ou quiz), la date limite et l'état :
**À venir**, **Ouvert**, **En retard** ou **Soumis** (**Rendu** dans l'application mobile).
Filtrez par type avec les puces en haut. Ouvrez une carte pour voir les consignes, les pièces
jointes de votre enseignant et la date limite.

### Rendre votre travail

<Steps>

<Step>
### Ajoutez vos fichiers

- **Web** — dans **Rendez votre travail**, choisissez **Télécharger des fichiers** ou déposez vos
  fichiers sur la page.
- **Application mobile** — dans **Envoyer votre travail**, touchez **Ajouter des fichiers** et
  choisissez-les sur votre téléphone.

La page indique combien de fichiers vous pouvez joindre.
</Step>

<Step>
### Ajoutez une note (facultatif)

Écrivez un commentaire pour votre enseignant si besoin.
</Step>

<Step>
### Soumettez

Choisissez **Soumettre un devoir** (web) ou **Envoyer** (application mobile). Le devoir apparaît
alors comme **Soumis**, avec les fichiers que vous avez rendus.
</Step>

</Steps>

Si votre enseignant l'autorise, vous pouvez rendre une nouvelle version avant la correction
(**Soumettre à nouveau** sur le web, **Renvoyer** dans l'application mobile).

La page vous indique aussi quand vous ne pouvez pas rendre en ligne — par exemple quand le
devoir se rend en classe, n'est pas encore disponible ou a dépassé sa date limite. Si votre
enseignant accepte les rendus tardifs, vous pouvez encore rendre après la date limite ; faites-le
dès que possible.

### Lire votre note et le retour

Une fois votre travail corrigé, ouvrez le devoir pour voir votre note et les commentaires —
**Votre note** et **Commentaires** sur le web, **Votre résultat** et **Retour du professeur**
dans l'application mobile. **Noté — en attente de publication** signifie que votre travail est
corrigé mais que la note n'est pas encore publiée.

## Quiz

Un devoir de type quiz indique le nombre de questions, les points, la limite de temps et le
nombre de tentatives restantes.

<Steps>

<Step>
### Commencez le quiz

Choisissez **Commencer le quiz**. Si vous avez laissé une tentative inachevée, choisissez
**Reprendre le quiz** pour continuer.
</Step>

<Step>
### Répondez aux questions

Passez d'une question à l'autre avec **Précédent** et **Suivant**. Certaines questions ont un
indice. Si le quiz a une limite de temps, répondez avant la fin — ce que vous avez répondu à ce
moment-là est rendu.
</Step>

<Step>
### Soumettez

Soumettez le quiz à la fin. Dans l'application mobile, un résumé indique combien de questions
vous avez répondu avant de confirmer. Selon le réglage de votre enseignant, vous voyez ensuite
votre score et si vous avez réussi.
</Step>

</Steps>

Vous ne pouvez pas commencer un quiz avant sa disponibilité, après sa date limite ou une fois
toutes vos tentatives utilisées — la page vous indique pourquoi.

### Revoir une tentative

Vos tentatives terminées sont listées sous **Mes tentatives** (web) ou **Vos tentatives**
(application mobile). Choisissez **Réviser** (web) ou touchez la tentative (application mobile)
pour voir vos réponses et leur correction. Dans l'application mobile, vous pouvez aussi filtrer
les questions : **Tout**, **Ignoré**, **Incorrect** ou **Partiel**, et voir **Votre réponse**,
la **Bonne réponse** et une éventuelle **Explication**. La possibilité de revoir dépend du
réglage du quiz par votre enseignant.

## Examens

Ouvrez **Examens**.

| | Web | Application mobile |
| --- | --- | --- |
| **À venir** | L'onglet **À venir** liste vos examens prévus. | L'onglet **À venir** liste vos examens avec la date et la durée. |
| **Résultats** | L'onglet **Terminé** montre vos résultats ; choisissez un trimestre. Vous voyez aussi votre **Performance par matière**. | L'onglet **Passés** montre vos résultats ; utilisez le filtre pour choisir un trimestre ou une matière. **Note en attente** signifie que la note n'est pas encore publiée. |

Un examen marqué comme ne comptant pas (**Ne compte pas**) est exclu de votre moyenne.

## Notes et bulletins

Ouvrez **Notes**.

| | Web | Application mobile |
| --- | --- | --- |
| **Vue d'ensemble** | Une liste de **Matières**, chacune avec sa **Moyenne**. | Votre **Moyenne générale**, puis une carte par matière. Choisissez un trimestre, ou **Tous les trimestres**. |
| **Une matière** | Sélectionnez une matière pour voir sa **Moyenne par matière**, son **Rang par matière**, son **Coefficient**, et pour chaque trimestre les examens, les **Devoirs** et les **Évaluations**. | Touchez une matière pour voir pour chaque trimestre la moyenne, les examens, les **Devoirs** et les **Autres évaluations**. |
| **Bulletins** | Sous **Bulletins**, choisissez **Télécharger PDF** à côté d'un bulletin. | Sous **Bulletins**, touchez un bulletin pour le télécharger puis le partager ou l'enregistrer. |

Vous ne voyez les notes qu'une fois publiées. Les bulletins apparaissent une fois publiés par
l'école.
