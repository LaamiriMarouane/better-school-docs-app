---
title: Changer un mot de passe temporaire
description: Définissez votre propre mot de passe lors de la première connexion avec des identifiants temporaires.
---

Lorsque l'école crée un compte pour vous, il est fourni avec un **mot de passe
temporaire**. À la première connexion, vous devez le remplacer par un mot de passe
que vous seul connaissez.

<Callout title="Pour qui">
Les nouveaux utilisateurs qui se connectent pour la première fois avec des
identifiants émis par l'école.
</Callout>

## Avant de commencer

- Le **mot de passe temporaire** que l'école vous a remis — voir
  [Créer des comptes de portail](../onboard-people/create-portal-accounts).

## Étapes

<Steps>

<Step>
### Se connecter avec le mot de passe temporaire

Connectez-vous comme d'habitude avec votre e-mail ou nom d'utilisateur et le mot de
passe temporaire. Comme le mot de passe est temporaire, vous êtes envoyé
directement vers l'écran de changement de mot de passe — impossible de l'ignorer.
</Step>

<Step>
### Saisir les mots de passe

Renseignez trois champs :

| Champ | À saisir |
| --- | --- |
| **Ancien mot de passe** | Le mot de passe temporaire que vous venez d'utiliser. |
| **Nouveau mot de passe** | Un nouveau mot de passe que vous seul connaissez. Il doit respecter l'exigence de robustesse. |
| **Confirmer le mot de passe** | À nouveau le nouveau mot de passe — les deux doivent correspondre. |
</Step>

<Step>
### Enregistrer

Choisissez **Enregistrer**. Pour des raisons de sécurité, vous êtes déconnecté afin
que le changement prenne effet.
</Step>

<Step>
### Se reconnecter

Revenez à la page de connexion et connectez-vous avec votre **nouveau** mot de
passe. Désormais, c'est celui-ci que vous utilisez.
</Step>

</Steps>

<Callout title="Cette étape ne peut pas être ignorée">
Tant que le mot de passe temporaire n'est pas remplacé, chaque connexion ramène à
cet écran. Vous pouvez vous déconnecter au lieu de le changer, mais vous
n'atteindrez pas votre tableau de bord.
</Callout>
