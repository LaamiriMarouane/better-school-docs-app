The **school documents** area is where you keep the school's own files — licences,
policies, certificates, and similar official documents — in one organised place.

<Callout title="Who this is for">
Administrators keeping the school's paperwork on file.
</Callout>

## Steps

<Steps>

<Step>
### Open the School Documents settings

Go to **Settings → School** and open the **School Documents** tab, then start a new document.

<Screenshot
  label="School documents form"
  caption="The form: title, description, file, and status."
/>
</Step>

<Step>
### Fill in the document details

Complete the fields below, then click **Submit**.

| Field | Required | Notes |
| --- | --- | --- |
| **Title** | Yes | A clear name for the document. |
| **Document** | Yes | The file to upload. |
| **Description** | No | Optional notes about the document. |
| **Status** | No | *Active*, *Inactive*, or *Archived* — used to keep the list tidy. |
</Step>

<Step>
### Repeat for each document

Add every official document the school needs on file. Use the status to archive ones
that are no longer current without deleting them.
</Step>

</Steps>
