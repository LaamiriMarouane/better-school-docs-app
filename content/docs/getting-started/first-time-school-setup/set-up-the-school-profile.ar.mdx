---
title: إعداد ملف المدرسة
description: املأ اسم مدرستك وبيانات التواصل والشعار وروابط التواصل الاجتماعي.
---

يحتوي **ملف المدرسة** على المعلومات التي تعرّف مدرستك عبر المنصّة — اسمها وبيانات
تواصلها وشعارها وروابطها الاجتماعية. أعِدّه مبكرًا لتعرض المستندات والبوّابات
والمراسلات المعلومات الصحيحة.

<Callout title="لمن هذا الدليل">
المسؤولون الذين يكملون المعلومات الأساسية للمدرسة.
</Callout>

## الخطوات

<Steps>

<Step>
### افتح إعدادات معلومات المدرسة

انتقل إلى **الإعدادات ← إعدادات المؤسسة** وافتح علامة تبويب **معلومات المدرسة**.

<Screenshot
  label="نموذج معلومات المدرسة"
  caption="ملف المدرسة: الهوية، التواصل، الشعار، والروابط الاجتماعية."
/>
</Step>

<Step>
### املأ تفاصيل المدرسة

أكمل الحقول أدناه.

| الحقل | ملاحظات |
| --- | --- |
| **الاسم** | الاسم المعروض للمدرسة. |
| **بريد إلكتروني** | بريد التواصل الخاص بالمدرسة. |
| **رقم الهاتف** | هاتف التواصل للمدرسة، مع رمز الدولة. |
| **البلد / المدينة / العنوان** | العنوان المكتوب للمدرسة. |
| **دبوس الخريطة** | ضع دبوسًا على الخريطة بجانب العنوان واحفظه. هذا هو الموقع الذي يستخدمه توجيه مسارات النقل. كتابة العنوان وحدها لا تكفي. |
| **شعار المدرسة** | اختر **رفع شعار المدرسة** وحدّد صورة. تُستخدم عبر المنصّة وعلى المستندات. |
| **الموقع الإلكتروني** | رابط اختياري لموقع المدرسة على الويب. |
| **فيسبوك / إنستغرام / واتساب** | روابط اختيارية لقنوات التواصل الاجتماعي للمدرسة. |
</Step>

<Step>
### احفظ الملف

اختر **تحديث**. تُطبَّق المعلومات المحدّثة عبر المنصّة.
</Step>

</Steps>

<Callout title="ضع الدبوس قبل بناء مسارات الحافلات">
يصبح الدبوس محطة المدرسة على كل مسار — نهاية مسار الذهاب وبداية مسار الإياب. من دونه لا يمر
خط الطريق بالمدرسة، وتتجاهلها الأوقات المقترحة والترتيب المحسَّن. احفظ الدبوس **قبل** إنشاء
المسارات. إذا كان المسار موجودًا مسبقًا، فافتح محطة المدرسة عليه واحفظها ليُنسخ الدبوس إلى
المسار. راجع [بناء المسارات والمحطات](../../transport/build-routes-and-stops).
</Callout>

<Callout title="إذا بدأت ببيانات نموذجية">
ما دامت مدرستك تعمل ببيانات نموذجية، يظهر مربّع **البيانات النموذجية** في أعلى علامة
التبويب هذه. اختر **مسح البيانات النموذجية** لحذف الفصول والمعلمين والتلاميذ والجدول
الزمني النموذجية مع الاحتفاظ ببياناتك الخاصّة، أو **البدء من جديد** لحذف البيانات
النموذجية والعودة إلى خيارات الإعداد.
</Callout>

<Callout title="نصيحة">
يظهر الشعار والاسم على المستندات المولَّدة وعلى بوّابات الأشخاص — حافظ على دقّتهما
وتحديثهما.
</Callout>
