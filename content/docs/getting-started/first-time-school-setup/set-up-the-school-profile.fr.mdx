---
title: Configurer le profil de l'école
description: Renseignez le nom, les coordonnées, le logo et les liens sociaux de votre école.
---

Le **profil de l'école** contient les informations qui identifient votre école sur
toute la plateforme — son nom, ses coordonnées, son logo et ses liens sociaux.
Configurez-le tôt pour que les documents, les portails et les communications affichent
les bonnes informations.

<Callout title="Pour qui">
Les administrateurs qui complètent les informations de base de l'école.
</Callout>

## Étapes

<Steps>

<Step>
### Ouvrir les paramètres Informations de l'école

Allez dans **Paramètres → Établissement** et ouvrez l'onglet **Informations de l'école**.

<Screenshot
  label="Formulaire d'informations de l'école"
  caption="Le profil de l'école : identité, contact, logo et liens sociaux."
/>
</Step>

<Step>
### Renseigner les détails de l'école

Complétez les champs ci-dessous, puis enregistrez.

| Champ | Remarques |
| --- | --- |
| **Nom** | Le nom affiché de l'école. |
| **E-mail** | L'e-mail de contact de l'école. |
| **Numéro de téléphone** | Le téléphone de contact de l'école, avec indicatif pays. |
| **Pays / Ville / Adresse** | L'adresse écrite de l'école. |
| **Épingle sur la carte** | Placez une épingle sur la carte à côté de l'adresse et enregistrez-la. C'est l'emplacement utilisé par le calcul d'itinéraire du transport. L'adresse écrite ne suffit pas. |
| **Logo de l'école** | Une image utilisée sur la plateforme et sur les documents. |
| **Facebook / Instagram / WhatsApp** | Liens facultatifs vers les réseaux sociaux de l'école. |
</Step>

<Step>
### Enregistrer le profil

Enregistrez vos modifications. Les informations mises à jour s'appliquent sur toute la
plateforme.
</Step>

</Steps>

<Callout title="Placez l'épingle avant de construire les itinéraires">
L'épingle devient l'arrêt de l'école sur chaque itinéraire — la fin d'un aller et le début
d'un retour. Sans elle, le tracé routier ne passe pas par l'école, et les heures suggérées et
l'ordre optimisé l'ignorent. Enregistrez l'épingle **avant** de créer les itinéraires. Si un
itinéraire existe déjà, ouvrez son arrêt d'école et enregistrez-le pour y recopier l'épingle.
Voir [Construire itinéraires et arrêts](../../transport/build-routes-and-stops).
</Callout>

<Callout title="Astuce">
Le logo et le nom apparaissent sur les documents générés et sur les portails des
personnes — gardez-les exacts et à jour.
</Callout>
