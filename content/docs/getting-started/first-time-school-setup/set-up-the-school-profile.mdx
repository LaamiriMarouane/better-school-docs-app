The **school profile** holds the details that identify your school across the
platform — its name, contact information, logo, and social links. Set it up early so
documents, portals, and communications show the right information.

<Callout title="Who this is for">
Administrators completing the school's basic information.
</Callout>

## Steps

<Steps>

<Step>
### Open the School Info settings

Go to **Settings → School** and open the **School Info** tab.

<Screenshot
  label="School info form"
  caption="The school profile: identity, contact, logo, and social links."
/>
</Step>

<Step>
### Fill in the school details

Complete the fields below, then save.

| Field | Notes |
| --- | --- |
| **Name** | The school's display name. |
| **Email** | The school's contact email. |
| **Phone number** | The school's contact phone, with country code. |
| **Country / City / Address** | The school's written location. |
| **Map pin** | Drop a pin on the map beside the address and save it. This is the location transport routing uses. The written address alone is not enough. |
| **School logo** | An image used across the platform and on documents. |
| **Facebook / Instagram / WhatsApp** | Optional links to the school's social channels. |
</Step>

<Step>
### Save the profile

Save your changes. The updated details apply across the platform.
</Step>

</Steps>

<Callout title="Set the map pin before you build bus routes">
The pin becomes the school stop on every route — the end of a pickup route and the start of
a dropoff route. Without it, the road line does not run to or from the school, and suggested
times and optimized order leave the school out. Save the pin **before** you create routes. If
a route already exists, open its school stop and save it so the pin is copied onto the route.
See [Build routes and stops](../../transport/build-routes-and-stops).
</Callout>

<Callout title="Tip">
The logo and name appear on generated documents and on the people portals — keep them
accurate and up to date.
</Callout>
