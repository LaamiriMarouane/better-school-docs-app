---
title: Ajouter des élèves
description: Créez les fiches des élèves, reliez leurs tuteurs et lancez éventuellement une pré-inscription.
---

Une fiche **élève** contient les informations personnelles, médicales et familiales
d'un enfant. Ajouter un élève est la première étape avant de pouvoir l'inscrire dans une
classe. Chaque élève doit être relié à au moins un **tuteur**.

<Callout title="Pour qui">
Les administrateurs qui intègrent les élèves et leurs familles.
</Callout>

## Avant de commencer

- Préparez le nom et le sexe de l'élève — ces champs sont obligatoires.
- Disposez d'au moins un **tuteur** à relier. Vous pouvez choisir un tuteur existant ou
  en ajouter un nouveau directement depuis ce formulaire.

## Étapes

<Steps>

<Step>
### Ouvrir la page Élèves

Dans la barre latérale d'administration, allez dans **Académique → Élèves**, puis
cliquez sur **Ajouter un élève**.

<Screenshot
  label="Formulaire d'ajout d'un élève"
  caption="Le formulaire : informations de l'élève, détails médicaux et tuteurs."
/>
</Step>

<Step>
### Renseigner les informations de l'élève

Complétez les champs ci-dessous. Le prénom, le nom et le sexe sont obligatoires.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Prénom** | Oui | Le prénom de l'élève. |
| **Nom** | Oui | Le nom de famille de l'élève. |
| **Sexe** | Oui | Utilisé dans les profils et les rapports. |
| **Prénom / nom (langue locale)** | Non | Le nom dans l'écriture locale, ex. l'arabe. |
| **Date de naissance** | Non | La date de naissance de l'élève. |
| **E-mail** | Non | Utilisé pour le compte portail s'il est créé ultérieurement. |
| **Nationalité**, **Ville**, **Adresse** | Non | Identité et coordonnées. |
| **Numéro PAN** | Non | Un numéro d'identité / d'enregistrement, si votre école en utilise un. |
| **École précédente**, **Adresse de l'école précédente** | Non | L'école antérieure de l'élève. |
</Step>

<Step>
### Ajouter des détails médicaux (facultatif)

Dans la section médicale, vous pouvez enregistrer les **allergies**, les
**médicaments** et les **antécédents médicaux**. Saisissez une valeur et appuyez sur
Entrée pour ajouter chaque allergie ou médicament sous forme d'étiquette.
</Step>

<Step>
### Relier les tuteurs

Dans la section **Tuteurs**, reliez au moins un tuteur. Vous pouvez :

- **Sélectionner un tuteur existant** déjà présent dans le système, ou
- **Ajouter un nouveau tuteur** directement en saisissant son prénom, son nom, son
  e-mail, son numéro de téléphone et son type de tuteur.

Un élève peut avoir jusqu'à **trois** tuteurs.
</Step>

<Step>
### Lancer une pré-inscription (facultatif)

Activez **Activer la pré-inscription** pour enregistrer l'élève sur un **niveau** avant
la création d'une inscription complète. Lorsqu'elle est activée, le choix d'un niveau
est obligatoire.
</Step>

<Step>
### Enregistrer l'élève

Cliquez sur **Valider**. Vous êtes redirigé vers le profil du nouvel élève, où vous
pouvez poursuivre avec l'inscription.
</Step>

</Steps>

<Callout type="warn" title="Au moins un tuteur">
Un élève ne peut pas être enregistré sans tuteur. Si le message *« Au moins un tuteur
requis »* s'affiche, reliez ou ajoutez un tuteur avant de valider.
</Callout>
