---
title: Add guardians
description: Create guardian records so they can be linked to students and reached for communication.
---

A **guardian** is a parent or other responsible adult connected to one or more
students. Guardian records link family members to students and are used to send
announcements and messages.

<Callout title="Who this is for">
Administrators onboarding families.
</Callout>

## Before you start

- Have each guardian's name, phone number, gender, and relationship to the student
  (the **guardian type**) ready.
- You can create a guardian on its own here, or add one inline while
  [adding a student](./add-students).

## Steps

<Steps>

<Step>
### Open the Guardians page

From the admin sidebar, go to **Academic → Guardians**, then click **Add Guardian**.

<Screenshot
  label="Add guardian form"
  caption="The Add Guardian form, grouped into guardian information and documents."
/>
</Step>

<Step>
### Fill in the guardian information

Complete the fields below. Fields marked required must be filled before you can save.

| Field | Required | Notes |
| --- | --- | --- |
| **First Name** | Yes | The guardian's given name. |
| **Last Name** | Yes | The guardian's family name. |
| **Phone Number** | Yes | Include the country code. |
| **Guardian Type** | Yes | The relationship to the student, e.g. father, mother. |
| **Gender** | Yes | Used across profiles and reports. |
| **Email** | No | Used for the portal account if one is created later. |
| **Given Name (Native)**, **Family Name (Native)** | No | The name in the local script, e.g. Arabic. |
| **Profession** | No | The guardian's occupation. |
| **Date of Birth**, **Birth Place** | No | Personal details. |
| **Nationality**, **Country**, **City**, **Address** | No | Contact and identity details. |

If your school has defined **custom fields** for guardians, they appear below these
fields; some may be required.
</Step>

<Step>
### Add a profile photo (optional)

Click the avatar to upload and crop a profile photo.
</Step>

<Step>
### Upload an identity document (optional)

In the **Documents** section you can attach an identity document. Accepted formats and
the size limit are shown above the upload field.
</Step>

<Step>
### Save the guardian

Click **Create Guardian**. You are taken to the new guardian's profile.
</Step>

</Steps>

<Callout title="Linking to students">
Creating a guardian does not link them to a student on its own. Open the student's
profile and use **Assign guardians**, or pick the guardian while creating the student.
The guardian's profile then lists their children.
</Callout>
