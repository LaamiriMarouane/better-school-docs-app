---
title: Ajouter des enseignants
description: Créez les fiches des enseignants afin de les affecter aux matières, aux classes et à l'emploi du temps.
---

Une fiche **enseignant** contient les informations personnelles et professionnelles
d'un membre de votre personnel enseignant. Une fois l'enseignant créé, il peut être
affecté à des matières et des classes, placé dans l'emploi du temps et — lors d'une
étape distincte — recevoir un compte portail pour se connecter.

<Callout title="Pour qui">
Les administrateurs qui intègrent le personnel enseignant.
</Callout>

## Avant de commencer

- Préparez les informations de base de chaque enseignant : nom complet, numéro de
  téléphone, sexe et date d'embauche.
- Rassemblez éventuellement les documents à téléverser — contrat, pièce d'identité et
  CV.

## Étapes

<Steps>

<Step>
### Ouvrir la page Enseignants

Dans la barre latérale d'administration, allez dans **Académique → Enseignants**, puis
cliquez sur **Ajouter un nouvel enseignant**.

<Screenshot
  label="Formulaire d'ajout d'un enseignant"
  caption="Le formulaire d'ajout, organisé en informations de l'enseignant et documents."
/>
</Step>

<Step>
### Renseigner les informations de l'enseignant

Complétez les champs ci-dessous. Les champs obligatoires doivent être remplis avant
l'enregistrement.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Prénom** | Oui | Le prénom de l'enseignant. |
| **Nom** | Oui | Le nom de famille de l'enseignant. |
| **Numéro de téléphone** | Oui | Incluez l'indicatif pays ; le numéro est validé. |
| **Sexe** | Oui | Utilisé dans les profils et les rapports. |
| **Date d'embauche** | Oui | La date d'arrivée de l'enseignant dans l'école. |
| **E-mail** | Non | Utilisé pour le compte portail s'il est créé ultérieurement. |
| **Prénom / nom (langue locale)** | Non | Le nom dans l'écriture locale, ex. l'arabe. |
| **Date de naissance**, **Lieu de naissance** | Non | Informations personnelles. |
| **Nationalité**, **Pays**, **Ville**, **Adresse** | Non | Coordonnées et identité. |
| **École précédente**, **Adresse de l'école précédente** | Non | Historique professionnel. |
</Step>

<Step>
### Ajouter une photo de profil (facultatif)

Cliquez sur l'avatar pour téléverser et recadrer une photo de profil.
</Step>

<Step>
### Téléverser des documents (facultatif)

Dans la section **Documents**, vous pouvez joindre un **contrat**, une **pièce
d'identité** et un **CV**. Les formats acceptés et les limites de taille sont indiqués
au-dessus des champs de téléversement.
</Step>

<Step>
### Enregistrer l'enseignant

Cliquez sur **Créer l'enseignant**. Vous êtes redirigé vers le profil du nouvel
enseignant, où vous pouvez vérifier et poursuivre l'intégration.
</Step>

</Steps>

<Callout title="La connexion est une étape distincte">
Créer une fiche enseignant ne crée **pas** d'identifiant de connexion. Pour permettre à
l'enseignant de se connecter, créez-lui un compte portail — voir
[Créer des comptes portail](./create-portal-accounts).
</Callout>
