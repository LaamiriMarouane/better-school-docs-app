---
title: Add students
description: Create student records, link their guardians, and optionally start a pre-inscription.
---

A **student** record holds a child's personal, medical, and family details. Adding a
student is the first step before they can be enrolled into a class. Every student must
be linked to at least one **guardian**.

<Callout title="Who this is for">
Administrators onboarding students and their families.
</Callout>

## Before you start

- Have the student's name and gender ready — these are required.
- Have at least one **guardian** to link. You can pick an existing guardian or add a
  new one inline from this form.

## Steps

<Steps>

<Step>
### Open the Students page

From the admin sidebar, go to **People → Students**, then click **Add Student**.

<Screenshot
  label="Add student form"
  caption="The Add Student form: student information, medical details and guardians."
/>
</Step>

<Step>
### Fill in the student information

Complete the fields below. First name, last name, and gender are required.

| Field | Required | Notes |
| --- | --- | --- |
| **First name** | Yes | The student's given name. |
| **Last name** | Yes | The student's family name. |
| **Gender** | Yes | Used across profiles and reports. |
| **Given / family name (native)** | No | The name in the local script, e.g. Arabic. |
| **Date of birth** | No | The student's birth date. |
| **Email** | No | Used for the portal account if one is created later. |
| **Nationality**, **City**, **Address** | No | Identity and contact details. |
| **PAN number** | No | An identity / registration number, if your school uses one. |
| **Previous school**, **Previous school address** | No | The student's prior school. |
</Step>

<Step>
### Add medical details (optional)

In the medical section you can record **allergies**, **medications**, and
**medical history**. Type a value and press Enter to add each allergy or medication as
a tag.
</Step>

<Step>
### Link guardians

In the **Guardians** section, link at least one guardian. You can:

- **Select an existing guardian** already in the system, or
- **Add a new guardian** inline by entering their first name, last name, email, phone
  number, and guardian type.

A student can have up to **three** guardians.
</Step>

<Step>
### Start a pre-inscription (optional)

Turn on **Enable pre-inscription** to register the student against a **level** before
a full enrollment is created. When enabled, choosing a level is required.
</Step>

<Step>
### Save the student

Click **Submit**. You are taken to the new student's profile, where you can continue
with enrollment.
</Step>

</Steps>

<Callout type="warn" title="At least one guardian">
A student cannot be saved without a guardian. If you see *"At least one guardian
required"*, link or add a guardian before submitting.
</Callout>
