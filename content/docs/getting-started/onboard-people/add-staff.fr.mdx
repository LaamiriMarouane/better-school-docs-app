---
title: Ajouter du personnel
description: Créez la fiche d'un membre du personnel non enseignant, y compris les chauffeurs.
---

Une fiche **personnel** concerne les personnes qui font tourner l'école sans enseigner —
secrétaires, comptables, chauffeurs, etc. Les enseignants ont leur propre type de fiche ;
voir [Ajouter des enseignants](./add-teachers). Les administrateurs ne sont pas ajoutés
comme personnel : seul le propriétaire de l'école peut ajouter un administrateur, depuis
**Accès → Utilisateurs** avec **Ajouter un administrateur**.

<Callout title="Pour qui">
Les administrateurs qui enregistrent le personnel non enseignant.
</Callout>

## Avant de commencer

- Le module **Gestion du personnel** doit être activé (**Paramètres → Modules**). Sans
  lui, le menu **RH → Personnel** est masqué.
- Chaque membre du personnel reçoit un **Rôle**. Les rôles viennent de
  **Accès → Rôles et permissions** ; créez-y d'abord ceux dont vous avez besoin.
- Beaucoup de personnes à ajouter ? Utilisez **Importer** sur la page Personnel :
  téléchargez le **Modèle**, remplissez une personne par ligne, téléversez-le, puis
  cliquez sur **Lancer l'import**.

## Étapes

<Steps>

<Step>
### Ouvrir le formulaire d'ajout

Dans la barre latérale d'administration, allez dans **RH → Personnel**, puis cliquez
sur **Ajouter Personnel**.

<Screenshot
  label="Formulaire d'ajout de personnel"
  caption="Le formulaire : identité, contact et détails du rôle."
/>
</Step>

<Step>
### Renseigner les informations

Complétez les champs ci-dessous. Seuls les champs obligatoires sont nécessaires pour
enregistrer.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Prénom** | Oui | Le prénom du membre du personnel. |
| **Nom de Famille** | Oui | Le nom de famille du membre du personnel. |
| **Numéro de téléphone** | Oui | Incluez l'indicatif pays. |
| **Genre** | Oui | Homme ou femme. |
| **Date d'embauche** | Oui | La date d'embauche. |
| **Rôle** | Oui | Choisi parmi les rôles du personnel de votre école, ex. comptable, chauffeur. |
| **Email** | Non | Utilisé plus tard s'il obtient un compte portail. |
| **Autres informations** | Non | Nom natif, nationalité, pays, ville, date et lieu de naissance, adresse, école précédente. |

Vous pouvez aussi téléverser une **photo de profil** et remplir les **champs
personnalisés** que votre école a définis pour le personnel.
</Step>

<Step>
### Ajouter les informations du chauffeur (chauffeurs uniquement)

Si vous choisissez le rôle **Chauffeur**, une section **Informations du chauffeur**
apparaît. La **Date d'expiration du permis** est alors obligatoire ; le **Numéro de
permis de conduire** est facultatif.
</Step>

<Step>
### Téléverser des documents (facultatif)

Lors de la création, vous pouvez joindre un **contrat**, une **pièce d'identité** et un
**CV**. Les formats acceptés et la limite de taille sont indiqués au-dessus des champs
de téléversement.
</Step>

<Step>
### Enregistrer le membre du personnel

Cliquez sur **Soumettre**. Vous êtes redirigé vers le profil du nouveau membre du
personnel.
</Step>

</Steps>

<Callout title="La connexion est une étape distincte">
Créer une fiche personnel ne crée **pas** d'identifiant de connexion. Pour permettre à
la personne de se connecter, utilisez **Créer un compte portail** sur son profil — voir
[Créer des comptes portail](./create-portal-accounts).
</Callout>
