title: "Supported platforms: web and mobile"
description: Where the platform runs and what to expect on each device.
---

The platform is used in two places: a **web app** in the browser and a **mobile app**
on phones. They share the same data — a change made on one shows on the other.

## Web app

The web app runs in any modern browser. It is the main place for **setup and
administration** — building the academic structure, onboarding people, finance, and
the timetable — where larger screens and detailed tables help. Every role can use it.

## Mobile app

The mobile app is built for **everyday use on the go**. It suits teachers, guardians,
and students checking timetables, attendance, results, messages, and notifications,
and staff checking their attendance, their leave, and — for drivers — their trips.

<Callout title="Administration is web only">
Administrators can't use the mobile app. If your only role is administrator, the app
signs you out and asks you to use the web app.
</Callout>

## Which to use

| You are… | Best on |
| --- | --- |
| An administrator setting the school up | Web app (only) |
| A teacher running daily classes | Either — web for detail, mobile on the go |
| A guardian or student following the day | Mobile app |
| A staff member, such as a driver | Mobile app |

<Callout title="Same account everywhere">
Sign in with the same account on the web and mobile apps. If you hold more than one
role, the mobile app opens a single area — teacher first, then guardian, student, and
staff — and has no role switcher. To work in another role, use the web app.
</Callout>
