The platform is used in two places: a **web app** in the browser and a **mobile app**
on phones. They share the same data — a change made on one shows on the other.

## Web app

The web app runs in any modern browser. It is the main place for **setup and
administration** — building the academic structure, onboarding people, finance, and
the timetable — where larger screens and detailed tables help.

## Mobile app

The mobile app is built for **everyday use on the go**. It suits teachers, parents,
and students checking timetables, attendance, results, messages, and notifications.

## Which to use

| You are… | Best on |
| --- | --- |
| An administrator setting the school up | Web app |
| A teacher running daily classes | Either — web for detail, mobile on the go |
| A parent or student following the day | Mobile app |

<Callout title="Same account everywhere">
Your login works on both the web and mobile apps. Sign in with the same account on
whichever device you are using.
</Callout>
