title: ما الذي يتضمّنه

تدير المنصّة العمل اليومي للمدرسة في مكان واحد. إليك ما يغطّيه كل مجال رئيسي.

## المجالات الأساسية

| المجال | ما الذي يغطّيه |
| --- | --- |
| **الأكاديمي** | السنوات الدراسية والفترات، المستويات، الفصول، المواد، القاعات، الالتحاقات، والجداول. |
| **الأشخاص** | الطلاب والمعلمون وأولياء الأمور والموظفون — سجلاتهم وملفّاتهم. |
| **الوصول** | حسابات البوّابة وتسجيلات الدخول، مع دور لكل نوع من المستخدمين. |
| **المالية** | الخدمات والرسوم وخطط الدفع والمدفوعات والمصروفات. |
| **الحضور** | تسجيل حضور الطلاب ومراجعته. |
| **السلوك** | تتبّع السلوك والحوادث (وحدة اختيارية). |
| **التواصل** | الإعلانات والإشعارات والمراسلة بين المدرسة والأُسَر. |
| **النقل** | المركبات والمسارات والسائقون (وحدة اختيارية). |

## الوحدات الاختيارية

بعض المجالات **وحدات** تفعّلها فقط إذا احتاجتها مدرستك — إدارة الموظفين، الإجازات،
السلوك، المصروفات، النقل، والمعدّات. راجع
[إعداد وحدات المدرسة](../first-time-school-setup/configure-school-modules).

## الويب والجوال

تُستخدَم المنصّة على **تطبيق الويب** و**تطبيق الجوال**. راجع
[المنصّات المدعومة: الويب والجوال](./supported-platforms-web-and-mobile).
