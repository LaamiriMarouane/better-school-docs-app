تدير المنصّة العمل اليومي للمدرسة في مكان واحد. إليك ما يغطّيه كل مجال رئيسي في الشريط
الجانبي للمشرف.

## المجالات الأساسية

| المجال | ما الذي يغطّيه |
| --- | --- |
| **الأكاديمي** | الطلاب والمعلمون والأوصياء والنماذج والمستويات والمواد وقوالب الدورات والفصول وتعيينات المعلمين والقاعات والجدول وسجلّ الأنشطة. |
| **القبول والتسجيل** | التسجيل المسبق والتسجيلات. |
| **التقييمات** | إعداد التقييم والامتحانات المجدولة ودفتر النقاط والواجبات ونقاط الواجبات والاختبارات وبنك الأسئلة. |
| **الحضور** | حضور الطلاب والمعلمين والموظفين. |
| **السلوك** | إعداد السلوك وحوادث الطلاب ولوحة المتصدرين (وحدة اختيارية). |
| **الموارد البشرية** | سجلات الموظفين والإجازات و**شهر الموظفين** — ساعات التدريس والغيابات والإجازات وحالة الأجر للشهر. |
| **المالية** | الخدمات والرسوم والمدفوعات وخطط الدفع وقواعد التخفيض والمصروفات. |
| **العمليات** | النقل (المركبات وخطوط النقل والرحلات ومناطق النقل)، والانصراف عند بوابة المدرسة، والمعدات (وحدات اختيارية). |
| **التقارير** | التقارير الأكاديمية والتقارير المالية. |
| **التواصل** | الإعلانات وشكاوى الأولياء والطلاب والفئات المستهدفة والإشعارات والرسائل والفعاليات. |
| **الوصول** | المستخدمون (بما فيهم حسابات البوابة) والأدوار والصلاحيات. |
| **الإعدادات** | الإعدادات الدراسية وإعدادات المؤسسة والمالية والوحدات، والفروع، وسجل التدقيق. |
| **الفواتير والاشتراك** | اشتراكك في المنصّة. |

يوجد **الدعم** و**الطلبات** في قائمة ملفك الشخصي: تواصل مع فريق الدعم، أو اقترح ميزة
جديدة.

## الوحدات الاختيارية

بعض المجالات **وحدات** تفعّلها فقط إذا احتاجتها مدرستك — **إدارة الموظفين** و**إدارة الإجازات**
و**السلوك** و**المصروفات** و**النقل** و**المعدات** و**الإعلانات** و**المحادثة** و**الشكاوى**
و**الانصراف**. راجع
[إعداد وحدات المدرسة](../first-time-school-setup/configure-school-modules).

تُستخدَم المنصّة على **تطبيق الويب** و**تطبيق الجوال**. راجع
