تدير المنصّة العمل اليومي للمدرسة في مكان واحد. إليك ما يغطّيه كل مجال رئيسي.

## المجالات الأساسية

| المجال | ما الذي يغطّيه |
| --- | --- |
| **الأكاديمي** | الطلاب والمعلمون والأوصياء والمستويات والصفوف والمواد والقاعات والجداول وسجلّ النشاط. |
| **القبول والتسجيل** | الطلبات والتسجيلات وأعمال القبول ذات الصلة. |
| **التقييمات** | إعداد التقييم والامتحانات المجدولة وسجل الدرجات والواجبات والاختبارات وبنك الأسئلة. |
| **الحضور** | حضور الطلاب والمعلمين والموظفين. |
| **الموارد البشرية** | سجلات الموظفين والإجازات والرواتب. |
| **المالية** | الخدمات والرسوم وخطط الدفع والمدفوعات وقواعد التخفيض والمصروفات. |
| **السلوك** | تتبّع السلوك والحوادث (وحدة اختيارية). |
| **التواصل** | الإعلانات والجماهير والإشعارات والمراسلة والأحداث. |
| **العمليات** | النقل (المركبات والمسارات والرحلات) والمعدّات (وحدات اختيارية). |
| **الإعدادات** | تهيئة الإعدادات الدراسية والمؤسسة والمالية والوحدات، إضافةً إلى المستخدمين والفوترة. |

## الوحدات الاختيارية

بعض المجالات **وحدات** تفعّلها فقط إذا احتاجتها مدرستك — إدارة الموظفين، الإجازات،
السلوك، المصروفات، النقل، المعدّات، الإعلانات والدردشة. راجع
[إعداد وحدات المدرسة](../first-time-school-setup/configure-school-modules).

## الويب والجوال

تُستخدَم المنصّة على **تطبيق الويب** و**تطبيق الجوال**. راجع
[المنصّات المدعومة: الويب والجوال](./supported-platforms-web-and-mobile).
