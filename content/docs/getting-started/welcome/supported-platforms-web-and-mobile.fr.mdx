La plateforme s'utilise à deux endroits : une **application web** dans le navigateur
et une **application mobile** sur téléphone. Elles partagent les mêmes données — une
modification faite sur l'une apparaît sur l'autre.

## Application web

L'application web fonctionne dans tout navigateur moderne. C'est l'endroit principal
pour la **configuration et l'administration** — construire la structure académique,
intégrer les personnes, la finance et l'emploi du temps — où les grands écrans et les
tableaux détaillés sont utiles. Tous les rôles peuvent l'utiliser.

## Application mobile

L'application mobile est conçue pour un **usage quotidien en déplacement**. Elle
convient aux enseignants, tuteurs et élèves qui consultent emplois du temps, présence,
résultats, messages et notifications, ainsi qu'au personnel qui consulte sa présence,
ses congés et — pour les chauffeurs — ses trajets.

<Callout title="L'administration se fait sur le web">
Les administrateurs ne peuvent pas utiliser l'application mobile. Si votre seul rôle
est administrateur, l'application vous déconnecte et vous invite à utiliser
l'application web.
</Callout>

## Laquelle utiliser

| Vous êtes… | Idéal sur |
| --- | --- |
| Un administrateur qui configure l'école | Application web (uniquement) |
| Un enseignant qui gère ses classes au quotidien | L'une ou l'autre — web pour le détail, mobile en déplacement |
| Un tuteur ou un élève qui suit la journée | Application mobile |
| Un membre du personnel, par exemple un chauffeur | Application mobile |

<Callout title="Le même compte partout">
Connectez-vous avec le même compte sur les applications web et mobile. Si vous avez
plusieurs rôles, l'application mobile ouvre un seul espace — enseignant d'abord, puis
tuteur, élève et personnel — et n'a pas de sélecteur de rôle. Pour travailler dans un
autre rôle, utilisez l'application web.
</Callout>
