---
title: Activate the first timetable
description: Review a finished timetable group, activate it so class sessions appear, then watch the first live week.
---

When setup and generation are done, the last step before teaching runs day to day is to
**activate** a [timetable group](../../timetable/timetable-groups). Activation makes the week live
and creates dated **class sessions** for teachers, students, and parents.

<Callout title="Who this is for">
Academic planners releasing the first live schedule for the year.
</Callout>

## Before you activate

- The group is generated (or built by hand) and you have reviewed it by class, teacher, and room.
  See [Generate and activate](../../timetable/generate-and-publish).
- You are ready for those levels to follow this plan — activating retires any overlapping active
  group for the same levels.

## Steps

<Steps>

<Step>
### Review the group

Open **Academic → Timetable → Groups**, open your draft group, and scan the week. Fix clashes or
pin lessons you want to keep before you go live.
</Step>

<Step>
### Activate

Choose **Activate**. Confirm if the preview lists overlapping groups that will be retired. Full
detail: [Activate and class sessions](../../timetable/activate-and-sessions).
</Step>

<Step>
### Confirm sessions appear

After activation, dated class sessions are created from the weekly template. Teachers can open them
from the timetable and the Activity Journal. See
[Class sessions & attendance](../../teaching/sessions-and-attendance).
</Step>

<Step>
### Monitor the first days

Watch attendance take-up and any missing teacher assignments or room issues. If you need a change,
deactivate (or unlock as allowed), edit or re-generate, then activate again.
</Step>

</Steps>
