Une fois la base académique en place, configurez le fonctionnement au quotidien : comment les cours
sont planifiés, ce que paient les familles, comment la présence est prise, comment le comportement
est suivi et comment l'école communique. Chaque article donne l'ordre à suivre et renvoie aux
guides complets.

<Callout title="Pour qui">
Les administrateurs qui préparent l'année scolaire.
</Callout>
