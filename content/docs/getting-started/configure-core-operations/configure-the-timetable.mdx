Before you generate and activate a timetable, set the year-wide week and the inputs the generator
needs. Full guides live under [Timetable](../../timetable).

<Callout title="Who this is for">
Academic planners and school administrators.
</Callout>

## Before you start

- Classes, subjects, teachers, terms, and rooms already exist. See
  [Prerequisites](../../timetable/prerequisites).

## What to configure

1. **[School schedule](../../settings/school-schedule)** — year-wide default days, hours, and
   shared breaks (**Settings → Academic → School schedule**).
2. **[Timetable config](../../timetable/timetable-config)** — weekly grid for each group (inside
   the school schedule).
3. **[Teaching load](../../timetable/teaching-load)** and
   **[Teacher assignments](../../timetable/teacher-assignments)**.
4. **[Scheduling setup](../../timetable/scheduling-setup)** — availability and limits.
5. **[Timetable groups](../../timetable/timetable-groups)** — create the weekly template, then
   [generate and activate](../../timetable/generate-and-publish).
