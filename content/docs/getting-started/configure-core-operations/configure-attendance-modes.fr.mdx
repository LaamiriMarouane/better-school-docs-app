---
title: Configurer les modes de présence
---

Ce plan explique comment une école définit les approches de présence qu'elle souhaite suivre.

## Plan

### Pour qui

- Les administrateurs et les équipes des opérations pédagogiques.

### Prérequis

- Un accord sur le processus de présence utilisé par l'école.

### Sections clés

- Les modes de présence et quand les utiliser.
- Les options de statut ou les modalités d'enregistrement.
- Comment la configuration de la présence influe sur les opérations quotidiennes.
