---
title: Bulk enroll students
description: Enroll several pending pre-inscriptions of the same level at once.
---

**Bulk enrollment** turns several **pending pre-inscriptions** of the **same level** into
enrollments in one action. Class and payment plan are optional — you can assign them later from
the Enrollments hub.

<Callout title="Who this is for">
Administrators converting a batch of applications into enrollments.
</Callout>

## Before you start

- Pending **pre-inscriptions** exist for the same level — see [Pre-inscriptions](./pre-inscriptions).
- Optional: a **class** and/or **payment plan** for that level.

## Steps

<Steps>

<Step>
### Open Applications and select rows

Go to **Admissions & Enrollment → Applications** (Direct / Admin). Select pending
pre-inscriptions that share the **same level**, then choose **Enroll**.
</Step>

<Step>
### Confirm the batch fields

| Field | Required | Notes |
| --- | --- | --- |
| **Level** | Yes | Locked to the selection's level. |
| **Track** | When the level offers tracks | Required if tracks are offered; must stay consistent with each pre-inscription. |
| **Class** | No | Same class for everyone in the batch, or leave empty and assign later. |
| **Payment plan** | No | Shared plan for the batch, or leave empty and assign later. |
| **Enrollment date** | No | Defaults to today if left empty. |
| **Notes** | No | Optional notes for the batch. |
</Step>

<Step>
### Review the result

The form reports how many enrollments succeeded. Any that failed are listed with a reason — fix
those and retry if needed.
</Step>

</Steps>

<Callout title="Need different plans or classes?">
Bulk enroll can apply one shared class and plan. If students need different ones, leave those
fields empty and use **Assign Class** / **Assign Plan** on **Admissions & Enrollment →
Enrollments**, or change a single enrollment afterwards.
</Callout>
