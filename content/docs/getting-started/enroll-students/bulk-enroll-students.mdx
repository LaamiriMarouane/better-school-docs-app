---
title: Bulk enroll students
description: Enroll many students into the same class at once, with a shared payment plan.
---

**Bulk enrollment** registers several students into the **same class** in a single
action. It is the fastest way to populate a class at the start of a year.

<Callout title="Who this is for">
Administrators enrolling a whole class group at once.
</Callout>

## Before you start

- The **students** and the target **class** must already exist.
- A **payment plan** is required for bulk enrollment — it is applied to every student
  in the batch.

## Steps

<Steps>

<Step>
### Open the bulk enrollment form

From the Enrollments area, choose **Bulk enroll students**.

<Screenshot
  label="Bulk enrollment form"
  caption="Pick a level and class, select students, then choose a payment plan."
/>
</Step>

<Step>
### Choose the level and class

Select a **level** first, then the **class** within it. The class determines where
every selected student is enrolled.
</Step>

<Step>
### Select the students

Add each student to the **selected students** list. They will all be enrolled into the
chosen class.
</Step>

<Step>
### Set the plan and date

Complete the remaining fields, then submit.

| Field | Required | Notes |
| --- | --- | --- |
| **Class** | Yes | The class all selected students are enrolled into. |
| **Payment plan** | Yes | Applied to every student in the batch. |
| **Enrollment date** | No | Defaults to today if left empty. |
| **Notes** | No | Optional notes applied to the batch. |
</Step>

<Step>
### Review the result

The form reports how many enrollments succeeded. Any student that could not be
enrolled is listed with the reason — fix those and re-run if needed.
</Step>

</Steps>

<Callout title="Need different plans?">
Bulk enrollment applies one shared payment plan. If students need different plans,
enroll them individually or change a plan afterwards from the enrollment.
</Callout>
