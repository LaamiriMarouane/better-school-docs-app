---
title: Créer une inscription
description: Inscrivez un élève dans une classe pour une année scolaire, avec un échéancier de paiement.
---

Une **inscription** relie un élève à une **classe** pour une année scolaire donnée.
C'est elle qui place l'élève sur la liste de classe, la feuille de présence et
l'emploi du temps — et, lorsqu'un échéancier de paiement y est associé, ce qui génère
ses frais.

<Callout title="Pour qui">
Les administrateurs qui inscrivent les élèves dans les classes.
</Callout>

## Avant de commencer

- La fiche **élève** doit exister — voir [Ajouter des élèves](../onboard-people/add-students).
- La **classe** doit exister pour l'année scolaire sélectionnée — voir
  [Créer des classes](../build-the-academic-foundation/create-classes).
- Un **échéancier de paiement** à associer — il génère les frais et échéances de l'élève.

## Étapes

<Steps>

<Step>
### Ouvrir la page Inscriptions

Dans la barre latérale d'administration, allez dans **Académique → Inscriptions**, puis
démarrez une nouvelle inscription. Vérifiez que la bonne année scolaire est
sélectionnée dans le sélecteur d'année.
</Step>

<Step>
### Renseigner les détails de l'inscription

Complétez les champs ci-dessous.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Élève** | Oui | L'élève à inscrire. |
| **Classe** | Oui | La classe dans laquelle l'inscrire. Filtrez par niveau pour réduire la liste. |
| **Date d'inscription** | Oui | La date de prise d'effet de l'inscription. |
| **Échéancier de paiement** | Oui | L'échéancier qui génère les frais et échéances de l'élève. |
| **Notes** | Non | Notes facultatives sur l'inscription. |
</Step>

<Step>
### Enregistrer l'inscription

Validez le formulaire. L'élève apparaît désormais sur la liste de classe et dans la
liste des inscriptions.
</Step>

</Steps>

<Callout title="Une inscription par classe">
Un élève est inscrit dans une seule classe par année scolaire. Pour le déplacer
ensuite, utilisez [Transférer un élève entre classes](./transfer-a-student-between-classes)
plutôt que de créer une deuxième inscription.
</Callout>
