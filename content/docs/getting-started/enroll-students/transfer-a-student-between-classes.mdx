---
title: Change a student's class
description: Move an enrolled student to another class — and change level or track when needed.
---

**Change Class** updates an active enrollment's placement: **level**, **track** (when offered),
and **class**. The enrollment history keeps the change so the move is traceable.

<Callout title="Who this is for">
Administrators correcting or changing a student's placement.
</Callout>

## Before you start

- The student must have an **active enrollment**.
- The destination **level** / **class** must exist for the academic year.

## Steps

<Steps>

<Step>
### Open Change Class

On **Admissions & Enrollment → Enrollments**, open the enrollment's actions and choose
**Change Class**.
</Step>

<Step>
### Set the new placement

| Field | Required | Notes |
| --- | --- | --- |
| **Level** | Yes | Can stay the same or move to another level. |
| **Track** | When the level offers tracks | Required if that level has offered tracks. |
| **Class** | Yes | The class the student moves to. |
| **Reason** | Yes | Why the change is happening (stored on history). |
</Step>

<Step>
### Confirm

Confirm the change. The student appears on the new class roster; the previous placement stays in
history.
</Step>

</Steps>

<Callout title="Payment plans">
Changing class does not change the payment plan. To change fees, use **Change Payment Plan** on
the enrollment separately.
</Callout>
