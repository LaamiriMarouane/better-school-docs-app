---
title: Transfer a student between classes
description: Move an enrolled student from one class to another within the same academic year.
---

A **class transfer** moves an active enrollment from its current class to a different
one — for example when a student changes section. The enrollment history is kept, so
the move is traceable.

<Callout title="Who this is for">
Administrators correcting or changing a student's class placement.
</Callout>

## Before you start

- The student must have an **active enrollment** in the current class.
- The **destination class** must exist for the same academic year.

## Steps

<Steps>

<Step>
### Open the enrollment

Find the student's enrollment — from the Enrollments page or the student's profile —
and open its actions.

<Screenshot
  label="Transfer class action on an enrollment"
  caption="Transferring keeps the enrollment and records the move."
/>
</Step>

<Step>
### Choose the new class

Select the **destination class** the student should move to.
</Step>

<Step>
### Give a reason

Enter a **reason** for the transfer. You can add optional **notes** with more detail.
The reason is stored on the enrollment's history.

| Field | Required | Notes |
| --- | --- | --- |
| **New class** | Yes | The class the student moves to. |
| **Reason** | Yes | Why the transfer is happening. |
| **Notes** | No | Optional extra detail. |
</Step>

<Step>
### Confirm

Confirm the transfer. The student now appears on the new class roster, and the old
placement is recorded in the enrollment history.
</Step>

</Steps>

<Callout title="Payment plans">
A class transfer does not change the payment plan. To change fees, update the
enrollment's payment plan separately.
</Callout>
