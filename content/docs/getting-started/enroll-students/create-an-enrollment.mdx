---
title: Create an enrollment
description: Enroll a student into a class for an academic year, with a payment plan.
---

An **enrollment** links a student to a **class** for a given academic year. It is what
places the student on a class roster, attendance sheet, and timetable — and, when a
payment plan is attached, what drives their fees.

<Callout title="Who this is for">
Administrators registering students into classes.
</Callout>

## Before you start

- The **student** record must exist — see [Add students](../onboard-people/add-students).
- The **class** must exist for the selected academic year — see
  [Create classes](../build-the-academic-foundation/create-classes).
- A **payment plan** to attach — it generates the student's fees and installments.

## Steps

<Steps>

<Step>
### Open the Enrollments page

From the admin sidebar, go to **Academic → Enrollments**, then start a new enrollment.
Make sure the correct academic year is selected in the year switcher.
</Step>

<Step>
### Fill in the enrollment details

Complete the fields below.

| Field | Required | Notes |
| --- | --- | --- |
| **Student** | Yes | The student being enrolled. |
| **Class** | Yes | The class to enroll them into. Filter by level to narrow the list. |
| **Enrollment date** | Yes | The date the enrollment takes effect. |
| **Payment plan** | Yes | The plan that generates the student's fees and installments. |
| **Notes** | No | Optional notes about the enrollment. |
</Step>

<Step>
### Save the enrollment

Submit the form. The student now appears on the class roster and the Enrollments list.
</Step>

</Steps>

<Callout title="One enrollment per class">
A student is enrolled into one class per academic year. To move them later, use
[Transfer a student between classes](./transfer-a-student-between-classes) rather than
creating a second enrollment.
</Callout>
