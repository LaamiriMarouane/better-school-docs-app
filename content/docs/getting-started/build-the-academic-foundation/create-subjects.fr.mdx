---
title: Créer des matières
description: Ajoutez les matières enseignées dans votre école pour les affecter aux classes, aux enseignants et aux emplois du temps.
---

Une **matière** est un sujet enseigné dans votre école — par exemple *Mathématiques*,
*Physique* ou *Arabe*. Les matières sont affectées aux classes, liées aux enseignants
et placées dans l'emploi du temps. Leur création est l'une des premières étapes de la
fondation académique.

<Callout title="Pour qui">
Les administrateurs qui mettent en place le programme de l'école.
</Callout>

## Avant de commencer

- Préparez la liste de vos matières et leurs codes courts. Inutile de créer les salles d'abord :
  les types de salles se choisissent dans une liste fixe.

<Screenshot
  label="Page des matières avec le bouton Ajouter une matière"
  caption="La page Matières liste toutes les matières enseignées par votre école."
/>

## Étapes

<Steps>

<Step>
### Ouvrir la page Matières

Dans la barre latérale d'administration, allez dans **Académique → Matières**.
</Step>

<Step>
### Démarrer une nouvelle matière

Cliquez sur **Ajouter une matière** pour ouvrir le formulaire de création. Pour ajouter
plusieurs matières d'un coup, utilisez **Importer**.

<Screenshot
  label="Formulaire de création d'une matière"
  caption="Le formulaire : nom, code, description, couleur et types de salles autorisés."
/>
</Step>

<Step>
### Renseigner les détails de la matière

Complétez les champs ci-dessous, puis cliquez sur **Créer une matière**.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Nom de la matière** | Oui | Le nom affiché, ex. *Mathématiques*. |
| **Code** | Oui | Un identifiant court, ex. `MATH`. |
| **Description** | Non | Notes facultatives sur la matière. |
| **Couleur** | Non | Une couleur qui permet de repérer la matière dans l'emploi du temps. |
| **Types de salles autorisés** | Non | Choisissez dans la liste des types de salles (par exemple un laboratoire ou une salle informatique) pour restreindre les lieux où la matière peut être planifiée. Laissez vide pour autoriser toute salle. |
</Step>

<Step>
### Vérifier que la matière apparaît

La nouvelle matière est ajoutée immédiatement à la liste des matières. Répétez pour
chaque matière de votre programme.
</Step>

<Step>
### Lier les matières à vos niveaux

Dans la [Configuration de l'année scolaire](./academic-year-setup), l'étape **Associations de
matières** vous permet de choisir les matières étudiées par chaque niveau dans l'année que vous
préparez.
</Step>

</Steps>

<Callout title="Astuce">
Choisissez une **couleur** distincte pour chaque matière. L'emploi du temps devient
bien plus lisible une fois la planification commencée.
</Callout>
