---
title: Créer des classes
description: Créez les classes dans lesquelles les élèves sont inscrits au sein d'un niveau.
---

Une **classe** est un groupe d'élèves enseignés ensemble à un niveau donné — par
exemple *1re année — A*. Les élèves sont inscrits dans une classe, et l'emploi du temps
y planifie les cours. Chaque classe appartient à un **niveau**.

<Callout title="Pour qui">
Les administrateurs qui construisent la structure des classes d'une année scolaire.
</Callout>

## Avant de commencer

- Une **année scolaire** doit être sélectionnée dans le sélecteur d'année.
- Les **niveaux** doivent déjà exister — chaque classe est rattachée à un niveau. Voir
  [Créer des niveaux](./create-levels).

  label="Page des classes avec le bouton Ajouter une classe"

## Étapes

<Steps>

<Step>
### Ouvrir la page Classes

Dans la barre latérale d'administration, allez dans **Académique → Classes**, puis
cliquez sur **Ajouter une classe**.

<Screenshot
  label="Formulaire de création d'une classe"
  caption="Le formulaire de création : nom, code et niveau."
/>
</Step>

<Step>
### Renseigner les détails de la classe

Complétez les champs ci-dessous, puis cliquez sur **Créer la classe**.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Nom de la classe** | Oui | Le nom affiché, ex. *1re année — A*. |
| **Code** | Oui | Un identifiant court, 15 caractères maximum, ex. `1A-A`. |
| **Niveau** | Oui | Le niveau auquel appartient cette classe. À choisir parmi les niveaux créés. |
</Step>

<Step>
### Vérifier que la classe apparaît

La nouvelle classe est ajoutée immédiatement à la liste. Répétez pour chaque classe de
chaque niveau.
</Step>

</Steps>

<Callout title="Et ensuite">
Une fois les classes créées, vous pouvez y inscrire des élèves et construire l'emploi
du temps.
</Callout>
