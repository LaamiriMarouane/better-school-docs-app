---
title: Créer des niveaux
description: Définissez les niveaux ou années d'études qui organisent la hiérarchie académique de votre école.
---

Un **niveau** représente une classe ou une année d'études — par exemple *1re année*,
*6e* ou *Grade 1*. Les niveaux constituent l'ossature de votre structure académique :
les classes sont rattachées à des niveaux, et les élèves sont inscrits dans une classe
à un niveau donné.

Les niveaux sont regroupés sous des **niveaux d'éducation** (par exemple *Primaire* ou
*Collège*), et un niveau peut être divisé en **filières** (par exemple *Sciences* et
*Lettres*).

<Callout title="Pour qui">
Les administrateurs qui construisent la structure académique de l'école.
</Callout>

## Avant de commencer

- Préparez d'abord la liste complète de vos niveaux (par exemple *1re année* à
  *6e année*) et les niveaux d'éducation auxquels ils appartiennent, afin de garder des
  noms et des codes cohérents.

## Étapes

<Steps>

<Step>
### Ouvrir la page Structure académique

Dans la barre latérale d'administration, allez dans **Académique → Niveaux**. La page
affiche votre **Structure académique** sous forme d'arborescence : niveaux d'éducation,
puis niveaux, puis filières.
</Step>

<Step>
### Ajouter un niveau d'éducation

Cliquez sur **Ajouter un niveau d’éducation** et nommez-le — par exemple *Primaire*. Chaque
niveau se trouve sous un niveau d'éducation : créez donc ceux-ci en premier.
</Step>

<Step>
### Ajouter un niveau

Cliquez sur **Ajouter un niveau**, complétez les champs ci-dessous, puis cliquez sur
**Créer un niveau**.

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Niveau d’éducation** | Oui | Le groupe auquel appartient ce niveau. |
| **Label du niveau** | Oui | Le nom affiché dans toute l'application, ex. *1re année*. |
| **Code** | Oui | Un identifiant court, ex. `1A`. Utilisé dans les rapports et les emplois du temps. |
| **Promu vers** | Non | Le niveau vers lequel les élèves passent l'année suivante. Choisissez **Aucun (dernier niveau / fin de cycle)** pour le dernier niveau. |
| **Description** | Non | Notes facultatives sur le niveau. |
| **Mode de présence des étudiants** | Non | Comment la présence est relevée pour ce niveau — par jour ou par période. |
</Step>

<Step>
### Ajouter des filières (facultatif)

Si un niveau est divisé en filières, utilisez **Ajouter une filière** sur ce niveau et
nommez chaque filière.
</Step>

<Step>
### Utiliser les niveaux dans votre année scolaire

Dans la [Configuration de l'année scolaire](./academic-year-setup), l'étape **Niveaux**
vous permet de choisir les niveaux qui fonctionnent dans l'année que vous préparez.
</Step>

</Steps>

<Callout type="warn" title="Mode de présence">
Une fois la présence enregistrée pour un niveau, son **mode de présence** est verrouillé
et ne peut plus être modifié. Choisissez-le avec soin lors de la création du niveau.
</Callout>
