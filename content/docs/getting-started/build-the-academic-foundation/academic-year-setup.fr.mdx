---
title: Configuration de l'année scolaire
description: Parcourez la configuration guidée de l'année — confirmez chaque étape pour l'année, terminez la configuration et activez l'année.
---

La **Configuration de l'année** est un espace de travail guidé pour une année donnée. Vous
parcourez un court **verrou de définition** (requis avant l'activation), puis des étapes de
**préparation** (classes, enseignants, inscriptions, etc.). Une étape ne compte comme prête
qu'après avoir cliqué sur **Confirmer pour cette année**. Lorsque toutes les étapes du verrou sont
confirmées, vous cliquez sur **Terminer la configuration** puis sur **Activer l'année**.

<Callout title="Pour qui">
Les administrateurs qui préparent une nouvelle année scolaire avant les opérations quotidiennes.
</Callout>

## Ouvrir la configuration de l'année

1. Allez dans **Paramètres → Académique** et ouvrez l'onglet **Année académique**.
2. Ouvrez l'année avec **Voir les détails**.
3. Cliquez sur **Configuration de l'année** (ou **Ouvrir le centre de configuration** /
   **Démarrer la configuration** lorsqu'ils sont proposés après la création d'une année).

La configuration s'ouvre en plein écran. Tout se fait à l'intérieur, étape par étape. Utilisez
**Revenir à l'année** pour retourner à la page de l'année.

## Confirmer chaque étape pour l'année

Chaque carte d'étape affiche un statut :

| Statut | Signification |
| --- | --- |
| **Confirmée** | Vous avez confirmé l'étape pour cette année. Elle compte comme prête. |
| **Non confirmée** | Des données existent peut-être déjà, mais vous ne les avez pas encore confirmées. |
| **Ignoré** | Vous avez choisi **Ignorer pour l'instant** sur une étape de préparation. |

- Cliquez sur **Confirmer pour cette année** sur la carte de l'étape ou en haut de la page de
  l'étape, une fois son contenu vérifié.
- Une étape de définition ne peut être confirmée que si elle contient des données pour l'année.
- Une étape de préparation peut être confirmée même vide (par exemple, aucune ligne de transport
  cette année). L'application vous demande d'abord de confirmer ce choix.
- Cliquez sur **Annuler la confirmation** pour revenir sur une confirmation. Cliquez sur
  **Ignoré — annuler** pour annuler un « ignorer ».

## Verrou de définition

Vous devez confirmer toutes ces étapes avant de pouvoir terminer la configuration. Elles ne
peuvent pas être ignorées.

| Étape | Ce que vous faites |
| --- | --- |
| **Périodes** | Datez les périodes de l'année. |
| **Niveaux** | Activez les niveaux qui fonctionnent cette année. Pour un niveau avec filières, utilisez l'interrupteur de chaque filière pour indiquer si elle est proposée cette année. |
| **Matières** | Vérifiez que les matières enseignées par votre école existent. |
| **Associations de matières** | Indiquez quelles matières chaque niveau enseigne cette année (par période si besoin). |

## Étapes de préparation (ne bloquent jamais l'activation)

Les cartes de préparation restent verrouillées tant que le verrou de définition n'est pas
confirmé.

| Étape | Ce que vous faites |
| --- | --- |
| **Notation** | Vérifiez la configuration de la notation de l'année (mêmes outils que [Configuration des notes](../../teaching/grading-setup)). |
| **Classes** | Créez les classes des niveaux et filières qui fonctionnent cette année. |
| **Enseignants** | Sélectionnez les enseignants de l'année précédente et assignez-les à cette année. |
| **Supervisions** | Copiez ou définissez les responsabilités de supervision. |
| **Admissions / pré-inscriptions** | Décidez de la place de chaque élève qui revient : **Promouvoir**, **Redoubler**, **Diplômer** ou **Départ**. Vous pouvez décider maintenant ou envoyer la décision au parent pour confirmation, et ouvrir ou fermer la réinscription avec **Ouvrir la réinscription** / **Fermer la réinscription**. |
| **Inscriptions** | Inscrivez les élèves à un niveau, puis affectez une classe et un plan de paiement (tous deux facultatifs). Les élèves promus ou redoublants apparaissent sous **En attente d'inscription** : choisissez une classe (facultatif) et cliquez sur **Inscrire**. |
| **Transport** | Affiché lorsque le transport est utilisé. Copiez les zones et itinéraires de l'an dernier, voyez où habitent les élèves et confirmez les arrêts des élèves qui reviennent. |

Les élèves promus ou redoublants sont réinscrits pour la nouvelle année, mais ne sont pas encore
dans une classe. L'étape **Admissions / pré-inscriptions** indique combien attendent, avec
**Les inscrire** pour passer à l'étape **Inscriptions**.

### Frais et plans de paiement

La carte **Frais et plans de paiement** (visible pour les utilisateurs qui peuvent créer des frais
et des plans de paiement) permet de **Copier les frais et plans de paiement de l'année dernière** :
services, frais avec leurs prix par niveau, et plans de paiement. Ajustez ensuite les montants
dans les pages Finances. Cette carte n'est pas une étape et n'a pas besoin d'être confirmée.

Utilisez **Ignorer pour l'instant** sur une étape de préparation que vous terminerez après
l'activation.

## Terminer la configuration et activer

<Steps>

<Step>
### Terminer la configuration

Lorsque chaque étape de définition est confirmée, cliquez sur **Terminer la configuration**. S'il
manque une étape, le bouton reste désactivé et les étapes manquantes sont listées dessous.
Terminer la configuration n'active **pas** l'année à lui seul.
</Step>

<Step>
### Activer l'année

Lorsque la configuration est terminée et que l'année est encore un brouillon, cliquez sur
**Activer l'année**. L'année devient alors l'année active.
</Step>

</Steps>

<Callout title="La préparation est facultative pour l'activation">
Vous pouvez activer avec des classes vides ou des inscriptions inachevées. Les étapes de
préparation vous aident à être prêt à enseigner et facturer — elles ne bloquent pas
**Activer l'année**.
</Callout>
