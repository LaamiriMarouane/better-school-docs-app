---
title: Configuration de l'année scolaire
description: Parcourez le centre de configuration guidé — terminez le verrou de définition, puis les étapes de préparation, terminez la configuration et activez l'année.
---

La **Configuration de l'année** est un espace de travail guidé pour une année donnée. Vous
terminez un court **verrou de définition** (requis avant l'activation), puis des étapes de
**préparation** facultatives (classes, enseignants, notation, etc.). Lorsque le verrou est
satisfait, vous **Terminez la configuration** et **Activez** l'année.

<Callout title="Pour qui">
Les administrateurs qui préparent une nouvelle année scolaire avant les opérations quotidiennes.
</Callout>

## Ouvrir la configuration de l'année

1. Allez dans **Paramètres → Pédagogique** et ouvrez l'onglet **Année scolaire**.
2. Ouvrez l'année → **Détails de l'année**.
3. Cliquez sur **Configuration de l'année** (ou **Ouvrir le centre de configuration** /
   **Démarrer la configuration** lorsqu'ils sont proposés après la création d'une année).

La configuration s'ouvre en plein écran. Utilisez **Revenir à l'année** pour retourner aux
détails de l'année.

## Définition vs préparation

| Parcours | Étapes | Bloque l'activation ? |
| --- | --- | --- |
| **Définition** (verrou) | Périodes, Niveaux, Matières, Associations de matières | **Oui** — toutes doivent être satisfaites. |
| **Préparation** | Notation, Classes, Enseignants, Supervisions, Admissions / inscriptions, Inscriptions | **Non** — vous pouvez ignorer ou terminer plus tard. |

Terminez d'abord les étapes de définition. La navigation de préparation reste verrouillée jusqu'à
ce que le verrou soit satisfait.

## Étapes de définition (verrou)

| Étape | Ce que vous faites |
| --- | --- |
| **Périodes** | Ajoutez au moins une période avec des dates pour cette année. |
| **Niveaux** | Activez les niveaux scolaires qui tournent cette année. |
| **Matières** | Assurez-vous que la liste des matières de l'école existe (vocabulaire à l'échelle de l'école). |
| **Associations de matières** | Indiquez quelles matières chaque niveau enseigne cette année (par période si besoin). |

Vous ne pouvez pas ignorer une étape du verrou. Les compteurs et coches viennent de la
complétude en direct pour l'année.

## Étapes de préparation (ne bloquent jamais l'activation)

| Étape | Ce que vous faites |
| --- | --- |
| **Notation** | Politique de notation de l'année, catégories, barèmes et configuration associée (mêmes outils que [Configuration des notes](../../teaching/grading-setup)). |
| **Classes** | Créez les sections de classe pour les niveaux actifs. |
| **Enseignants** | Associez les enseignants à cette année (souvent depuis l'année précédente). |
| **Supervisions** | Copiez ou définissez les responsabilités de supervision / enseignant principal. |
| **Admissions / inscriptions** | Promouvez ou décidez des élèves qui reviennent depuis l'année précédente (première année : utilisez plutôt les admissions / l'intake manuel). |
| **Inscriptions** | Placez les élèves (niveau, classe et plan de paiement facultatifs) — se remplit au fil du temps. |

Utilisez **Ignorer pour l'instant** sur une étape de préparation si vous la terminerez après
l'activation. Vous pouvez annuler une ignore plus tard.

## Terminer la configuration et activer

<Steps>

<Step>
### Terminer la configuration

Lorsque chaque étape de définition est satisfaite, cliquez sur **Terminer la configuration**. Cela
marque la configuration de l'année comme terminée — cela n'active **pas** l'année à lui seul.
</Step>

<Step>
### Activer l'année

Lorsque la configuration est terminée et que l'année est encore un brouillon, cliquez sur
**Activer l'année**. Ce n'est qu'alors que l'année devient l'année d'exploitation active (selon
les règles d'année de votre école).
</Step>

</Steps>

<Callout title="La préparation est facultative pour l'activation">
Vous pouvez activer avec des classes vides ou des inscriptions inachevées. Les étapes
opérationnelles sont là pour vous préparer à enseigner et facturer — elles ne bloquent pas
**Activer l'année**.
</Callout>
