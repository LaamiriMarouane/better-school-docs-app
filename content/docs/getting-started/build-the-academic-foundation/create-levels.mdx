---
title: Create levels
description: Define the grade or year levels that organise your school's academic hierarchy.
---

A **level** represents a grade or year of study — for example *Grade 1*, *Year 7*, or
*Première année*. Levels are the backbone of your academic structure: classes are
attached to levels, and students are enrolled into a class at a given level.

Levels are grouped under **education levels** (for example *Primary* or *Middle school*),
and a level can be split into **tracks** (for example *Sciences* and *Literature*).

<Callout title="Who this is for">
Administrators building the school's academic structure.
</Callout>

## Before you start

- Plan your full list of levels first (for example *Grade 1* through *Grade 6*) and the
  education levels they belong to, so names and codes stay consistent.

## Steps

<Steps>

<Step>
### Open the Academic structure page

From the admin sidebar, go to **Academic → Levels**. The page shows your **Academic
structure** as a tree: education levels, then levels, then tracks.
</Step>

<Step>
### Add an education level

Click **Add education level** and name it — for example *Primary*. Every level sits under an
education level, so create these first.
</Step>

<Step>
### Add a level

Click **Add Level**, complete the fields below, then click **Create Level**.

| Field | Required | Notes |
| --- | --- | --- |
| **Education level** | Yes | The group this level belongs to. |
| **Level Label** | Yes | The display name shown across the app, e.g. *Grade 1*. |
| **Code** | Yes | A short identifier, e.g. `G1`. Used in reports and timetables. |
| **Promotes to** | No | The level students move up to next year. Choose **None (final level / graduation)** for the last level. |
| **Description** | No | Optional notes about the level. |
| **Student Attendance Mode** | No | How attendance is taken for this level — per day or per period. |
</Step>

<Step>
### Add tracks (optional)

If a level is split into streams, use **Add track** on that level and name each track.
</Step>

<Step>
### Use the levels in your academic year

In [Academic year setup](./academic-year-setup), the **Levels** step lets you choose which
levels run in the year you are preparing.
</Step>

</Steps>

<Callout type="warn" title="Attendance mode">
Once attendance has been recorded for a level, its **attendance mode** is locked and
can no longer be changed. Choose it carefully when you create the level.
</Callout>
