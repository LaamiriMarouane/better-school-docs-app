---
title: Create classes
description: Create the classes that students are enrolled into within a level.
---

A **class** is a group of students taught together at a given level — for example
*Grade 1 — A* or *Year 7 Blue*. Students are enrolled into a class, and the timetable
schedules lessons for it. Each class belongs to one **level**.

<Callout title="Who this is for">
Administrators building the class structure for an academic year.
</Callout>

## Before you start

- The **levels** must already exist — every class is attached to a level. See
  [Create levels](./create-levels).
- If a level has **tracks**, decide which track each class follows.

/>

## Steps

<Steps>

<Step>
### Open the Classes page

From the admin sidebar, go to **Academic → Classes**, then click **Add Class**.

<Screenshot
  label="Create class form"
  caption="The create class form: name, code and level."
/>
</Step>

<Step>
### Fill in the class details

Complete the fields below, then click **Create Class**.

| Field | Required | Notes |
| --- | --- | --- |
| **Class Name** | Yes | The display name, e.g. *Grade 1 — A*. |
| **Code** | Yes | A short identifier, e.g. `G1-A`. |
| **Level** | Yes | The level this class belongs to. Pick from the levels you created. |
| **Track** | Yes, for levels with tracks | Appears only when the chosen level has tracks. Pick the track this class follows. |
</Step>

<Step>
### Confirm the class appears

The new class is added to the list immediately. Repeat for every class in each level.
You can also create classes in the **Classes** step of
[Academic year setup](./academic-year-setup).
</Step>

</Steps>

<Callout title="What comes next">
Once classes exist you can enroll students into them and build the timetable.
</Callout>
