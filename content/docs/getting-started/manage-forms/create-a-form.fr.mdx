---
title: Créer un formulaire
description: Démarrer un nouveau formulaire d'admission ou général et l'ouvrir dans le constructeur.
---

Créer un formulaire définit son nom, sa catégorie et son type. Une fois créé, le
formulaire s'ouvre directement dans le **constructeur**, où vous concevez ses
champs.

<Callout title="Pour qui">
Les administrateurs qui collectent des candidatures ou des données via des
formulaires en ligne.
</Callout>

## Avant de commencer

- Sélectionnez l'**année scolaire** dans le sélecteur d'année. La page
  **Formulaires** liste les formulaires de l'année sélectionnée, et les nouveaux
  formulaires y sont créés. Voir
  [Créer une année scolaire](../build-the-academic-foundation/create-an-academic-year).
- Pour un formulaire d'**Admission**, les **niveaux** auxquels les candidats
  peuvent postuler doivent déjà exister — voir
  [Créer des niveaux](../build-the-academic-foundation/create-levels).
- Pour un formulaire **Privé**, les **audiences** que vous souhaitez cibler
  doivent exister.

## Étapes

<Steps>

<Step>
### Ouvrir la page Formulaires

Dans la barre latérale, allez dans **Académique** → **Formulaires**, puis
choisissez **Créer un formulaire**.
</Step>

<Step>
### Nommer le formulaire

Renseignez **Nom du formulaire** — les candidats comme les évaluateurs le voient.
Vous pourrez le renommer plus tard en touchant son nom en haut du constructeur.
</Step>

<Step>
### Choisir le mode

Choisissez l'une des trois cartes. Chacune définit ensemble la catégorie et le
type du formulaire — voir
[Types et catégories de formulaires](./form-types-and-categories).

| Carte | À utiliser pour |
| --- | --- |
| **Admission** | Les candidatures de nouveaux élèves. |
| **Public** | Un formulaire général que toute personne disposant du lien peut remplir. |
| **Privé** | Un formulaire général limité à des audiences sélectionnées. |
</Step>

<Step>
### Choisir les audiences (Privé uniquement)

Si vous avez choisi **Privé**, un champ **Audiences** apparaît. Choisissez au
moins une audience — seuls ses membres verront le formulaire.
</Step>

<Step>
### Créer et ouvrir le constructeur

Choisissez **Créer**. Le formulaire est créé en **Brouillon** et s'ouvre
directement dans le constructeur pour que vous conceviez ses champs.
</Step>

</Steps>

<Callout title="Les formulaires d'admission démarrent pré-construits">
Un formulaire d'Admission est créé avec les sections **Informations du tuteur** et
**Informations de l’élève** déjà en place. Vous choisissez ses niveaux et ajoutez
les champs nécessaires depuis le constructeur — voir
[Construire un formulaire](./build-a-form).
</Callout>

## Réutiliser un formulaire existant

Plutôt que de partir de zéro, vous pouvez copier un formulaire existant :

- **Dupliquer** — dans la liste **Formulaires**, ouvrez les actions de la ligne
  du formulaire et choisissez **Dupliquer**. Ajustez le nom si besoin, puis
  confirmez. Vous obtenez un nouveau brouillon avec les mêmes champs et
  paramètres.
- **Copier depuis une année** — en haut de la page **Formulaires**, choisissez
  **Copier depuis une année**. Choisissez l'**Année scolaire source**,
  sélectionnez le formulaire à copier, ajustez son nom si besoin et choisissez
  **Copier le formulaire**. La copie est créée en brouillon dans l'année sur
  laquelle vous travaillez.
