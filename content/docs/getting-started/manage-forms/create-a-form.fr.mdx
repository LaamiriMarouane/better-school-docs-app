---
title: Créer un formulaire
description: Démarrer un nouveau formulaire d'admission ou général et l'ouvrir dans le constructeur.
---

Créer un formulaire définit sa catégorie, son type et les règles qui l'entourent.
Une fois créé, le formulaire s'ouvre directement dans le **constructeur**, où vous
concevez ses champs.

<Callout title="Pour qui">
Les administrateurs qui collectent des candidatures ou des données via des
formulaires en ligne.
</Callout>

## Avant de commencer

- Une **année scolaire** doit être sélectionnée dans le sélecteur d'année — chaque
  formulaire appartient à une année. Voir
  [Créer une année scolaire](../build-the-academic-foundation/create-an-academic-year).
- Pour un formulaire d'**Admission**, les **niveaux** auxquels les candidats
  peuvent postuler doivent déjà exister — voir
  [Créer des niveaux](../build-the-academic-foundation/create-levels).
- Pour un formulaire **Privé**, les **audiences** que vous souhaitez cibler
  doivent exister.

## Étapes

<Steps>

<Step>
### Ouvrir la page Formulaires

Dans la barre latérale d'administration, allez dans **Formulaires**, puis
choisissez **Créer un formulaire**.
</Step>

<Step>
### Nommer le formulaire

Donnez au formulaire un nom clair — les candidats comme les évaluateurs le voient.
Le nom peut être modifié plus tard depuis le constructeur.
</Step>

<Step>
### Choisir le mode

Choisissez l'une des trois cartes. Chacune définit ensemble la catégorie et le
type du formulaire — voir
[Types et catégories de formulaires](./form-types-and-categories).

| Carte | À utiliser pour |
| --- | --- |
| **Admission** | Les candidatures de nouveaux élèves. |
| **Public** | Un formulaire général que toute personne disposant du lien peut remplir. |
| **Privé** | Un formulaire général limité à des audiences sélectionnées. |
</Step>

<Step>
### Renseigner les champs propres au mode

Selon la carte choisie, un champ supplémentaire apparaît.

| Champ | Apparaît pour | Remarques |
| --- | --- | --- |
| **Audiences** | Privé | Obligatoire. Les groupes autorisés à soumettre le formulaire. |
| **Niveaux** | Admission | Les niveaux auxquels les candidats peuvent postuler. |
</Step>

<Step>
### Créer et ouvrir le constructeur

Validez la boîte de dialogue. Le formulaire est créé en **brouillon** et s'ouvre
directement dans le constructeur pour que vous conceviez ses champs.
</Step>

</Steps>

<Callout title="Les formulaires d'admission démarrent pré-construits">
Un formulaire d'Admission est créé avec les sections **Élève** et **Responsable**
déjà en place. Vous ajoutez les champs nécessaires par-dessus — voir
[Construire un formulaire](./build-a-form).
</Callout>
