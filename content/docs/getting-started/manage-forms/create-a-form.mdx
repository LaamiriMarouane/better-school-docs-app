title: Create a form
description: Start a new admission or general form and open it in the builder.
---

Creating a form sets its name, category and type. Once created, the form opens
directly in the **builder**, where you design its fields.

<Callout title="Who this is for">
Administrators collecting applications or data through online forms.
</Callout>

## Before you start

- Select the **academic year** in the year switcher. The **Forms** page lists the
  forms of the selected year, and new forms are created there. See
  [Create an academic year](../build-the-academic-foundation/create-an-academic-year).
- For an **Admission** form, the **levels** applicants can apply to should already
  exist — see [Create levels](../build-the-academic-foundation/create-levels).
- For a **Private** form, the **audiences** you want to target should exist.

## Steps

<Steps>

<Step>
### Open the Forms page

In the sidebar, go to **Academic** → **Forms**, then choose **Create Form**.
</Step>

<Step>
### Name the form

Fill in **Form Name** — applicants and reviewers both see it. You can rename the
form later by tapping its name at the top of the builder.
</Step>

<Step>
### Choose the mode

Pick one of the three cards. Each sets the form's category and type together — see
[Form types and categories](./form-types-and-categories).

| Card | Use it for |
| --- | --- |
| **Admission** | New-student applications. |
| **Public** | A general form anyone with the link can fill in. |
| **Private** | A general form limited to selected audiences. |
</Step>

<Step>
### Pick the audiences (Private only)

If you chose **Private**, an **Audiences** field appears. Pick at least one
audience — only its members will see the form.
</Step>

<Step>
### Create and open the builder

Choose **Create**. The form is created as a **Draft** and opens straight into the
builder so you can design its fields.
</Step>

</Steps>

<Callout title="Admission forms start pre-built">
An Admission form is created with the **Guardian Information** and **Student
Information** sections already in place. You choose its levels and add the fields
you need from the builder — see [Build a form](./build-a-form).
</Callout>

## Reuse an existing form

Instead of starting from scratch, you can copy a form you already have:

- **Duplicate** — in the **Forms** list, open a form's row actions and choose
  **Duplicate**. Adjust the name if you want, then confirm. You get a new draft
  with the same fields and settings.
- **Copy from year** — at the top of the **Forms** page, choose **Copy from
  year**. Pick the **Source academic year**, select the form to copy, adjust its
  name if needed and choose **Copy form**. The copy is created as a draft in the
  year you are working in.
