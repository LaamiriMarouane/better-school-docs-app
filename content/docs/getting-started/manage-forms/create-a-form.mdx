---
title: Create a form
description: Start a new admission or general form and open it in the builder.
---

Creating a form sets its category, type, and the rules around it. Once created,
the form opens directly in the **builder**, where you design its fields.

<Callout title="Who this is for">
Administrators collecting applications or data through online forms.
</Callout>

## Before you start

- An **academic year** must be selected in the year switcher — every form belongs
  to one year. See [Create an academic year](../build-the-academic-foundation/create-an-academic-year).
- For an **Admission** form, the **levels** applicants can apply to should already
  exist — see [Create levels](../build-the-academic-foundation/create-levels).
- For a **Private** form, the **audiences** you want to target should exist.

## Steps

<Steps>

<Step>
### Open the Forms page

From the admin sidebar, go to **Forms**, then choose **Create form**.
</Step>

<Step>
### Name the form

Give the form a clear name — applicants and reviewers both see it. The name can be
changed later from the builder.
</Step>

<Step>
### Choose the mode

Pick one of the three cards. Each sets the form's category and type together — see
[Form types and categories](./form-types-and-categories).

| Card | Use it for |
| --- | --- |
| **Admission** | New-student applications. |
| **Public** | A general form anyone with the link can fill in. |
| **Private** | A general form limited to selected audiences. |
</Step>

<Step>
### Set the mode-specific fields

Depending on the card you chose, one extra field appears.

| Field | Appears for | Notes |
| --- | --- | --- |
| **Audiences** | Private | Required. The groups allowed to submit the form. |
| **Levels** | Admission | The levels applicants may apply to. |
</Step>

<Step>
### Create and open the builder

Submit the dialog. The form is created as a **draft** and opens straight into the
builder so you can design its fields.
</Step>

</Steps>

<Callout title="Admission forms start pre-built">
An Admission form is created with **Student** and **Guardian** sections already in
place. You add the fields you need on top of that — see [Build a form](./build-a-form).
</Callout>
