---
title: Récupérer votre enfant
description: "Prévenez l'école de votre arrivée avec Je suis là, puis suivez votre enfant jusqu'à la remise — sur le web ou dans l'application mobile."
---

Quand vous arrivez pour récupérer votre enfant, appuyez sur **Je suis là**. L'école voit votre
arrivée immédiatement, fait sortir votre enfant, et vous suivez chaque étape sur votre téléphone.

<Callout title="Où la trouver">
Dans le portail parent, ouvrez **Récupération**. Dans l'application mobile, ouvrez **Sortie**
depuis le menu. Elle apparaît quand votre école utilise le module **Sortie**.
</Callout>

## Signaler votre arrivée

<Steps>

<Step>
### Vérifier que la récupération est ouverte

Sur le web, le haut de la page affiche la récupération du jour : **Récupération ouverte jusqu'à**
une heure, **Ouvre à** une heure, ou **Fermé pour aujourd'hui**. Vous ne pouvez signaler votre
arrivée que pendant l'ouverture.
</Step>

<Step>
### Choisir qui vous récupérez

Sous **Qui venez-vous chercher ?** (**Qui est récupéré ?** dans l'application mobile), touchez
chaque enfant que vous récupérez. Vous pouvez choisir plusieurs enfants pour une même arrivée.
</Step>

<Step>
### Choisir votre porte

Si l'école a plusieurs portes, choisissez celle où vous attendez dans **Choisir une porte**.
</Step>

<Step>
### Appuyer sur Je suis là

Appuyez sur **Je suis là**. L'école et les enseignants de votre enfant sont prévenus de votre
arrivée.
</Step>

</Steps>

## Suivre votre enfant

Chaque enfant signalé affiche une carte avec votre numéro dans la file, la porte, et trois étapes :

| Étape | Ce que cela signifie |
| --- | --- |
| **En attente** | L'école sait que vous êtes là. Votre enfant sera bientôt libéré. |
| **En route** | Votre enfant a quitté la classe et arrive à la porte. |
| **Remis** | Votre enfant vous a été remis. |

Dans l'application mobile, chaque enfant affiche la même progression sous forme de statut :
**En attente de libération**, **En route**, puis **Remis**. Tirez vers le bas pour actualiser.

Vous recevez aussi une notification quand votre enfant est en route et quand il est remis. Sur le
web, les enfants récupérés aujourd'hui apparaissent sous **Terminé aujourd'hui**.

Tant que votre enfant est **En attente**, vous pouvez annuler l'arrivée avec **Annuler l'arrivée**
(**Annuler** dans l'application mobile), puis confirmer.

## Quand vous ne pouvez pas signaler votre arrivée

| Vous voyez | Pourquoi |
| --- | --- |
| **Prend le bus aujourd'hui — contactez l'école pour le récupérer à la porte.** | Votre enfant prend le bus scolaire aujourd'hui. Appelez l'école si vous voulez le récupérer vous-même. |
| **L'arrivée des parents est désactivée pour cette école.** | Votre école enregistre les familles à la porte. |
| **L'école n'a pas encore défini de porte de récupération.** | L'école n'a pas fini de configurer la récupération. |
| **Aucun enfant n'est lié à ce compte.** | Demandez à l'école de lier vos enfants à votre compte. |

Si l'école vous a indiqué que vous ne pouvez pas récupérer un enfant, vous ne pourrez pas signaler
votre arrivée pour cet enfant.
