title: Record incidents

An **incident** records a single behaviour event for a student — what happened, under which category
and level, when, and how many points it's worth.

<Callout title="Who this is for">
Teachers and administrators recording student behaviour.
</Callout>

## Who can record

- **Administrators** can record an incident for any student.
- **Teachers** can record incidents for students in the **classes they teach**.

Students and parents can only view — see [Points & leaderboard](./leaderboard).

## Record an incident

<Steps>

<Step>
### Open incidents

Go to **Behaviour → Student Incidents**, then choose **Add incident**.
</Step>

<Step>
### Fill in the incident

| Field | Required | Notes |
| --- | --- | --- |
| **Class** | No | Pick the class first to narrow the student list, or leave **All classes**. Teachers only see the classes they teach. |
| **Student** | Yes | Search for the student the incident is for. |
| **Category** | Yes | The kind of behaviour (positive or negative). |
| **Subcategory** | No | A finer label, if the category has any. |
| **Level** | Yes | The level of significance — it sets the points. |
| **Description** | Yes | What happened. |
| **Incident date** | Yes | When it happened. |
| **Location** | No | Where it happened, if relevant. |
| **Points** | Yes | Pre-filled from the level. |
</Step>

<Step>
### Save

Choose **Add incident**. The incident is recorded, and its points count toward the student's total.
</Step>

</Steps>

<Callout title="Points come from the level">
When you pick a **level**, its default points fill in. You can lower them for a single incident: enter
a whole number between 0 and the level's points (for a negative level, between the level's points
and 0). The allowed range shows under the field.
</Callout>

## Find an incident

Use the search box, or open the filter to narrow the list by **Sentiment** (positive or negative) and
**Incident date range**.

## Edit or delete

Open the row's actions menu and choose **Edit** or **Delete**. The student's points update
accordingly.

- **Administrators** can edit or delete any incident.
- **Teachers** can edit or delete only the incidents they recorded.

## Common use cases

- **Reward good behaviour** — record a positive incident so it adds to the student's points.
- **Fix a mistake** — edit the incident and correct the level, points, or description.
