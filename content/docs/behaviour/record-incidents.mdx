---
title: Record incidents
description: Log a behaviour event for a student, set its points, and add follow-up actions like a parent call or detention.
---

An **incident** records a single behaviour event for a student — what happened, under which category
and level, when, and how many points it's worth. You can also attach **follow-up actions**.

<Callout title="Who this is for">
Teachers and administrators recording student behaviour.
</Callout>

## Who can record

- **Administrators** can record an incident for any student.
- **Teachers** can record incidents for students in the **classes they teach**.

Students and parents can only view — see [Points & leaderboard](./leaderboard).

## Record an incident

<Steps>

<Step>
### Open incidents

Go to **Behaviour → Incidents**, then choose **Add incident**.
</Step>

<Step>
### Fill in the incident

| Field | Required | Notes |
| --- | --- | --- |
| **Student** | Yes | The student the incident is for. Teachers see only students in their own classes. |
| **Category** | Yes | The kind of behaviour (positive or negative). |
| **Sub-category** | No | A finer label, if the category has any. |
| **Level** | Yes | The level of significance — it sets the points. |
| **Points** | Yes | Pre-filled from the level; adjust if needed. Positive levels add, negative subtract. |
| **Description** | Yes | What happened. |
| **Date** | Yes | When it happened. |
| **Location** | No | Where it happened, if relevant. |
</Step>

<Step>
### Save

The incident is recorded, and its points count toward the student's total.
</Step>

</Steps>

<Callout title="Points come from the level">
When you pick a **level**, its default points fill in automatically. You can change the value for a
single incident — but whether it **adds or subtracts** comes from the level's positive/negative side.
</Callout>

## Add a follow-up action

An incident can have one or more **actions** — the steps taken in response, such as a parent call, a
detention, or counselling. Open an incident and add an action:

| Field | Required | Notes |
| --- | --- | --- |
| **Action** | Yes | What was done — e.g. *Parent phone call*, *Detention*. |
| **Notes** | No | Any detail or context. |
| **Date** | Yes | When the action took place. |

## Edit or delete

Open an incident to change its details, add or remove actions, or delete it. The student's points
update accordingly.

## Common use cases

- **Reward good behaviour** — record a positive incident so it adds to the student's points.
- **Log a problem and follow up** — record a negative incident, then add a *Parent phone call*
  action once you've contacted the family.
- **Fix a mistake** — open the incident and correct the level, points, or description.
