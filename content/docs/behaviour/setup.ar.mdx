قبل تسجيل أيّ سلوك، تُعِدّ **المصطلحات** التي تستخدمها مدرستك: **فئات** السلوك، و**فئات فرعية**
اختيارية، و**مستويات** الأهمية. وكلٌّ منها مُميَّز **إيجابيًا** أو **سلبيًا**، كي يعرف النظام هل يضيف
نقاطًا أم يطرحها.

<Callout title="لمن هذا الدليل">
المسؤولون الذين يُعِدّون نظام السلوك للسنة.
</Callout>

## العناصر

| العنصر | ما هو |
| --- | --- |
| **الفئة** | نوع السلوك — مثل *الاحترام*، *المساعدة*، *الإخلال*، *التأخّر*. مُميَّز إيجابيًا أو سلبيًا، بلون. |
| **الفئة الفرعية** | تسمية أدقّ اختيارية تحت فئة (مثلًا تحت *الإخلال*: *الكلام*، *استخدام الهاتف*). |
| **المستوى** | درجة أهمية لها **نقاط افتراضية** — مثل *بسيط* / *جسيم*، أو *برونزي / فضّي / ذهبي* للإيجابيات. ويقرّر جانبه الإيجابي أو السلبي هل تُضاف النقاط أم تُطرَح. |

عند تسجيل حادثة، تختار **فئة**، واختياريًا **فئة فرعية**، و**مستوى** — وتصف معًا ما حدث ومقدار قيمته.

## إنشاء فئة

<Steps>

<Step>
### افتح إعداد السلوك

انتقل إلى **السلوك ← الإعداد**، حيث تُدار الفئات والمستويات.
</Step>

<Step>
### أضِف فئة

| الحقل | إلزامي | ملاحظات |
| --- | --- | --- |
| **الاسم** | نعم | مثل *الاحترام* أو *الإخلال*. |
| **النوع** | نعم | **إيجابي** أو **سلبي**. |
| **اللون** | لا | لون لتمييزها بنظرة. |
</Step>

<Step>
### أضِف فئات فرعية (اختياري)

تحت فئة، أضِف تسميات أدقّ إن شئت — مثل *الكلام* و*الهاتف* تحت *الإخلال*.
</Step>

</Steps>

## إنشاء مستوى

| الحقل | إلزامي | ملاحظات |
| --- | --- | --- |
| **الاسم** | نعم | مثل *بسيط*، *جسيم*، *ذهبي*. |
| **النوع** | نعم | **إيجابي** أو **سلبي**. |
| **النقاط الافتراضية** | نعم | النقاط التي تساويها حادثة في هذا المستوى. تُعبّأ مسبقًا عند التسجيل، وقابلة للتعديل. |
| **الترتيب** | نعم | موضع المستوى بين مستويات النوع نفسه. |
| **اللون** | لا | لون للمستوى. |

<Callout title="الإيجابي أو السلبي يحدّد النقاط">
المستوى المُميَّز **إيجابيًا** يضيف إلى نقاط الطالب؛ والمستوى **السلبي** يطرح منها. اجعل الإيجابيات
سخيّة لمكافأة السلوك الحسن، والسلبيات متناسبة مع المشكلات.
</Callout>
