title: Configuration de l'emploi du temps
description: Définissez une grille hebdomadaire pour un groupe — jours ouvrés, heures quotidiennes, durée des créneaux et pauses — à l'intérieur des horaires de l'école.
---

Une **configuration d'emploi du temps** décrit la forme d'une semaine scolaire pour un ou plusieurs
[groupes d'emploi du temps](./timetable-groups) : les jours d'enseignement, les heures de la
journée, la durée d'un créneau et le moment des pauses. Le générateur la découpe en une grille de
créneaux et y place chaque séance.

Elle se situe **à l'intérieur** des [horaires de l'école](../settings/school-schedule) de l'année.
Les horaires de l'école sont le défaut extérieur ; une configuration peut les reprendre ou utiliser
une journée **plus étroite** (moins de jours, heures plus courtes, ou pauses supplémentaires).

<Callout title="Pour qui">
Les administrateurs qui définissent la grille hebdomadaire utilisée par les groupes.
</Callout>

## Deux niveaux : horaires de l'école et configuration

| Niveau | Où | Rôle |
| --- | --- | --- |
| **Horaires de l'école** | **Paramètres → Académique → Horaires de l'école** | Défaut global de l'année — jours, heures d'ouverture, durée par défaut, pauses partagées. |
| **Configuration** | **Académique → Emploi du temps → Configuration → Grille horaire** | Grille liée à un groupe (ex. primaire vs secondaire). Doit tenir dans les horaires de l'école. |

Lorsque vous créez une **nouvelle** configuration, le formulaire est **prérempli** depuis les
horaires de l'école. Vous pouvez ensuite le resserrer pour certains niveaux — par exemple le niveau
1 finit plus tôt avec deux courtes pauses, tandis que les niveaux 2–3 gardent une journée plus
longue.

<Callout title="Validation">
Une configuration ne peut pas enseigner un jour fermé dans les horaires de l'école, ni commencer
avant / finir après les heures scolaires, ni entrer en conflit avec les pauses scolaires. Corrigez
d'abord les horaires de l'école si la fenêtre extérieure est fausse.
</Callout>

## Où cela se trouve

Allez dans **Académique → Emploi du temps → Configuration**. La page comporte plusieurs onglets :

| Onglet | Ce qu'il couvre |
| --- | --- |
| **Grille horaire** | Les configurations elles-mêmes — jours, heures, durée des créneaux, pauses (cet article). |
| **Charge d'enseignement** | Combien de séances chaque matière nécessite par semaine. Voir [Charge d'enseignement](./teaching-load). |
| **Enseignants / Salles / Salles attitrées / Horaires des classes** | Disponibilité, limites et politiques de salles. Voir [Réglages de planification](./scheduling-setup). |

## Avant de commencer

- Une **année scolaire** doit être sélectionnée.
- Les **[horaires de l'école](../settings/school-schedule)** de cette année doivent être réglés —
  les nouvelles configurations en héritent, et les enregistrements sont vérifiés par rapport à eux.

## Créer une configuration

<Steps>

<Step>
### Ouvrir l'onglet Grille horaire

Allez dans **Académique → Emploi du temps → Configuration**, restez sur **Grille horaire**, et
cliquez sur **Ajouter une configuration** (ou ouvrez celle qui existe pour la modifier).

<Screenshot
  label="Formulaire de configuration de l'emploi du temps"
  caption="Définissez les jours, les heures, la durée des créneaux et les pauses de la semaine de ce groupe."
/>
</Step>

<Step>
### Renseigner les détails

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Nom** | Oui | Un libellé pour cette configuration, ex. *Primaire 2025–26*. |
| **Jours ouvrés** | Oui | Les jours d'enseignement de cette configuration. Doivent figurer parmi les jours des **horaires de l'école**. |
| **Heures quotidiennes** | Oui | Début et fin de la journée pour cette configuration. Doivent tenir dans les heures scolaires. |
| **Durée des créneaux** | Oui | Minutes par créneau, ex. *45*. |
| **Créneaux max. par jour** | Oui | Le maximum de créneaux d'une classe en une journée. |
| **Séparateur de demi-journée** | Non | Heure qui sépare matin et après-midi, ex. *12:00*. |
| **Pauses** | Non | Moments sans séance. Les pauses scolaires sont incluses au départ ; vous pouvez en ajouter d'autres sans conflit. |
</Step>

<Step>
### Enregistrer

La configuration est enregistrée pour l'année sélectionnée. Associez-la quand vous créez ou
modifiez un [groupe d'emploi du temps](./timetable-groups).
</Step>

</Steps>

## Comment la grille est construite

À partir de la configuration, le système détermine les **créneaux horaires** qu'une séance peut
occuper. Par exemple, une journée 08:00–17:00 avec des créneaux de 45 minutes et un déjeuner de
12:00–13:00 produit une série de créneaux le matin, un déjeuner protégé, et une série l'après-midi.

<Callout title="Les pauses sont protégées">
Aucune séance n'est jamais placée par-dessus une pause. Utilisez les pauses pour le déjeuner, la
récréation, la prière, ou tout moment où ces niveaux doivent être libres.
</Callout>

## Le séparateur de demi-journée

Le **séparateur de demi-journée** est le moment où votre journée se divise en matin et après-midi
(souvent à midi). Le définir débloque des règles par demi-journée. S'il est vide, ces règles ne
s'appliquent pas.

## Utiliser plusieurs configurations

Vous pouvez créer **plusieurs configurations** pour la même année — par exemple une grille pour le
primaire et une autre pour le secondaire — tant que chacune reste dans les
[horaires de l'école](../settings/school-schedule). Chaque [groupe](./timetable-groups) utilise une
configuration.

## Conseils et bonnes pratiques

- Réglez d'abord les **horaires de l'école**, puis créez des configurations qui les reprennent ou
  les resserrent.
- Faites correspondre la **durée des créneaux** à l'enseignement réel de ces niveaux.
- Mettez les pauses **partagées** dans les horaires de l'école ; les extras propres aux niveaux
  dans la configuration.
- Définissez le **séparateur de demi-journée** si vous voulez des règles matin/après-midi.
