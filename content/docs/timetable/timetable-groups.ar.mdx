**مجموعة الجدول الزمني** هي **قالب أسبوعي** لـ**فصل دراسي** ومجموعة مختارة من **المستويات**. تحتفظ
بخطة الأسبوع المتكرّرة (أي صفّ لديه أي مادة ومعلّم وقاعة وحصة) والقواعد المستخدمة لبنائها. إنها
*نمط* الأسبوع — وليست بعد درسًا مؤرّخًا في يوم تقويم معيّن.

<Callout title="لمن هذا الدليل">
المخطّطون الأكاديميون والمسؤولون الذين ينظّمون جداول المدرسة ويقارنون بينها.
</Callout>

## ما هي المجموعة

| العنصر | المعنى |
| --- | --- |
| **الاسم** | تسمية تختارها، مثل *الفصل 1 — الابتدائي* أو *الخيار ب — جمعة أقصر*. |
| **الفصل الدراسي** | الفصل الذي تنتمي إليه هذه الخطة الأسبوعية. |
| **المستويات** | المستويات التي تغطّيها هذه المجموعة. |
| **إعداد الجدول** | أيام وأساعات واستراحات أسبوع هذه المجموعة. راجع [إعداد الجدول الزمني](./timetable-config). |
| **الشبكة الأسبوعية** | الجدول المملوء (أو المسوّدة) لكل صفّ في تلك المستويات. |

عندما **تفعّل** المجموعة لاحقًا، يتحوّل القالب الأسبوعي إلى **حصص صفّ** حقيقية بتاريخ ووقت.
راجع [التفعيل وحصص الصفّ](./activate-and-sessions).

## لماذا تنشئ أكثر من مجموعة

أسباب شائعة:

- **فصل إعدادات المستويات** — المستوى 1 يستخدم شكل يوم (ساعات واستراحات)؛ المستويان 2–3
  يستخدمان آخر. كل مجموعة تشير إلى [الإعداد](./timetable-config) المناسب.
- **متغيّرات وتجارب** — ابنِ *الخيار أ* و*الخيار ب*، قارن، وفعّل فقط ما تختاره. تبقى المسوّدات
  غير مرئية للمعلّمين والعائلات.
- **أسابيع خاصّة** — نمط مختلف لأسبوع امتحانات أو أسبوع مختصر، مع الإبقاء على الأسبوع العادي
  في مجموعة أخرى.

يمكنك أيضًا **استنساخ** مجموعة كمسوّدة جديدة لتحتفظ بنفس القواعد مع شبكة فارغة وتجرّب ترتيبًا
جديدًا.

## أين تعيش المجموعات

انتقل إلى **الأكاديمي ← الجدول ← المجموعات**. افتح مجموعة لتحرير شبكتها، أو تشغيل المُولِّد، أو
ضبط القيود، أو تغيير حالتها.

## حالات المجموعة

| الحالة | المعنى |
| --- | --- |
| **مسوّدة** | يراها ويعدّلها المخطّطون فقط. ليست حيّة للمدرسة. |
| **نشِطة** | الخطة الأسبوعية المعمول بها لمستوياتها. تُنشئ [حصص صفّ](./activate-and-sessions). |
| **غير نشِطة** | لم تعد تولّد حصصًا؛ يُسمح بالتعديل بعد إلغاء التفعيل. |
| **مؤرشفة** | محفوظة للتاريخ؛ لم تعد الخطة المعمول بها. |

يمكن أن يُضاف **قفل** فوق الحالة: أثناء القفل لا يمكنك سحب الحصص أو حفظ تعديلات الشبكة حتى
تُلغِي القفل (أو تلغي التفعيل إن كانت نشِطة).

## الإجراءات المتاحة

| الإجراء | متى تستخدمه |
| --- | --- |
| **إنشاء** | بدء قالب أسبوعي جديد لفصل ومستويات وإعداد. |
| **استنساخ كمسوّدة جديدة** | نسخ سياسة المجموعة وإعدادها إلى مسوّدة جديدة بشبكة **فارغة** — مناسب لمتغيّر جديد. |
| **توليد** | دع المُولِّد يملأ الأسبوع. راجع [التوليد والتفعيل](./generate-and-publish). |
| **تعديل يدوي** | انقل الحصص، غيّر القاعة، ثبّت ما تريد الإبقاء عليه. |
| **قفل / إلغاء القفل** | احمِ مسوّدة منتهية، أو جمّد مجموعة نشِطة من التعديلات العرضية. |
| **تفعيل** | اجعلها الأسبوع المعمول به لمستوياتها وأنشئ حصصًا مؤرّخة. |
| **إلغاء التفعيل** | أوقف الاستخدام الحيّ، اسمح بالتعديل من جديد، ثم فعّل عند الجاهزية. |
| **أرشفة** | احتفظ بالمجموعة للرجوع عندما لم تعد حيّة. |
| **طباعة / عروض** | راجع أو اطبع حسب الصفّ أو المعلّم أو القاعة. |
