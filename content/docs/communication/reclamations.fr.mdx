---

Une **réclamation** est une plainte adressée à l'école — au sujet d'une note, de frais, ou de tout
autre chose. Les parents (et les élèves, si l'école l'autorise) l'envoient et suivent son statut.
Les administrateurs la prennent en charge et la clôturent avec une note que la famille peut lire.

<Callout title="Module requis">
Les réclamations nécessitent le module **Réclamations**. Si vous ne les voyez pas, demandez à la
personne qui gère les modules de votre école de l'activer.
</Callout>

## Statuts

| Statut | Ce que cela signifie |
| --- | --- |
| **En attente** | Envoyée, pas encore traitée. |
| **En cours** | Un administrateur l'a prise en charge. |
| **Résolue** | Clôturée, avec une note expliquant comment elle a été résolue. |
| **Rejetée** | Clôturée, avec une note expliquant pourquoi elle a été rejetée. |

## Types

| Type | Pour… |
| --- | --- |
| **Problème de note** | Une question ou un désaccord sur une note. |
| **Problème de frais** | Une question ou un problème lié à des frais ou à un paiement. |
| **Général** | Un sujet scolaire général. |
| **Autre** | Tout le reste. |

## Autoriser les élèves à envoyer des réclamations

Les parents peuvent toujours en envoyer tant que le module est activé. Les élèves ne le peuvent que
si vous l'autorisez.

Allez dans **Paramètres → Établissement**, ouvrez l'onglet **Réclamations**, et activez **Les élèves
peuvent créer des réclamations**. Quand l'option est désactivée, les élèves voient un message les
invitant à contacter un parent ou l'administration.

## Envoyer une réclamation (parents et élèves)

<Steps>

<Step>
### Ouvrir Réclamations

Sur le web, allez dans **Communication → Réclamations**. Dans l'application mobile, ouvrez
**Réclamations** depuis le menu.
</Step>

<Step>
### Choisir l'enfant (parents)

Une réclamation concerne un seul enfant. Sélectionnez d'abord cet enfant dans le sélecteur
d'enfant — le formulaire indique pour quel enfant elle est.
</Step>

<Step>
### Remplir le formulaire

Cliquez sur **Nouvelle réclamation**, puis choisissez le **Type** et saisissez un **Titre** et une
**Description** du problème.
</Step>

<Step>
### Envoyer

Cliquez sur **Envoyer**. La réclamation apparaît dans votre liste en **En attente**.
</Step>

</Steps>

Votre liste affiche chaque réclamation avec son statut. Quand l'école répond, vous recevez une
notification, et la réclamation indique qui l'a traitée et la **Note de résolution**.

## Traiter les réclamations (administrateurs)

Allez dans **Communication → Réclamations**. La liste affiche toutes les réclamations avec leur
auteur. Utilisez la recherche, **Tous les statuts** et **Tous les types** pour la filtrer. Cliquez
sur une réclamation pour voir le détail : l'**Élève**, **Soumise par**, **Traitée par**, le
**Message** et son **Historique**.

| Action | Quand | Ce qui se passe |
| --- | --- | --- |
| **Prendre en charge** | **En attente** | Elle passe **En cours**, avec votre nom comme responsable. |
| **Résoudre** | **En cours** | Saisissez une **Note de résolution**, puis confirmez. Elle passe à **Résolue**. |
| **Rejeter** | **En attente** ou **En cours** | Saisissez une **Note de résolution** expliquant pourquoi, puis confirmez. Elle passe à **Rejetée**. |
| Supprimer | À tout moment | Supprime définitivement la réclamation, après confirmation. |

Vous recevez une notification à chaque nouvelle réclamation, et la famille est prévenue quand son
statut change.
