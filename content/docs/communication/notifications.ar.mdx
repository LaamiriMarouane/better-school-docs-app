تُبقيك **الإشعارات** على اطّلاع عند حدوث شيء — إعلان جديد، أو حدث قادم، أو واجب مُصحَّح، أو دفعة
مستحقّة. أنت تتحكّم في **ما** تُنبَّه إليه و**كيف** يصلك كل تنبيه.

<Callout title="لمن هذا الدليل">
الجميع. يدير كل شخص إعدادات إشعاراته الخاصة.
</Callout>

## كيف يمكن تنبيهك

يمكن أن يصلك كل نوع من الإشعارات عبر **قناة** واحدة أو أكثر:

| القناة | ما هي |
| --- | --- |
| **داخل التطبيق** | قائمة الإشعارات (الجرس) داخل التطبيق. |
| **البريد الإلكتروني** | يُرسَل إلى بريدك الإلكتروني. |
| **إشعار فوري (Push)** | نافذة من متصفّحك، حتى عندما لا يكون التطبيق مفتوحًا. |

## بماذا يمكن تنبيهك

لن ترى إلا الفئات التي تخصّ دورك. الفئات الشائعة:

| الفئة | تنبّهك بـ |
| --- | --- |
| **الإعلانات** | إعلان جديد منشور لك. |
| **الأحداث** | حدث جديد، أو تذكير قبل بدئه. |
| **الواجبات والدرجات** | واجبات جديدة، ومواعيد نهائية، وأعمال مُصحَّحة، ونتائج امتحانات منشورة. |
| **المدفوعات** | فواتير جديدة، ودفعات مستحقّة، ودفعات مؤكَّدة. |
| **الجدول الزمني** | تغييرات الجدول — جدول جديد، وتغيير قاعات، واستبدال معلّمين، وجداول امتحانات. |
| **النقل** | انتهاء وثائق المركبات (للمسؤولين). |
| **التذكيرات** | تذكيرات النظام، مثل اقتراب انتهاء سنة دراسية أو سنة مالية. |

## تغيير إعدادات إشعاراتك

<Steps>

<Step>
### افتح إعدادات إشعاراتك

انتقل إلى **إعدادات الإشعارات** (في ملفك الشخصي أو منطقة الإعدادات).
</Step>

<Step>
### فعّل الفئات أو عطّلها

لكل فئة، فعّل الإشعارات أو عطّلها. عطّل ما لا تريد سماعه.
</Step>

<Step>
### اختر كيفية تنبيهك

للفئات التي تُبقيها مفعّلة، اختر **القنوات** المراد استخدامها — داخل التطبيق، أو البريد، أو الإشعار
الفوري، أو مزيجًا. واحفظ تغييراتك.
</Step>

</Steps>

<Callout title="كتم محادثة أمر مختلف">
تتحكّم إعدادات الإشعارات في تنبيهات المنصّة. ولإسكات محادثة بعينها، **اكتمها** من داخل المحادثة —
راجع [المراسلة](./messaging).
</Callout>

## حالات استخدام شائعة

- **البريد للمهمّ فقط** — أبقِ المدفوعات والإعلانات على البريد، والباقي داخل التطبيق.
- **داخل التطبيق فقط** — عطّل البريد والإشعار الفوري، وراجع الجرس عندما تكون في التطبيق.
- **متابعة الدرجات عن كثب** — أبقِ الواجبات والدرجات مفعّلة مع الإشعار الفوري لتُنبَّه فورًا.
