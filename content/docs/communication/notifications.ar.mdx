تُبقيك **الإشعارات** على اطّلاع عند حدوث شيء — إعلان جديد، أو حدث قادم، أو واجب مُصحَّح، أو دفعة
مستحقّة. وتُجمَع في مكان واحد لتلحق بكل جديد بنظرة سريعة.

<Callout title="لمن هذا الدليل">
الجميع. يرى كل شخص الإشعارات التي تخصّه.
</Callout>

## أين تظهر الإشعارات

| المكان | ما تحصل عليه |
| --- | --- |
| **الجرس** | يعرض الجرس أعلى الشاشة أحدث إشعاراتك وعدد غير المقروء منها. |
| **صفحة الإشعارات** | القائمة الكاملة لإشعاراتك. افتحها من **عرض جميع الإشعارات** في الجرس. |
| **تطبيق الهاتف** | إشعارات فورية على هاتفك، لتُنبَّه حتى عندما يكون التطبيق مغلقًا. |

## قراءة الإشعارات ومسحها

<Steps>

<Step>
### افتح الجرس

انقر على **الجرس** لرؤية أحدث إشعاراتك. تظهر غير المقروءة منها مميَّزة.
</Step>

<Step>
### افتح إشعارًا

انقر على إشعار للانتقال مباشرة إلى ما يتعلّق به — الإعلان أو الواجب أو الدفعة وغير ذلك. واستخدم
**وضع علامة كمقروء** لمسح إشعار دون فتحه.
</Step>

<Step>
### الحق بكل شيء دفعة واحدة

استخدم **وضع علامة على الكل كمقروء** لمسح كل شيء مرة واحدة، أو افتح **عرض جميع الإشعارات**
لتصفّح القائمة الكاملة.
</Step>

</Steps>

## بماذا يمكن تنبيهك

لن ترى إلا الإشعارات التي تخصّ دورك. الشائعة منها:

| الفئة | تنبّهك بـ |
| --- | --- |
| **الإعلانات** | إعلان جديد منشور لك. |
| **الأحداث** | حدث جديد، أو تذكير قبل بدئه. |
| **الواجبات والدرجات** | واجبات جديدة، ومواعيد نهائية، وأعمال مُصحَّحة، ونتائج امتحانات منشورة. |
| **المدفوعات** | فواتير جديدة، ودفعات مستحقّة أو متأخّرة، ودفعات مؤكَّدة أو ملغاة أو مستردّة. |
| **الجدول الزمني** | تغييرات الجدول — جدول جديد، وتغيير قاعات، واستبدال معلّمين، وجداول امتحانات. |
| **الإجازات** | طلب إجازة، وعند الموافقة عليه أو رفضه أو إلغائه. |
| **الشكاوى** | شكوى جديدة، أو تغيّر في حالتها. |
| **النقل** | مستجدّات الحافلة للأولياء، وانتهاء وثائق المركبات والسائقين للمسؤولين. |
| **التذكيرات** | تذكيرات مثل اقتراب انتهاء سنة دراسية أو سنة مالية. |
