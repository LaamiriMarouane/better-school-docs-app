An **announcement** is a one-way message you publish to chosen audiences — news, reminders, or
notices. People in the audiences read it; they don't reply (for two-way conversations, use
[Messages](./messaging)).

<Callout title="Who this is for">
Administrators, who create and publish announcements. Teachers, students and parents read the
announcements meant for them.
</Callout>

## Before you start

- Make sure the [audiences](./audiences) you need already exist. You pick them in the announcement
  form; you can't create one from there.

## Create an announcement

<Steps>

<Step>
### Open Announcements

Go to **Communication → Announcements**, then choose **Add Announcement**.

<Screenshot
  label="Announcements list with the Add announcement button"
  caption="Your school's announcements are listed here."
/>
</Step>

<Step>
### Write the announcement

Complete the fields below.

| Field | Required | Notes |
| --- | --- | --- |
| **Title** | Yes | A short headline. |
| **Audiences** | Yes | Who receives it. Pick one or more [audiences](./audiences). |
| **Content** | Yes | The body of the announcement. You can format it — headings, bold, lists, and links. |
| **Attachments** | No | Up to 5 files to share alongside the message. |
| **Upload Thumbnail** | No | A cover image shown with the announcement. |

<Screenshot
  label="Create announcement form"
  caption="Title, rich-text content, audience, and optional attachments."
/>
</Step>

<Step>
### Choose a status and save

Set **Status**, then choose **Create Announcement**:

- **Draft** — keep working on it. Only administrators see drafts.
- **Published** — send it now. The announcement becomes visible to its audiences, and the people
  in them are [notified](./notifications).
</Step>

</Steps>

<Callout title="Publishing is immediate">
An announcement goes live the moment it's published — there's no scheduled release. If you need
it to appear later, save it as a draft and publish it at that time.
</Callout>

## Edit, publish, unpublish, or delete

Open the menu on an announcement's card:

- **Edit** — change its title, audiences, content, or attachments.
- **Publish** — send a draft to its audiences.
- **Unpublish** — hide a published announcement again (for example if it was sent by mistake). It
  returns to draft and is no longer visible to the audiences.
- **Delete** — remove the announcement entirely.

## Who sees an announcement

Only the people in the announcement's **audiences** see it, on web and mobile. Choose the
audiences carefully — for example *all parents*, *Year 5 students*, or a list of specific people.
See [Audiences](./audiences).

## Common use cases

- **School-wide notice** — publish to audiences that include everyone.
- **Year-group reminder** — publish to a level audience that includes that level's guardians.
- **Draft now, publish later** — prepare the announcement as a draft and use **Publish** when the
  time is right.
