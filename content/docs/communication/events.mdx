An **event** is a dated entry on the school calendar — an activity, a meeting, an exam, a
holiday, or a closure. Events appear on the calendar for the people you choose, and some of them
(holidays and closures) also tell the rest of the platform that the school is closed that day.

<Callout title="Who this is for">
Administrators, who manage the school calendar. Teachers, students and parents see the events
shared with them, read-only.
</Callout>

## Create an event

<Steps>

<Step>
### Open Events

Go to **Communication → Events**, then choose **Add Event** (or select a day on the calendar).

<Screenshot
  label="Events calendar with the Add event button"
  caption="The school calendar, with events colour-coded by type."
/>
</Step>

<Step>
### Fill in the event details

| Field | Required | Notes |
| --- | --- | --- |
| **Event Title** | Yes | The name of the event. |
| **Event Type** | Yes | A school-defined category with its own colour — e.g. *Activity*, *Meeting*, *Exam*. See [Event types](#event-types). |
| **Location** | No | Where it takes place. |
| **Kind** | No | How the day is treated — *Normal*, *Holiday*, *Closure*, *Exam day*, or *Early dismissal*. Defaults to *Normal* (see below). |
| **Start Date / End Date** | Yes | The date and time. An event can last one day or span several. |
| **Description** | No | More details about the event. |
| **Custom Color** | No | Overrides the type's colour for this one event. Leave empty to use the type's colour. |
| **Public Event** | — | Turn on to show the event to the audiences you choose. Leave off to keep it for administrators only. |
| **Audiences** | Yes, when public | Who sees the event. Appears when **Public Event** is on. See [Audiences](./audiences). |
| **Notify Participants** | — | Appears when **Public Event** is on. |
| **Thumbnail** | No | A cover image for the event. |
</Step>

<Step>
### Save

Choose **Create Event**. The event appears on the calendar for everyone who can see it.
</Step>

</Steps>

## Event kinds

The **Kind** tells the platform how to treat the day. Most events are *Normal*; two kinds change
what the rest of the platform does:

| Kind | What it means |
| --- | --- |
| **Normal** | A regular event — activity, meeting, trip. The default. |
| **Holiday** | A non-teaching day. **Closes the school** — the timetable and transport skip those days. |
| **Closure** | An unplanned closure (for example bad weather). **Closes the school**, the same as a holiday. |
| **Exam day** | Marks an exam day on the calendar. |
| **Early dismissal** | Marks a shortened day on the calendar. |

<Callout title="Holidays and closures close the school">
Only **Holiday** and **Closure** change school operations: no timetable sessions and no bus trips
take place on those dates. **Exam day** and **Early dismissal** are calendar labels.
</Callout>

## Event types

An **event type** is a reusable category with a name and a colour — for example *Activity*,
*Meeting*, *Exam*, *Parent meeting*. Types keep the calendar readable: every event of the same
type shares a colour. Open **Event Types** on the Events page to add, edit, or delete types, then
pick one each time you add an event.

## Who sees an event

- **Public Event on** — the event is shown to the people in the **Audiences** you pick (for
  example *Year 5 guardians* for a Year 5 trip).
- **Public Event off** — only administrators see the event. Use this for internal planning.

People in the audiences get a [notification](./notifications) when a public event is added, and a
reminder the day before it starts.

## View, edit, or delete

- Switch the calendar between **Month**, **Week**, **Day**, and **List**, and filter by event type.
- Select an event to see its details. Administrators can **Edit** or **Delete** it from there.

<Callout title="Events don't repeat">
Each event is a single entry. There's no automatic weekly/monthly repeat — for a recurring event,
add one entry per occurrence.
</Callout>

## Common use cases

- **School holiday** — add an event with the kind *Holiday* so the day is closed everywhere.
- **Snow day** — add a *Closure* for the affected date.
- **Class trip** — add a *Normal* event, turn **Public Event** on, and choose the audience for that
  class or level.
- **Exam week** — add events marked *Exam day* for each exam.
