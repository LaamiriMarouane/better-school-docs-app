**الحدث** مُدخَل مؤرَّخ في التقويم المدرسي — نشاط أو اجتماع أو امتحان أو عطلة أو إغلاق. تظهر
الأحداث في التقويم للأشخاص الذين تختارهم، وبعضها (العطل والإغلاقات) يُخبر أيضًا بقية المنصّة بأن
المدرسة مغلقة ذلك اليوم.

<Callout title="لمن هذا الدليل">
المسؤولون والمعلّمون الذين يديرون التقويم المدرسي.
</Callout>

## إنشاء حدث

<Steps>

<Step>
### افتح الأحداث

انتقل إلى **التواصل ← الأحداث**، ثم اختر **إضافة حدث**.

<Screenshot
  label="تقويم الأحداث مع زر إضافة حدث"
  caption="التقويم المدرسي، والأحداث ملوّنة حسب النوع."
/>
</Step>

<Step>
### املأ تفاصيل الحدث

| الحقل | إلزامي | ملاحظات |
| --- | --- | --- |
| **العنوان** | نعم | اسم الحدث. |
| **النوع** | نعم | فئة تحدّدها المدرسة بلونها الخاص — مثل *نشاط* أو *اجتماع* أو *امتحان*. راجع [أنواع الأحداث](#أنواع-الأحداث). |
| **الطبيعة** | لا | كيف يتعامل النظام مع اليوم — *عادي* أو *عطلة* أو *إغلاق* أو *يوم امتحان* أو *انصراف مبكّر*. الافتراضي *عادي* (انظر أدناه). |
| **البداية / النهاية** | نعم | التاريخ والوقت. قد يدوم الحدث يومًا أو عدّة أيام. |
| **الوصف** | لا | مزيد من التفاصيل عن الحدث. |
| **المكان** | لا | أين يجري. |
| **اللون** | لا | يتجاوز لون النوع لهذا الحدث وحده. |
| **عام** | — | عند تفعيله، يراه الجميع. وعند تعطيله، لا يراه إلا الجمهور المختار. |
| **الجمهور** | لا | من يرى الحدث حين لا يكون عامًّا. راجع [الجماهير](./audiences). |
| **إشعار المشاركين** | — | عند تفعيله، يُنبَّه الجمهور بالحدث. |
| **الصورة المصغّرة** | لا | صورة غلاف للحدث. |
</Step>

<Step>
### احفظ

يظهر الحدث في التقويم لكل من يمكنه رؤيته.
</Step>

</Steps>

## طبائع الحدث

تُخبر **الطبيعة** النظامَ بكيفية التعامل مع اليوم. معظم الأحداث *عادية*؛ وطبيعتان تغيّران فعلًا ما
تفعله بقية المنصّة:

| الطبيعة | المعنى |
| --- | --- |
| **عادي** | حدث اعتيادي — نشاط أو اجتماع أو رحلة. وهو الافتراضي. |
| **عطلة** | يوم بلا تدريس. **يُغلق المدرسة** — فلا تُنشأ رحلات حافلات، ويُعدّ اليوم مغلقًا عبر المنصّة. |
| **إغلاق** | إغلاق غير مخطّط (مثل سوء الأحوال الجوية). **يُغلق المدرسة** كالعطلة. |
| **يوم امتحان** | يميّز يوم امتحان. للعلم فقط. |
| **انصراف مبكّر** | يميّز يومًا مختصرًا. للعلم فقط. |

<Callout title="العطل والإغلاقات تُغلق المدرسة">
**عطلة** و**إغلاق** فقط هما اللذان يغيّران حاليًا تشغيل المدرسة — فيُميّزان اليوم مغلقًا، فلا تُنشأ
مثلًا أيّ رحلات نقل. أما **يوم امتحان** و**انصراف مبكّر** فهما حاليًا تسميتان في التقويم.
</Callout>

## أنواع الأحداث

**نوع الحدث** فئة قابلة لإعادة الاستخدام لها اسم ولون — مثل *نشاط* أو *اجتماع* أو *امتحان* أو
*اجتماع أولياء الأمور*. تُبقي الأنواع التقويم مقروءًا: تتشارك كل أحداث النوع نفسه اللون. أدِر أنواع
مدرستك من قسم الأحداث، ثم اختر نوعًا في كل مرّة تضيف فيها حدثًا.

## من يرى الحدث

- **عام** — فعّل «عام» ليراه الجميع.
- **حسب الجمهور** — اترك «عام» معطّلًا واختر [جمهورًا](./audiences) لتقييد من يراه (مثل *أولياء أمور
  السنة الخامسة* لرحلة السنة الخامسة).

## الإشعار والإلغاء

- **إشعار المشاركين** — فعّل هذا لتنبيه الجمهور بالحدث. ويُنبَّه الأشخاص وفق
  [إعدادات الإشعارات](./notifications) الخاصة بهم.
- **إلغاء حدث** — يُخفي الإلغاء الحدث عن الجميع مع الاحتفاظ بسجلّ له. استخدمه بدل الحذف عندما يُعلَن
  حدث ثم يُلغى.

<Callout title="الأحداث لا تتكرّر">
كل حدث مُدخَل واحد. لا يوجد تكرار أسبوعي/شهري تلقائي — للحدث المتكرّر، أضِف مُدخَلًا لكل مرّة.
</Callout>

## حالات استخدام شائعة

- **عطلة مدرسية** — أضِف حدثًا من طبيعة *عطلة* ليكون اليوم مغلقًا في كل مكان.
- **يوم ثلجي** — أضِف *إغلاقًا* للتاريخ المعنيّ.
- **رحلة صفّية** — أضِف حدثًا *عاديًا*، وأبقِه خاصًّا، واختر جمهور الصف.
- **أسبوع الامتحانات** — أضِف أحداثًا مميّزة بـ*يوم امتحان* لكل امتحان.
