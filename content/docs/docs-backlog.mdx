## How to use this list

1. Pick one row.
2. Read the live UI (and matching sidebar labels) before writing.
3. Match the existing docs voice — short paragraphs, tables for fields, `Steps` for procedures, `Callout` for warnings.
4. Ship EN, FR, and AR together, and update this table when done.
