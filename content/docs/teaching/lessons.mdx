A **lesson** is one teaching unit inside a chapter of a [course template](./courses). It has two
parts: its **details** (type, duration, objectives), set in the course template, and its
**content** — the material each teacher writes for students. You also control **who can see** your
content in each class.

<Callout title="Who this is for">
Teachers preparing and sharing lesson material.
</Callout>

## Lesson details

Each lesson carries some structure, set in [Course Templates](./courses):

| Detail | What it is |
| --- | --- |
| **Lesson Type** | *Theory, Practical, Lab, Exercise, Review, Assessment, Project, Presentation, Discussion,* or *Field Trip*. |
| **Duration (Weeks)** | Roughly how many weeks the lesson takes. |
| **Objectives** | What students should learn by the end. |
| **Prerequisites** | What students should already know first. |
| **Activities** | What students do during the lesson. |

While writing content, open **Curriculum template** to see these details for the current lesson
without leaving the editor.

## Write the lesson content

You can add or edit a lesson's content if you're **assigned to teach that subject to a class**.
Open **My Courses**, choose a subject, then pick a lesson in the
outline. This is separate from who *edits the course template* — see [Course templates](./courses).

Each teacher writes their **own version** of a lesson's content in a rich editor:

- **Format text** — headings, bold and italic, lists, quotes, and code blocks.
- **Add media** — images and YouTube videos.
- **Insert equations** — mathematical formulas, inline or as blocks.

Your work **saves automatically** as you write; you can also choose **Save Changes**.

### Assets

The **Assets** panel beside the editor holds what goes with the lesson:

- **Attachments** — choose **Add file** to attach worksheets, slides or any supporting document.
- **Boards** — choose **Attach board** to link a whiteboard from your boards, or create a new one.

### Import existing content

To reuse material you've already written, choose **Import existing content**. Pick the academic
year, search or filter by grade and subject, and select one of your lesson contents. It replaces the
current content and attachments of this lesson (you're asked to confirm with **Replace and
import**). The imported copy stays hidden from students until you make it visible.

<Callout title="Each teacher keeps their own content">
Two teachers teaching the same lesson to different classes each have their own content for it. Your
content is yours — other teachers don't change it.
</Callout>

## Control who sees a lesson

There's no publish step. A student sees your content only when you make it **visible** for their
class. Save your content first, then choose **Manage class visibility**.

<Steps>

<Step>
### Pick a class

The dialog lists the classes you teach this subject to. Select one.
</Step>

<Step>
### Set the lesson's progress

For the selected class, set the lesson to **Not Started**, **In Progress**, **Completed** or
**Skipped**, so you can follow where each class is in the outline.
</Step>

<Step>
### Turn visibility on or off

Under **Content items**, switch **Your content** to **Visible** or **Hidden** for the whole class
(**All**). If the class is split into groups, you can switch each group separately.
</Step>

</Steps>

Content written by another teacher for the same class — for example the class's previous teacher —
also appears in the list with their name. Only its author can change its visibility.

<Callout title="Visibility is immediate">
There's no scheduled release. Students see the content as soon as you switch it to visible. To
reveal a lesson later, switch it on then.
</Callout>

## Common use cases

- **Prepare ahead** — write several lessons and keep them hidden, then make each visible as you reach
  it.
- **Different pace per class** — make a lesson visible to one class now and another class later.
- **Reuse last year's material** — use **Import existing content** and pick last year's lesson.
