A **lesson** is one teaching unit inside a chapter of a [course](./courses). It has two parts: its
**details** (type, duration, objectives) and its **content** — the actual material a teacher writes
for students. You also control **who can see** each lesson.

<Callout title="Who this is for">
Teachers preparing and sharing lesson material.
</Callout>

## Lesson details

Each lesson carries some structure, set when you build the course:

| Detail | What it is |
| --- | --- |
| **Type** | The kind of lesson — *Theory, Practical, Lab, Exercise, Review, Assessment, Project, Presentation, Discussion,* or *Field trip*. |
| **Duration** | Roughly how long the lesson takes, in minutes. |
| **Objectives** | What students should learn by the end. |
| **Prerequisites** | What students should already know first. |
| **Activities** | What students do during the lesson — reading, exercises, a video, a quiz, homework, group work, an experiment, and so on. |

## Write the lesson content

You can add or edit a lesson's content if you're **assigned to teach that subject to a class** this
year (administrators always can). You reach the subjects you teach from **My Courses**, then open a
lesson. This is separate from who *manages the curriculum* — see [Courses](./courses).

Each teacher writes their **own version** of a lesson's content in a rich editor:

- **Format text** — headings, bold and italic, lists, quotes, and code blocks.
- **Add media** — images, videos, and YouTube embeds.
- **Insert equations** — mathematical formulas, inline or as blocks.
- **Attach files** — worksheets, slides, or any supporting document.

Your work **saves automatically** as you write.

<Callout title="Each teacher keeps their own content">
Two teachers teaching the same lesson to different classes each have their own content for it. Your
content is yours — other teachers don't change it.
</Callout>

## Publish and control who sees a lesson

Two things decide whether a student sees a lesson:

<Steps>

<Step>
### Publish your content

A lesson's content stays a **draft** until you **publish** it. Drafts are visible only to you.
</Step>

<Step>
### Choose which classes can see it

Set each class — or each group within a class — to **Can view** or **No access**. This is how you
decide which of your classes see this lesson.
</Step>

</Steps>

A student sees the lesson only when **both** are true: the content is **published** *and* their
class is set to **Can view**.

<Callout title="Publishing is immediate">
There's no scheduled publishing. A lesson becomes visible the moment you publish it and the class is
allowed to view it. To reveal a lesson later, publish it then.
</Callout>

## Common use cases

- **Prepare ahead** — write several lessons as drafts, then publish each as you reach it.
- **Different pace per class** — publish a lesson to one class now and another class later by
  changing each class's view access.
- **Reuse last year's material** — carried-over lessons keep their content, ready to update.
