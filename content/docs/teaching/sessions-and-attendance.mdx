title: Class sessions & attendance
description: Run each class meeting from the timetable — log what was taught and homework, take student attendance, and close the session.

A **class session** is one real meeting of a class. Sessions are created when you
**[activate a timetable group](../timetable/activate-and-sessions)** — the weekly template in a
[timetable group](../timetable/timetable-groups) becomes dated meetings. Teachers **take attendance**
and **log what was covered** from the session on the **Timetable**, and review their teaching record
in the **Activity journal**.

<Callout title="Who this is for">
Teachers running their classes day to day, and administrators overseeing sessions and attendance.
</Callout>

## Where to find your sessions

- **Timetable** — your sessions on the weekly schedule. Open a session's menu to **Mark Attendance**,
  **Add Activity**, or record how the session went.
- **Activity journal** — choose a term, a class and a date range to see its sessions and what was
  recorded in each. Switch between **List view** (sessions on one side, details on the other) and
  **Kanban view** (sessions grouped by subject). You can also add or edit a session's activity here.

## Session statuses

| Status | Meaning |
| --- | --- |
| **Scheduled** | An upcoming session from the timetable. |
| **In progress** | The session is happening now. |
| **Completed** | The session took place. |
| **Auto-completed** | A past session closed automatically because nobody marked it. |
| **Cancelled** | The session was called off. |
| **No show** | The class didn't take place. |

## Session actions

From a session's menu on the **Timetable**:

- **Mark as completed** or **Mark as no-show** — the session's teacher or an administrator records
  how a session went, on the day of the session or later.
- **Cancel Session** — administrators can call off a session from today onwards, with an optional
  **Cancellation Reason**. A cancelled session can be restored with **Uncancel Session**.
- **Edit Session** and **Add Session** — administrators can change a session's details or add a
  one-off session.

## Log what was taught

Choose **Add Activity** on a session (from the timetable or the journal) and record:

- **Topics** covered — use **Link lesson** to tie a topic to a lesson from the course template.
- Any **Homework** set.
- **Notes** and **Attachments** — observations or files for the record.

Add at least one item, then save. You can record activity from the day of the session onwards,
even before it starts — not for a session on a later day, nor for a cancelled one. Saving the
activity marks the session **Completed**.

## Take attendance

How attendance is taken depends on the **Student Attendance Mode** of the class's **level**, set in
the level's settings:

| Mode | How it works |
| --- | --- |
| **Per Period** | Attendance is taken **for each session** — by the teacher from the **Timetable**, or by an administrator there or on the **Student Attendance** page. |
| **Per Day** | Attendance is taken **once a day** by administrators, on the **Student Attendance** page. |

See [Configure attendance modes](../getting-started/configure-core-operations/configure-attendance-modes).

### Mark attendance for a session

For levels in **Per Period** mode:

1. On the **Timetable**, open the session's menu and choose **Mark Attendance**. You can mark a
   session from its day onwards, even before it starts — not a session on a later day, nor a
   cancelled one.
2. Every student starts as **Present** — change only the exceptions. If the session is for one
   group of the class, only that group's students are listed.
3. Add **Remarks** for a student who isn't present, if needed.
4. Choose **Save Attendance**. Saving the attendance marks the session **Completed**.

Attendance can be taken or changed for today and a set number of past days, so a missed session can
still be recorded shortly after. An administrator sets that number in **Attendance → Student
Attendance → Configure Attendance** — see
[Configure attendance modes](../getting-started/configure-core-operations/configure-attendance-modes).
After that, the session's attendance is locked for teachers; administrators can still change it.

### Attendance statuses

| Status | Meaning |
| --- | --- |
| **Present** | The student attended. |
| **Absent** | The student didn't attend. |
| **Late** | The student arrived late. |
| **Half Day** | The student attended part of the day. |

### Attendance sheets (PDF)

From the **Mark Attendance** panel you can download:

- **Download attendance marking sheet (PDF)** — a blank register to fill in on paper.
- **Download attendance taken sheet (PDF)** — the recorded attendance, once it's been taken.

You choose the document language before the download.

## Student Attendance page (administrators)

Administrators find **Attendance → Student Attendance** in the menu. Choose a class and a **Week**
or **Month** view to see its attendance as a grid, one row per student:

- For a **Per Day** level, there is **one column per day**.
- For a **Per Period** level, there is **one column per session**, labelled with the day and the
  subject.

To take or change attendance, select a column header (**Edit this column**), set each student's
status — or use **Set all to** — and choose **Save Attendance**. Future days can't be marked.

The **settings** button at the top of the page (**Configure Attendance**) holds the school's
past-days window — see
[Configure attendance modes](../getting-started/configure-core-operations/configure-attendance-modes).

## Common use cases

- **Daily teaching log** — after class, record the topics and homework so families can follow along.
- **Mark the register** — take attendance in each session, or once a day for per-day levels.
- **Lesson didn't happen** — mark the session as no-show, or have an administrator cancel it.
- **Backfill** — enter yesterday's attendance within the allowed window.
