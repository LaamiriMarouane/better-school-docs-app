**الواجب** عمل تكلّف به صفًّا — واجب منزلي، أو مشروع، أو مقال. يمكن للطلاب تسليم أعمالهم عبر الإنترنت،
وتصحّحها مع ملاحظات، وتنتقل الدرجة إلى [سجلّ الدرجات](./gradebook).

<Callout title="لمن هذا الدليل">
المعلّمون الذين يكلّفون بالأعمال ويصحّحونها، والطلاب الذين يسلّمونها.
</Callout>

## إنشاء واجب

<Steps>

<Step>
### افتح الواجبات

انتقل إلى **الواجبات** واختر **إضافة واجب**.
</Step>

<Step>
### املأ التفاصيل

| الحقل | إلزامي | ملاحظات |
| --- | --- | --- |
| **العنوان** | نعم | اسم الواجب. |
| **الوصف** | لا | تعليمات للطلاب. |
| **الصف** *(والمجموعة)* | نعم | لمن هو. اختر مجموعة لتكليف جزء من صفّ مقسّم. |
| **تاريخ الإتاحة** | لا | متى يراه الطلاب أوّل مرّة. اتركه فارغًا للإتاحة الآن. |
| **تاريخ الاستحقاق** | نعم | الموعد النهائي. |
| **الدرجة القصوى** | نعم | ما يُقيَّم منه العمل (مثل 20). |
| **المرفقات** | لا | ملفات تقدّمها — ورقة عمل، أو نصّ، أو معيار تصحيح. |
</Step>

<Step>
### حدّد قواعد التسليم

قرّر كيف يسلّم الطلاب أعمالهم:

| الخيار | ما يفعله |
| --- | --- |
| **نوع التسليم** | **عبر الإنترنت** (يرفع الطلاب ملفات) أو **في الصف** (يُسلَّم ورقيًا — تسجّل الدرجة فقط). |
| **السماح بالتسليم المتأخّر** | السماح بالتسليم بعد الاستحقاق، اختياريًا حتى موعد لاحق. |
| **عدد الملفات لكل تسليم** | كم ملفًا يمكن للطالب إرفاقه. |
| **أنواع الملفات المقبولة** | تقييد الرفع (مثل *pdf, docx*). |
| **السماح بإعادة التسليم** | السماح للطلاب باستبدال تسليمهم قبل الموعد النهائي. |
</Step>

<Step>
### احفظ

يظهر الواجب للصف، ويمكن للطلاب تسليمه ضمن نافذة الاستحقاق.
</Step>

</Steps>

## كيف يسلّم الطلاب

في الواجب **عبر الإنترنت**، يفتحه الطالب و**يرفع** ملفاته، مع ملاحظة اختيارية. وإن سمحت بإعادة
التسليم، فيمكنه استبدال عمله حتى الموعد النهائي (أو موعد التأخير).

ويظهر واجب الطالب **قيد الانتظار** حتى يسلّم، ثم **تمّ** — أو **لم يُنجَز** إن مرّ الموعد دون تسليم.

## التصحيح وإبداء الملاحظات

افتح عرض تصحيح الواجب لترى كل التسليمات في مكان واحد. لكل طالب، أدخِل **درجة** و**ملاحظات** اختيارية.
وعندما تجهز، **انشر الدرجات** لجعلها مرئية للطلاب والأسر.

<Callout title="تبقى الدرجات خاصة حتى تنشرها">
الدرجات والملاحظات التي تُدخِلها غير مرئية للطلاب حتى **تنشرها** — فيمكنك إنهاء التصحيح أولًا.
</Callout>

## تُحتسَب في سجلّ الدرجات

يمكن وضع الواجب في **فئة درجات** (مثل *الواجبات*) ومنحه **وزنًا**، فتغذّي درجاته درجة المادة لكل طالب.
راجع [سجلّ الدرجات](./gradebook).

## حالات استخدام شائعة

- **واجب بملف** — أنشئ واجبًا عبر الإنترنت؛ يرفع الطلاب ملف PDF.
- **تسليم ورقي** — أنشئ واجبًا *في الصف* وسجّل الدرجات فقط.
- **فرصة ثانية** — اسمح بإعادة التسليم ليصحّح الطلاب ويُعيدوا التسليم قبل الموعد.
