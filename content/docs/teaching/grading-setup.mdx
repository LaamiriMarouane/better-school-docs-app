**Grading setup** is where you decide how grades work. It has six tabs, listed in the order you
usually work through them.

<Callout title="Who this is for">
Administrators who configure grading before teachers enter marks, and teachers who supervise a level
or subject.
</Callout>

## Open Grading setup

Go to **Assessments** → **Grading setup**. The tabs run down the side of the screen (across the top on
a phone):

| Tab | What you set |
| --- | --- |
| **Year policy** | Display scale, rounding, calculation method, display formats, exception codes, and the grading scale. |
| **Grade categories** | The category names every subject can use, such as Homework or Mid-term. |
| **Levels** | For each level or track: marking periods, grading scheme, external exams, and level or period settings. |
| **Subjects** | For each subject and term: which categories count and their weights, and the exam templates. |
| **Competencies** | Proficiency scales, the competency library, and which subjects use competency grading. |
| **Comment bank** | Ready-made phrases for writing remarks. |

If you leave a tab with unsaved changes, the app asks you to confirm first.

### What teachers can do

Teachers can open **Grading setup** too. A lock next to a tab means it is view only for you:

- **Year policy** and **Grade categories** are always view only for teachers.
- **Levels** can be edited only for the levels you supervise for grading policy.
- **Subjects** and **Competencies** can be edited only for what you supervise for assessment setup.
  Proficiency scales stay view only.
- **Comment bank**: every teacher can manage their own personal phrases.

## Year policy

Set the defaults for the whole year, then click **Save**.

| Section | What you set |
| --- | --- |
| **Grade scale & rounding** | **Display scale** (for example 20 or 100), **Rounding precision**, **Rounding mode**, and **Allow manual average override**. |
| **Calculation Method** | **Category weighted** or **Total points** and what happens to **Uncategorized items**. |
| **Display formats** | **Primary format**, **Pass threshold**, and **Class ranking**. |
| **Exception codes** | The code and label shown for Absent and Exempt, and whether each one is dropped from the average or counts as zero. |
| **Grading scale** | The bands that turn averages into a letter, mention, and GPA. See [Grading scale](./grading-scale). |

## Grade categories

Categories are the names subjects use to group their marks. Click **Add Grade Category**, then give it
a **Name**, a **Purpose** (**Exam** or **Continuous**), and optionally a description and a colour.
Click **Save**.

Exam categories hold the exams you define for each subject. Continuous categories hold assignments,
quizzes, and other day-to-day marks. Weights are not set here: each subject sets its own under
**Subjects**.

## Levels

Use **Select a level or track**, then work through the tabs:

| Tab | What you'll do |
| --- | --- |
| **Marking Periods** | Split each term into marking periods. See [Marking periods](./marking-periods). |
| **Grading Scheme** | Decide how much each term and external exam counts in the year grade. |
| **External Exams** | Add regional or national exams, choose the subjects they cover, and enter scores. |
| **Level config** | Change year policy settings for this level only. |
| **Period Configuration** | Change settings for a single marking period. |

**Copy from last year** brings last year's setup into levels you haven't configured yet.

## Subjects

Pick a **Term**, then a subject from the list.

- **Categories**: add the categories that apply to this subject with **Add Category**. For each one,
  set the **Weight**, choose whether it **Counts** toward the average, and optionally how many low
  marks to drop (**Drop low**). Counting categories must total 100%.
- **Exams**: add the exam templates for each exam category. An exam category needs a weight on the
  **Categories** tab first. See [Exams](./exams).

You can also set the subject's coefficient, use **Copy to other subjects** to reuse the setup, and use
**Copy from last year** to bring back every subject's categories and exam templates.

## Competencies

An optional proficiency track alongside numeric grades, with three tabs: **Scales**, **Library**, and
**Subjects**. See [Competency-based grading](./competencies).

## Comment bank

The comment bank holds phrases teachers can insert when writing a subject remark or an overall remark.

- Switch between **School** phrases, shared with every teacher and managed by administrators, and
  **Personal** phrases, which only you see.
- Click **Add phrase**, then fill in the **Category** (for example "Excellent" or "Needs
  improvement"), the **Phrase**, and the **Usage**: **Subject remark**, **Overall remark**, or
  **Subject & overall**.
- Filter the list by usage or category. Deleting a phrase removes it from the picker but doesn't
  change remarks already written.

## Tips and best practices

- Finish **Year policy** and **Grade categories** before **Levels** and **Subjects**.
- On **Subjects**, set up **Categories** before **Exams**.
- **Level config** and **Period Configuration** start from the year policy. Change only the fields
  that really need to be different.
