Un **quiz** est un test en ligne construit à partir de questions. Vous créez des questions dans une
**banque de questions** réutilisable, vous les assemblez en un quiz, vous décidez de son
fonctionnement, et vous l'attribuez à une classe. Les élèves le passent à l'écran, et la plupart des
types de questions sont **corrigés automatiquement**.

<Callout title="Pour qui">
Les enseignants qui construisent et attribuent des quiz, et les élèves qui les passent.
</Callout>

## Les briques de base

| Élément | Ce que c'est |
| --- | --- |
| **Banque de questions** | Vos questions réutilisables. Chacune peut être **étiquetée** (ex. *algèbre*, *chapitre 3*) et reste un brouillon jusqu'à publication. |
| **Quiz** | Un ensemble de questions et de réglages. Un quiz est un brouillon jusqu'à publication, après quoi vous pouvez l'attribuer. |
| **Attribution de quiz** | Un quiz publié donné à une classe, avec une date de diffusion et d'échéance. |
| **Tentative** | Le passage d'un élève. |

## Types de questions

Les questions peuvent être :

- **Vrai / faux**
- **Choix multiple** — une ou plusieurs bonnes réponses
- **Ordonnancement** — remettre des éléments dans le bon ordre
- **Texte à trous** — taper la réponse, choisir dans une liste, ou glisser des mots
- **Étiquetage** — glisser des étiquettes sur une image
- **Catégorisation** — trier des éléments en groupes

Chaque question peut inclure un **indice**, une **explication** (affichée dans le retour), et des
**pièces jointes** comme une image ou un schéma.

## Construire un quiz

<Steps>

<Step>
### Créer le quiz

Donnez-lui un titre et une description. Il commence en **brouillon**.
</Step>

<Step>
### Ajouter des questions

Tirez des questions de la banque (ou créez-en), et définissez pour chacune l'**ordre**, les
**points**, et si elle est obligatoire.
</Step>

<Step>
### Régler le fonctionnement

Choisissez le comportement du quiz (voir ci-dessous).
</Step>

<Step>
### Publier

Publiez le quiz pour pouvoir l'attribuer. Ses questions doivent aussi être publiées.
</Step>

</Steps>

### Le fonctionnement d'un quiz

| Réglage | Ce qu'il contrôle |
| --- | --- |
| **Limite de temps** | Aucune limite, une limite par question, ou un temps total (15 minutes à 3 heures). |
| **Tentatives** | Combien de fois un élève peut le passer — ou illimité. |
| **Réserve de questions** | Montrer toutes les questions, ou tirer un sous-ensemble aléatoire à chaque tentative. |
| **Mélange** | Aléatoiriser l'ordre des questions et/ou des options de réponse. |
| **Retour** | Montrer les explications jamais, après chaque question, ou après tout le quiz. |
| **Afficher le score** | Si les élèves voient leur score à la fin. |
| **Note de passage** | Un pourcentage facultatif requis pour réussir. |
| **Navigation** | Laisser les élèves se déplacer librement, ou une question à la fois. |
| **Barème** | Comment les points sont attribués — standard, ou avec points négatifs pour les mauvaises réponses. |

## Attribuer le quiz à une classe

Attribuez un quiz publié à une **classe ou un groupe**, avec une date de **diffusion** et
d'**échéance**. Vous pouvez ajuster les réglages juste pour cette attribution si vous le souhaitez.

## Comment les élèves le passent

Un élève **démarre** le quiz, répond dans la limite de temps éventuelle, et **soumet**. La plupart
des questions sont **corrigées automatiquement**, le score est donc prêt immédiatement (affiché si
vous l'avez autorisé). Selon votre réglage de retour, ils voient les explications après chaque
question ou à la fin.

## Voir comment la classe a réussi

Pour chaque quiz, vous pouvez voir les **tentatives par élève** et des **analyses par question** —
quelles questions ont été bien réussies et lesquelles ont posé problème — pour guider votre
enseignement.

## Compte dans le carnet de notes

Comme les devoirs, un quiz peut être placé dans une **catégorie de note** avec un **poids**, afin que
les scores alimentent le [carnet de notes](./gradebook).

## Cas d'usage courants

- **Vérification rapide** — un court quiz à choix multiple avec retour instantané après chaque
  question.
- **Test chronométré** — fixez un temps total et une seule tentative.
- **Entraînement** — autorisez des tentatives illimitées et affichez les explications pour aider les
  élèves à apprendre.
