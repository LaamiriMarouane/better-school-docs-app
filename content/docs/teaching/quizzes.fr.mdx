Un **quiz** est un test en ligne construit à partir de questions. Vous créez des questions dans une
**banque de questions** réutilisable, vous les assemblez en un quiz, vous décidez de son
fonctionnement, et vous l'attribuez à une classe. Les élèves le passent à l'écran, et leurs réponses
sont **corrigées automatiquement**.

<Callout title="Pour qui">
Les enseignants qui construisent et attribuent des quiz, et les élèves qui les passent.
</Callout>

## Où le trouver

Tout se trouve dans **Évaluations** : **Quiz** pour vos quiz et **Banque de questions** pour vos
questions (les enseignants la voient sous le nom **Questions de Quiz**).

## Les briques de base

| Élément | Ce que c'est |
| --- | --- |
| **Banque de questions** | Vos questions réutilisables. Chacune peut être **étiquetée** (ex. *algèbre*, *chapitre 3*) et reste en **Brouillon** jusqu'à publication. |
| **Quiz** | Un ensemble de questions et de réglages. Un quiz reste en **Brouillon** jusqu'à publication, après quoi vous pouvez l'attribuer. |
| **Attribution de quiz** | Un quiz publié donné à une classe, avec une date de publication et d'échéance. |
| **Tentative** | Le passage d'un élève. |

Publier une question ou un quiz le rend visible aux administrateurs et aux enseignants de l'école,
pour que les collègues puissent le réutiliser.

## Types de questions

Choisissez **Ajouter une Question**, puis un type :

- **Vrai/Faux**
- **Choix multiples**
- **Ordre** — remettre des éléments dans le bon ordre
- **Saisissez vos réponses** — compléter les trous en tapant
- **Choisissez vos réponses** — compléter les trous avec des listes déroulantes
- **Glisser-déposer** — glisser des mots dans les trous
- **Étiquettes** — placer des étiquettes sur une image
- **Catégoriser** — trier des éléments en groupes
- **Hotspot image** — toucher la bonne zone d'une image
- **Surlignage texte** — surligner les bons mots d'un passage

Chaque question peut inclure un **Indice**, une **Explication** (affichée dans le retour), et des
images.

## Construire un quiz

Dans **Quiz**, choisissez **Ajouter un quiz**. L'éditeur vous guide en cinq étapes.

<Steps>

<Step>
### Informations de base

Donnez au quiz un **Titre du quiz**, une **Description** facultative, des **Étiquettes** et une
**Miniature**.
</Step>

<Step>
### Ajouter des Questions

Choisissez des questions dans la banque. Seules les questions publiées peuvent entrer dans un quiz.
</Step>

<Step>
### Gérer les Questions

Glissez les questions dans l'ordre voulu, et définissez pour chacune les **Points** et si elle est
obligatoire (**Requis**) ou optionnelle. Quand le quiz utilise une durée par question, vous réglez aussi le temps
de chaque question ici.
</Step>

<Step>
### Configuration

Choisissez le fonctionnement du quiz (voir ci-dessous).
</Step>

<Step>
### Réviser

Vérifiez le tout et choisissez **Créer un Quiz**. Le quiz commence en **Brouillon** : utilisez
**Publier** sur sa carte pour pouvoir l'attribuer.
</Step>

</Steps>

### Le fonctionnement d'un quiz

| Réglage | Ce qu'il contrôle |
| --- | --- |
| **Tentatives Max** | Combien de fois un élève peut le passer. Laissez vide pour **Sans limite**. |
| **Score de Réussite (%)** | Le pourcentage requis pour réussir. |
| **Durée** | **Sans limite**, **Par question** (un temps pour chaque question), ou un temps total de 15 minutes à 3 heures. |
| **Stratégie de Notation** | **Standard** (tous les points pour une réponse entièrement juste, une partie des points pour une réponse partiellement juste ; en sélection multiple, chaque mauvais choix annule un bon choix) ou **Points Négatifs** (chaque élément faux retire un quart de sa part). Une question ne descend jamais sous zéro. |
| **Mode de Rétroaction** | Afficher les corrections **Jamais**, **Après le Quiz** ou **Après Chaque Question**. |
| **Mode de Navigation** | **Libre** (aller et venir), **Séquentiel** (vers l'avant uniquement) ou **Verrouiller après Réponse** (une réponse donnée ne peut plus changer). Avec des temps par question, utilisez Séquentiel ou Verrouiller après Réponse. |
| **Mélanger les Questions** / **Mélanger les Options** | Rendre aléatoire l'ordre des questions et des choix de réponse. |
| **Réponse Requise pour Continuer** | Les élèves doivent répondre avant de passer à la suite. |
| **Afficher les Scores** | Si les élèves voient leur score à la fin. |
| **Choisir des Questions au Hasard dans le Pool** | Donner à chaque tentative un ensemble aléatoire de **Questions par Tentative**. Les questions requises sont toujours incluses. |

## Attribuer le quiz à une classe

Ouvrez **Évaluations → Devoirs**, choisissez **Ajouter un devoir**, puis **Quiz** : vous arrivez
sur **Quiz**, où vous choisissez un quiz publié puis **Assigner**. Vous pouvez aussi choisir
**Assigner** directement depuis un quiz.

Renseignez ensuite le **Trimestre**, la **Classe** (et la **Section de classe** si la classe est
divisée), la **Matière**, la **Période de notation**, la **Date de publication** et la **Date
d'échéance**. Vous pouvez ajuster les réglages du quiz juste pour cette attribution.

## Comment les élèves le passent

L'élève ouvre le quiz dans **Devoirs** et choisit **Commencer le quiz**. Il répond dans la limite de
temps éventuelle et soumet. Les réponses sont corrigées tout de suite, le score est donc prêt
immédiatement (affiché si vous avez activé **Afficher les Scores**). Selon le mode de rétroaction,
il voit les corrections après chaque question ou à la fin. S'il lui reste des tentatives, il peut
le repasser.

## Voir comment la classe a réussi

Ouvrez l'attribution du quiz pour voir les **Participants** (les tentatives de chaque élève et son
**Meilleur score**) et l'onglet **Analyses** : taux de réussite, **Distribution des scores** et
**Performance par question** — quelles questions ont été bien réussies et lesquelles ont posé
problème.

## Compte dans le carnet de notes

Un quiz n'a pas de poids propre. Comme pour les [devoirs](./assignments), activez **Compte dans la
moyenne finale** lors de l'attribution et choisissez une **Catégorie** : la meilleure tentative de
l'élève compte alors dans le [carnet de notes](./gradebook), dans le poids de cette catégorie. Vous
pouvez saisir une autre note dans le carnet ; effacez-la pour revenir à la meilleure tentative.

## Cas d'usage courants

- **Vérification rapide** — un court quiz à choix multiples avec un retour après chaque question.
- **Test chronométré** — fixez une durée totale et une seule tentative.
- **Entraînement** — laissez les tentatives illimitées, affichez le retour, et ne le comptez pas
  dans la moyenne finale.
