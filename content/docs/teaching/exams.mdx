---
title: Exams
description: Create exam templates, schedule exams for classes, grade them, publish results, and record exam attendance.
---

Exams work in two parts. An **exam template** is the blueprint — its name, length, maximum score,
and how much it counts. A **scheduled exam** is an actual sitting of that template for a class, on a
date, in a room. You build the template once, then schedule it for each class.

<Callout title="Who this is for">
Administrators and teachers who set, schedule, and grade exams.
</Callout>

## Step 1 — Create an exam template

<Steps>

<Step>
### Open exam templates

Go to **Exams → Templates** and add a template for a subject (at a level, for a term).
</Step>

<Step>
### Fill in the template

| Field | Required | Notes |
| --- | --- | --- |
| **Name** | Yes | The exam's name, e.g. *Mid-term*. |
| **Description** | No | Optional notes. |
| **Duration** | Yes | How long the exam lasts — 30 min, 45 min, 1 h, 1 h 30, 2 h, 2 h 30, or 3 h. |
| **Max score** | No | The score the exam is marked out of. |
| **Weight (%)** | No | How much this exam counts toward the term grade. A subject's exam weights should add up to 100%. |
| **Category** | No | A grade category to group the exam under. |
</Step>

</Steps>

## Step 2 — Schedule the exam

Go to **Exams → Scheduled** and schedule the template for a class.

| Field | Required | Notes |
| --- | --- | --- |
| **Template** | Yes | Which exam to sit. |
| **Class** *(and group)* | Yes | Who sits it. Pick a group if only part of a divided class takes it. |
| **Date and time** | Yes | When the exam takes place. |
| **Room** | No | Where it's held. |
| **Supervisors** | No | The teachers overseeing the exam. |

## Step 3 — Grade and publish results

When the exam is done, enter results in a grid — each student's **score** and optional
**notes** — then **publish** the results to make them visible to students and families.

<Callout title="Results stay private until you publish">
Scores you enter are not visible to students or families until you **publish** the results. This
lets you finish marking before anyone sees a grade.
</Callout>

## Step 4 — Record exam attendance

Exam attendance is recorded separately from grades. For each student, mark:

| Status | Meaning |
| --- | --- |
| **Present** | The student sat the exam. |
| **Absent** | The student didn't attend. |
| **Excused** | An approved absence — add the reason. |
| **Late** | The student arrived late. |

## Exam statuses

| Status | Meaning |
| --- | --- |
| **Scheduled** | Set up, not yet taken. |
| **Completed** | The exam has taken place. |
| **Graded** | Results have been entered. |
| **Cancelled** | The exam won't take place. |

## Make-up exams

If a student or class needs to retake or sit an exam later, schedule a **make-up** exam linked to
the original. It's marked as a make-up so it's clear in the records.

## Common use cases

- **Termly exams** — create a template per exam with weights that add up to 100%, then schedule each
  per class.
- **Split class** — schedule the same template separately for each group.
- **Absent student** — mark them absent (or excused), then schedule a make-up.
