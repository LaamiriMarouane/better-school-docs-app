This section is where teaching happens day to day. You build **course templates** and **lessons**, set
**assignments**, **quizzes**, and **exams**, follow results in the **gradebook**, and run each
**class session** — recording what was covered and taking **attendance**.

<Callout title="Who this is for">
Teachers delivering lessons and recording results, and administrators overseeing the academic side.
</Callout>

## The pieces

| Tool | Use it to… |
| --- | --- |
| **Course Templates** | Build the curriculum: one template per subject and level (and track), organised into chapters and lessons. |
| Lessons | Write the teaching content in a rich editor, and choose which classes can see it. |
| **Assignments** | Set homework, collect submissions, and grade with feedback. |
| **Quizzes** | Build quizzes from a question bank and let students take them with automatic marking. |
| **Scheduled Exams** | Schedule exams, grade them, and record exam attendance. |
| **Grading setup** | Set the year policy, grade categories, level and subject settings (including exam templates), competencies, and the comment bank. |
| **Gradebook** | See how exams, assignments, and quizzes combine into each student's grade. |
| **Report Cards** | Generate and publish student report cards (administrators). |
| Class sessions & attendance | Run each real class meeting: log what was covered, and mark who attended from **Timetable** → **Mark Attendance**. |

Two more tools sit alongside these. Teachers draw and present on interactive whiteboards from
**Academic** → **Boards**, and can attach a board to a lesson. The **Comment bank** tab in
**Grading setup** holds ready-made phrases teachers can insert when writing remarks.

## How it fits with the timetable

The [timetable](../timetable) produces the weekly plan. **Class sessions** are the actual meetings
that happen from that plan, day by day — and that's where attendance and the lesson log live. So
the timetable is the *plan*, and this section is what happens when classes actually run.
