This section is where teaching happens day to day. You build **courses** and **lessons**, set
**assignments**, **quizzes**, and **exams**, follow results in the **gradebook**, and run each
**class session** — recording what was covered and taking **attendance**.

<Callout title="Who this is for">
Teachers delivering lessons and recording results, and administrators overseeing the academic side.
</Callout>

## The pieces

| Tool | Use it to… |
| --- | --- |
| **Courses** | Build the curriculum — a course per subject and level, organised into chapters and lessons. Reuse a course from year to year. |
| **Lessons** | Write the teaching content in a rich editor, and control who can see it. |
| **Assignments** | Set homework, collect submissions, and grade with feedback. |
| **Quizzes** | Build quizzes from a question bank and let students take them with automatic marking. |
| **Exams** | Create exam templates, schedule exams, grade them, and record exam attendance. |
| **Gradebook** | See how exams, assignments, and quizzes combine into each student's grade. |
| **Class sessions & attendance** | Run each real class meeting: log the topic and homework, and mark who attended. |

## How it fits with the timetable

The [timetable](../timetable) produces the weekly plan. **Class sessions** are the actual meetings
that happen from that plan, day by day — and that's where attendance and the lesson log live. So
the timetable is the *plan*, and this section is what happens when classes actually run.
