title: Devoirs

---

Un **devoir** est un travail que vous donnez à une classe — devoir maison, projet, dissertation. Les
élèves peuvent rendre leur travail en ligne, vous le notez avec un retour, et la note remonte dans le
[carnet de notes](./gradebook).

<Callout title="Pour qui">
Les enseignants qui donnent et notent du travail, et les élèves qui le rendent.
</Callout>

## Créer un devoir

<Steps>

<Step>
### Ouvrir les devoirs

Allez dans **Devoirs** et choisissez **Ajouter un devoir**.
</Step>

<Step>
### Renseigner les détails

| Champ | Obligatoire | Remarques |
| --- | --- | --- |
| **Titre** | Oui | Le nom du devoir. |
| **Description** | Non | Les consignes pour les élèves. |
| **Classe** *(et groupe)* | Oui | Pour qui il est. Choisissez un groupe pour une partie d'une classe divisée. |
| **Date de diffusion** | Non | Quand les élèves le voient pour la première fois. Laissez vide pour diffuser maintenant. |
| **Date d'échéance** | Oui | La date limite. |
| **Note maximale** | Oui | Le barème (ex. 20). |
| **Pièces jointes** | Non | Des fichiers que vous fournissez — fiche, énoncé, grille. |
</Step>

<Step>
### Définir les règles de remise

Décidez comment les élèves rendent leur travail :

| Option | Ce qu'elle fait |
| --- | --- |
| **Type de remise** | **En ligne** (les élèves téléversent des fichiers) ou **En classe** (remis sur papier — vous enregistrez juste la note). |
| **Autoriser les remises tardives** | Permettre de rendre après l'échéance, éventuellement jusqu'à une limite ultérieure. |
| **Fichiers par remise** | Combien de fichiers un élève peut joindre. |
| **Types de fichiers acceptés** | Restreindre les téléversements (par exemple *pdf, docx*). |
| **Autoriser la re-remise** | Permettre aux élèves de remplacer leur travail avant l'échéance. |
</Step>

<Step>
### Enregistrer

Le devoir apparaît pour la classe, et les élèves peuvent le rendre dans la fenêtre prévue.
</Step>

</Steps>

## Comment les élèves rendent

Pour un devoir **en ligne**, l'élève l'ouvre et **téléverse** ses fichiers, avec une note
facultative. Si vous avez autorisé la re-remise, il peut remplacer son travail jusqu'à l'échéance (ou
la limite tardive).

Le devoir d'un élève est **En attente** jusqu'à la remise, puis **Fait** — ou **Non fait** si
l'échéance passe sans rien de rendu.

## Noter et donner un retour

Ouvrez la vue de notation du devoir pour voir toutes les remises au même endroit. Pour chaque élève,
saisissez une **note** et un **retour** facultatif. Quand vous êtes prêt, **publiez les notes** pour
les rendre visibles aux élèves et aux familles.

<Callout title="Les notes restent privées jusqu'à publication">
Les notes et retours que vous saisissez ne sont pas visibles par les élèves tant que vous ne les avez
pas **publiés** — vous pouvez donc finir la correction d'abord.
</Callout>

## Compte dans le carnet de notes

Un devoir peut être placé dans une **catégorie de note** (ex. *Devoirs*) et recevoir un **poids**,
afin que ses notes alimentent la note de matière de chaque élève. Voir
[Carnet de notes](./gradebook).

## Cas d'usage courants

- **Devoir avec fichier** — créez un devoir en ligne ; les élèves téléversent un PDF.
- **Remise sur papier** — créez un devoir *en classe* et enregistrez simplement les notes.
- **Seconde chance** — autorisez la re-remise pour que les élèves corrigent et rendent à nouveau avant
  l'échéance.
