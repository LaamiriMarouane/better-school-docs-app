A **quiz** is an online test built from questions. You create questions in a reusable **question
bank**, assemble them into a quiz, decide how it runs, and assign it to a class. Students take it on
screen, and most question types are **marked automatically**.

<Callout title="Who this is for">
Teachers building and assigning quizzes, and the students who take them.
</Callout>

## The building blocks

| Piece | What it is |
| --- | --- |
| **Question bank** | Your reusable questions. Each can be **tagged** (e.g. *algebra*, *chapter 3*) and is a draft until you publish it. |
| **Quiz** | A set of questions plus settings. A quiz is a draft until you publish it, after which you can assign it. |
| **Quiz assignment** | A published quiz given to a class, with a release and due date. |
| **Attempt** | A student's go at the quiz. |

## Question types

Questions can be:

- **True / false**
- **Multiple choice** — one or several correct answers
- **Ordering** — put items in the right sequence
- **Fill in the blank** — type the answer, pick from a dropdown, or drag words in
- **Labelling** — drag labels onto an image
- **Categorise** — sort items into groups

Each question can include a **hint**, an **explanation** (shown in feedback), and **attachments** such
as an image or diagram.

## Build a quiz

<Steps>

<Step>
### Create the quiz

Give it a title and description. It starts as a **draft**.
</Step>

<Step>
### Add questions

Pull questions from the bank (or create new ones), and set each one's **order**, **points**, and
whether it's required.
</Step>

<Step>
### Set how it runs

Choose the quiz's behaviour (see below).
</Step>

<Step>
### Publish

Publish the quiz so it can be assigned. Its questions need to be published too.
</Step>

</Steps>

### How a quiz runs

| Setting | What it controls |
| --- | --- |
| **Time limit** | No limit, a per-question limit, or a total time (15 minutes to 3 hours). |
| **Attempts** | How many times a student may take it — or unlimited. |
| **Question pool** | Show all questions, or draw a random subset each attempt. |
| **Shuffle** | Randomise the order of questions and/or answer options. |
| **Feedback** | Show explanations never, after each question, or after the whole quiz. |
| **Show score** | Whether students see their score when they finish. |
| **Pass mark** | An optional percentage needed to pass. |
| **Navigation** | Let students move freely, or one question at a time. |
| **Scoring** | How marks are awarded — standard, or with negative marking for wrong answers. |

## Assign the quiz to a class

Assign a published quiz to a **class or group**, with a **release** and **due** date. You can tweak
the settings just for this assignment if you want.

## How students take it

A student **starts** the quiz, answers within any time limit, and **submits**. Most questions are
**marked automatically**, so the score is ready immediately (shown if you allowed it). Depending on
your feedback setting, they see explanations after each question or at the end.

## See how the class did

For each quiz you can see **attempts per student** and **question-level analytics** — which questions
were answered well and which tripped students up — to guide your teaching.

## Counts toward the gradebook

Like assignments, a quiz can sit in a **grade category** with a **weight**, so scores feed into the
[gradebook](./gradebook).

## Common use cases

- **Quick check** — a short multiple-choice quiz with instant feedback after each question.
- **Timed test** — set a total time limit and one attempt.
- **Practice** — allow unlimited attempts and show explanations to help students learn.
