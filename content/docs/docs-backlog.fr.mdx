## Comment utiliser cette liste

1. Choisissez une ligne.
2. Lisez l'UI live (et les libellés de barre latérale correspondants) avant d'écrire.
3. Respectez la voix des docs existantes — paragraphes courts, tableaux pour les champs, `Steps` pour les procédures, `Callout` pour les avertissements.
4. Livrez EN, FR et AR ensemble, et mettez à jour ce tableau une fois terminé.
