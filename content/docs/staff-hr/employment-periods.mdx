---
title: Employment periods
description: Record each staff member's employment contracts — dates, contract type, and pay terms — used for payroll.
---

An **employment period** is one stretch of employment for a staff member: when it started, when it
ends (if it has), the contract type, and the pay terms. A person can have several periods over
time. Payroll uses the period that covers the month you are paying.

<Callout title="Who this is for">
Administrators managing staff contracts and pay terms.
</Callout>

## Where to manage employment

Employment is **not** a separate sidebar item. Open it from:

| Path | When to use it |
| --- | --- |
| **HR → Staff** → open the staff member → **Employment** tab | The usual place on a staff (or driver) profile. |
| **HR → Payroll → Staff Salaries** → **Manage Salary** | When you are setting pay and recurring components together. |

## What an employment period holds

| Field | Required | Notes |
| --- | --- | --- |
| **Start date** | Yes | First day of this period. Locked once the period is saved. |
| **End date** | No | Leave empty while the person is still employed (**Present**). Set an end date to close the period. |
| **Contract type** | No | Full time, Part time, Contract, Temporary, Internship — or not specified. |
| **Pay frequency** | No | Monthly or Hourly. |
| **Base salary** | No | Used when pay is monthly. |
| **Hourly rate** | No | Used when pay is hourly. |
| **Notes** | No | Free text. |

An **Active** badge shows on the period that covers today (started on or before today, and no end
date or an end date still in the future).

## Add or edit a period

<Steps>

<Step>
### Open employment for the staff member

From **HR → Staff**, open the person's profile and stay on **Employment**, or use
**Manage Salary** from **Payroll → Staff Salaries**.
</Step>

<Step>
### Add employment period

Choose **Add employment period** and fill in the fields above.
</Step>

<Step>
### Save

The period is saved on the staff member. Creating a new open period closes the previous open one
the day before the new start date, so periods do not overlap.
</Step>

</Steps>

To change pay terms or set an **end date**, edit the period. There is no separate “close”
action — ending employment means setting the end date (or deleting the period if it was created
in error).

<Callout title="Overlaps are blocked">
Two employment periods for the same person cannot cover the same dates. The system stops you if
the ranges would overlap.
</Callout>

## Recurring salary components

On **Manage Salary**, you can also attach **recurring components** (allowances or deductions) to
the **active** employment period. Those amounts are picked up when payslips are generated. See
[Payroll](./payroll).
