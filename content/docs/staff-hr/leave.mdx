---
title: Leave
description: "Record staff time off, and approve, reject, or cancel leave requests."
---

**Leave** records a staff member's time off for a date range. An administrator can record leave
directly, or a staff member can request it and an administrator decides.

<Callout title="Module required">
Leave needs the **Leave Management** module. If you don't see it, ask whoever manages your school's
modules to turn it on.
</Callout>

## Leave types

| Type | For… |
| --- | --- |
| **Sick** | Illness. |
| **Maternity** | Maternity leave. |
| **Unpaid** | Time off without pay. |
| **Other** | Anything that doesn't fit the above. |

<Callout title="No balances or quotas">
Leave is recorded as **dates with a type** — the system doesn't track an allowance, accrual, or a
paid-vs-unpaid day count. *Unpaid* is simply a type you choose, not a running balance.
</Callout>

## Statuses

| Status | What it means |
| --- | --- |
| **Pending** | Requested by a staff member, waiting for a decision. |
| **Approved** | Granted. Leave an administrator records directly is approved straight away. |
| **Rejected** | Turned down, with an optional reason. |
| **Canceled** | Called off before it started. |

## Record leave as an administrator

<Steps>

<Step>
### Open Leave and add one

In the **HR → Leave** area, choose **Add**, then pick the staff member.
</Step>

<Step>
### Set the type and dates

Choose the **type** and the **start** and **end** dates.
</Step>

<Step>
### Save

The leave is saved as **Approved** right away — no separate approval step when an administrator
records it.
</Step>

</Steps>

## Request leave as a staff member

Teachers and staff request their own leave from their leave page. A request is created as **Pending**
and waits for an administrator. You can edit or **cancel** your own request while it's still pending.

## Approve or reject requests

From the leave list, an administrator handles pending requests:

- **Approve** — grants the leave.
- **Reject** — turns it down; you can add a reason that the requester will see.
- **Bulk approve / reject** — select several pending requests and act on them at once.

## Cancel a leave

A leave can be **canceled** while it is **Pending** or **Approved**, but only **before its start
date** — you can't cancel one that has already begun. Once a leave is rejected or canceled, it stays
that way.

<Callout title="Overlaps are blocked">
A staff member can't have two leaves that overlap the same dates. If you try to add or edit one into
an existing leave's range, the system stops you.
</Callout>

## Who can do what

| Action | Administrator | Staff / teacher |
| --- | --- | --- |
| Record leave directly (approved) | ✅ | — |
| Request leave (pending) | — | ✅ (their own) |
| Approve / reject | ✅ | — |
| Cancel before start date | ✅ | ✅ (their own) |
| See all staff's leave | ✅ | Their own only |
