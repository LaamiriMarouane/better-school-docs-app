تحوّل **الرواتب** توظيف الموظفين ومكوّنات الأجر إلى قسائم رواتب شهرية. تدير الرواتب، وتنشئ دورة
لشهر، وتعاين وتولّد القسائم، ثم تقفل وتدفع وتغلق الدورة.

<Callout title="لمن هذا الدليل">
المسؤولون الذين يُعدّون رواتب الموظفين ويدفعونها.
</Callout>

## افتح الرواتب

انتقل إلى **الموارد البشرية ← الرواتب**. مساحة العمل تضم أربع علامات تبويب، إضافةً إلى
**الإعداد** في الترويسة:

| علامة التبويب / المكان | تُستخدَم لـ… |
| --- | --- |
| **رواتب الموظفين** | فتح **إدارة الراتب** لكل موظف — فترات التوظيف والمكوّنات المتكررة. |
| **دورات الرواتب** | إنشاء دورة لشهر، ثم فتحها للمعاينة والتوليد والقفل والدفع والإغلاق. |
| **قسائم الرواتب** | مراجعة القسائم الفردية ونقلها مسوّدة ← معتمدة ← مدفوعة. |
| **السلف** | منح سلف رواتب وإلغاء ما يجب إيقافه. |
| **الإعداد** (الترويسة) | إعدادات رواتب المدرسة وكتالوج مكوّنات الراتب. |

## قبل تشغيل الرواتب

- يوجد الموظفون تحت **الموارد البشرية ← الموظفين**.
- لكل شخص سيُدفع له **فترة توظيف** تغطّي الشهر، مع شروط أجر مضبوطة. راجع
  [فترات التوظيف](./employment-periods).
- اختياريًا، مكوّنات متكررة مرفقة بالفترة النشطة.
- **إعداد** الرواتب مضبوط (دورة الأجر / الإعدادات ومكوّنات الراتب).

إن لم يكن أحد موظفًا في ذلك الشهر، تُظهر معاينة الدورة أنه لا يمكن دفع راتب لأي موظف.

## إنشاء دورة وإكمالها

<Steps>

<Step>
### أنشئ الدورة

في **دورات الرواتب**، أنشئ دورة لـ**الفترة** (الشهر). يمكنك إضافة تسمية اختيارية. تبدأ الدورة
كـ**مفتوحة**.
</Step>

<Step>
### عاين وولّد

افتح الدورة واستخدم **معاينة وتوليد**. حدّد الموظفين الجاهزين (تظهر علامات مثل جاهز أو يحتاج
ساعات عندما يجب إكمال شيء أولًا)، ثم **توليد المحدّد**.
</Step>

<Step>
### وافق واقفل وادفع

بينما الدورة **مفتوحة** يمكنك اعتماد القسائم، و**قفل** الدورة، و**دفع الكل**. يطلب الدفع تاريخ
دفع وطريقة ومرجعًا اختياريًا، ويدفع كل قسيمة **معتمدة** في الدورة.
</Step>

<Step>
### أغلق

بعد أن تصبح الدورة **مدفوعة**، استخدم **إغلاق الدورة** لإنهائها. يمكن أيضًا **إلغاء** الدورة قبل
إنهاء الدفع.
</Step>

</Steps>

### حالات الدورة

| الحالة | المعنى |
| --- | --- |
| **مفتوحة** | دورة عمل — معاينة وتوليد واعتماد وقفل أو دفع. |
| **مقفلة** | مجمّدة للتعديلات؛ ما زال بإمكانك الدفع. |
| **مدفوعة** | قُيّدت قسائم الدورة كمدفوعة. |
| **مغلقة** | مُنهَاة نهائيًا. |
| **ملغاة** | أُهمِلت قبل إنهاء الدفع. |

## قسائم فردية

تسرد علامة تبويب **قسائم الرواتب** القسائم عبر الدورات. تنتقل القسيمة **مسوّدة ← معتمدة ← مدفوعة**
(أو **ملغاة**). يمكنك معالجة قسيمة واحدة خارج أزرار الدفعة عند الحاجة.

## السلف

في **السلف**، امنح سلفة بمبلغ إجمالي وقسط وتاريخ منح وطريقة دفع وملاحظات اختيارية. يمكن إلغاء
السلف النشطة لإيقاف الأقساط المستقبلية.

## الإعداد

افتح **الإعداد** من ترويسة الرواتب:

- **إعدادات الرواتب** — كيف تُثبَّت فترة الأجر والقواعد المدرسية ذات الصلة.
- **مكوّنات الراتب** — كتالوج مكوّنات الأرباح والخصومات التي يمكنك إرفاقها بفترات التوظيف.
